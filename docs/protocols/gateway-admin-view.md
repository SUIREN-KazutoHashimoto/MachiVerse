# ゲートウェイ・管理ビュー間プロトコル設計書

## 1. 所有者

本プロトコルの所有者はゲートウェイです。

## 2. 目的

管理ビューがゲートウェイを通じてシステム状態を参照し、必要な管理操作をコアへ伝達するための契約を定義します。

## 3. 設計原則

- 管理ビューはゲートウェイのコード、DLL、内部型を参照しない。
- ゲートウェイは管理ビューのコード、DLL、内部型を参照しない。
- 双方は本プロトコル設計書を契約として実装する。
- 管理ビューはコアへ直接接続しない。
- コアへ影響する管理操作は必ずゲートウェイを経由する。
- 管理ビューがゲートウェイ内部キャッシュやコア内部モデルを直接意識しない。

## 4. 通信カテゴリ

### 4.1 状態参照

管理ビューが監視・診断・運用確認に必要な情報を取得します。

### 4.2 管理操作

管理ビューからゲートウェイへ、コアへ影響する管理要求を送信します。

ゲートウェイは認証・認可・形式検証・要求種別判定を行い、コア向けプロトコルへ仲介します。

### 4.3 管理結果

管理要求の処理結果を管理ビューへ返します。

## 5. 禁止事項

- 管理ビューからコアへの直接通信
- ゲートウェイ内部型への依存
- コア内部型への依存
- 共有 DTO ライブラリへの依存
- UI 側だけで管理権限制御を完結させること

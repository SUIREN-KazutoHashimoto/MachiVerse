# ゲートウェイ・一般ビュー間プロトコル設計書

## 1. 所有者

本プロトコルの所有者はゲートウェイです。

## 2. 目的

一般ビューがゲートウェイの公開情報を読み取り専用で取得するための契約を定義します。

## 3. 設計原則

- 一般ビューはゲートウェイのコード、DLL、内部型を参照しない。
- ゲートウェイは一般ビューのコード、DLL、内部型を参照しない。
- 双方は本プロトコル設計書を契約として実装する。
- 一般ビュー向けプロトコルには、シミュレーション状態を変更する操作を定義しない。
- 応答可能な情報は原則としてゲートウェイの参照用キャッシュから提供できる構造とする。
- コア内部モデルをそのまま公開しない。

## 4. 通信カテゴリ

### 4.1 状態参照

一般ビューが表示に必要な公開済みシミュレーション状態を取得します。

### 4.2 接続・通信状態

必要に応じて、データの鮮度、取得失敗、再接続など、一般ビューが表示判断に利用する通信状態を定義します。

## 5. 禁止事項

- 状態変更要求
- 管理操作
- コアへの直接アクセスを前提とする情報
- ゲートウェイ内部キャッシュ構造への依存
- 共有 DTO ライブラリへの依存

## 6. 今後定義する詳細

- 物理通信方式
- 参照 API / メッセージ一覧
- フィールド定義
- データ鮮度の表現
- ページング・範囲指定
- エラー形式
- バージョニング
- 認証要否
- 更新通知方式

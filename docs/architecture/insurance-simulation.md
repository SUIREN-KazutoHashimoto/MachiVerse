# 保険シミュレーション設計

## 1. 確定方針

標準では保険を単なる損失軽減補正として扱わず、世界内の契約・経済活動として表現する。

- 住人・企業等が保険契約を持ち得るものとする。
- 保険料、補償、事故、災害、医療等を接続できる方向とする。
- 保険の存在・種類・制度は社会・時代によって異なり得るものとし、現代的な保険制度を全世界へ固定適用しない。
- 保険契約は金融・信用、所有・権利、企業活動、医療、災害等と相互作用できるものとする。
- 保険会社の詳細な準備金管理、再保険、詳細な商品設計、高度なリスク査定等を標準で最高詳細度まで扱うことは要求せず、より詳細な保険モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準で扱う保険主体・契約の範囲
- 保険料・補償条件の表現
- 保険事故・請求・支払の流れ
- 保険会社等の組織状態をどこまで扱うか
- 公的保険と民間保険の扱い
- 不正請求・支払不能等をどこまで扱うか
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

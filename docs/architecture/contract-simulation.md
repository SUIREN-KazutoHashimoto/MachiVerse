# 契約シミュレーション設計

## 1. 確定方針

標準では売買・雇用等の成立時に状態だけを書き換えるのではなく、必要な契約関係を世界状態として表現する。

- 売買、雇用、賃貸、貸借、業務委託等について契約関係を表現できる方向とする。この列挙は確定済みの全契約類型ではない。
- 契約は当事者、義務、期間、対価等を持ち得る。
- 契約には成立だけでなく、履行、違反、終了等の状態変化が起こり得る。
- 契約は所有・権利、企業活動、金融・債務、住宅、雇用、司法等と接続する。
- 契約の有効性・強制力等は、その社会の法・慣習・制度によって異なり得るものとする。
- 条件付き義務、保証、違約金、複雑な契約連鎖等を標準で無制限に詳細化することは要求せず、より詳細な契約モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準契約類型と共通状態
- 義務・対価・期限等の表現
- 契約成立・変更・終了のモデル
- 契約違反と司法・評判等との接続
- 口頭・文書その他の契約形態をどこまで区別するか
- 法的契約と非公式な約束の境界
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

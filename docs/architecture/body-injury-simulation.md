# 身体部位別負傷シミュレーション設計

## 1. 確定方針

標準では負傷を単一のHPや総合負傷度だけに集約せず、ある程度の身体部位ごとの状態として扱う。

- 頭部、腕、脚等、ある程度の身体部位ごとに負傷状態を持たせられるものとする。この列挙は確定済みの身体区分ではない。
- 負傷した部位によって移動、作業、戦闘、日常行動等への影響が異なり得る。
- 負傷は医療、痛み等の住人状態、障害、回復、死亡等と接続する。
- 火災、事故、戦争、災害、身体的衝突等の原因から部位別負傷が生じ得る方向とする。
- 骨、臓器、血管、神経等まで解剖学的に非常に細かく常時シミュレーションすることは標準で要求せず、より詳細な人体・外傷モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準身体部位の区分
- 負傷種別・重症度の表現
- 部位別負傷から能力への影響モデル
- 出血・痛み等を標準でどこまで扱うか
- 治療・回復・後遺障害との接続
- 装備・防具との具体的接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

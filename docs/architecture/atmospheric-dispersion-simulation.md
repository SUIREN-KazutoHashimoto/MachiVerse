# 地上煙・ガス拡散シミュレーション設計

## 1. 確定方針

標準では地上の煙・有害ガスを発生地点周辺への固定範囲効果だけとして扱わず、C相当の比較的詳細な空間シミュレーションを行う。

- 風、建物、地形等によって煙・ガスの移動方向、影響範囲、濃度分布が時間とともに変化し得る。
- 建物や地下空間への流入・流出を表現できる方向とし、室内空気環境・地下環境と接続する。
- 火災、産業活動、事故、汚染等から発生する煙・ガスを扱える方向とする。この列挙は確定済みの全発生源ではない。
- 濃度等の空間状態は住人の健康、知覚、避難・移動、労働等へ影響し得る。
- 天候・大規模風系・建物・地形等との因果的な接続を持つ。
- C相当を標準範囲とするが、汎用CFDとして現実の大気流体を無制限の精度で解くことまでは要求しない。世界因果に必要な詳細度を優先する。
- 空間的な拡散・移流等の計算も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準で追跡する煙・ガス成分
- 濃度場・空気流の空間粒度
- 風・建物・地形による影響モデル
- 屋内・地下との境界交換モデル
- 健康・知覚への影響閾値
- 詳細領域外での簡略化

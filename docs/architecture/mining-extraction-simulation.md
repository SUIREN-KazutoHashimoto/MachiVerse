# 地下資源採掘シミュレーション設計

## 1. 確定方針

標準では採掘を地域資源量の単純な減算だけとして扱わず、地下の実際の位置と採掘活動を接続する。

- 地下資源は位置・深さ等の三次元的な分布と結び付くものとする。
- 採掘には坑道・採掘地点、設備、労働、技術、搬出経路等が関与し得る。この列挙は確定済みの全採掘要因ではない。
- 採掘によって地下資源は実際に減少し、資源枯渇モデルと接続する。
- 採掘活動は地形改変、地下構造物、物流、企業、労働、エネルギー、地下環境等と相互作用する。
- 標準では採掘面、支保、換気、詳細な掘削方式等をC相当の最高詳細度まで全て扱うことは要求しない。
- 将来アドオンによって、採掘面・支保・換気・詳細な掘削方式等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 地下資源の標準空間表現
- 採掘地点・坑道と資源量の関係
- 採掘設備・技術・労働の影響モデル
- 採掘物の搬出・在庫化
- 地形・地下安定性への影響
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 暗黙知・技能継承シミュレーション設計

## 1. 確定方針

標準では技術情報が文書化されれば、それだけで技能を完全複製できるとは仮定しない。

- 一部の技能・製造法・作業手順等には、実践経験や直接指導を通じて伝わる暗黙知を持たせられる。
- 文書・記録による知識伝達と、実地訓練・徒弟・共同作業等による技能継承を区別できる方向とする。
- 熟練者・指導者が失われたり、教育・実践の機会が途絶えたりすることで、社会・組織・地域から技能が衰退・消失し得る。
- 技術そのものが世界に存在すること、住人が理論を知っていること、住人が実際に実行できることを区別する。
- 教育、職業、技能・熟練、知識媒体、製造、文化、組織等と接続する。
- 標準では手技・コツ等を非常に細かな知識要素として常時追跡することは要求しない。
- 継承・忘却等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 暗黙知の標準表現
- 理論知識・技能・暗黙知の境界
- 直接指導・徒弟・共同作業による伝達モデル
- 技能消失・再発見の条件
- 組織・地域単位の技能保有との関係
- 詳細領域外での簡略化

# 医療シミュレーション設計

## 1. 確定方針

標準では医療を単純な回復率補正だけにせず、世界内の人員・施設・物資・経済等と接続する。

- 医師、看護等の医療従事者、薬、医療施設、設備等を世界状態と接続できるものとする。この列挙は確定済みの全要素ではない。
- 診療、治療、入院等をある程度実体的にシミュレーションできる方向とする。
- 医療へのアクセスには、利用可能な人員・施設・設備・薬、費用、移動時間等が影響し得る。
- `resident-lifecycle-health.md` の疾病・負傷・回復・死亡等と接続する。
- 医療供給は教育・職業・企業・組織・物流・資源・政治等と相互作用できるものとする。
- 詳細な診断過程、検査、薬効、副作用、専門科等を標準で無制限に詳細化することは要求せず、より詳細な医療モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準で扱う診療・治療の粒度
- 医療職・施設・設備・薬の標準分類
- 診断・治療選択のモデル
- 医療費・保険・公的医療等をどこまで扱うか
- 救急医療の扱い
- 医療物資の生産・物流との接続
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

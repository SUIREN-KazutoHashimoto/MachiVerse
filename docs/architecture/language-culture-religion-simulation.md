# 言語・文化・宗教シミュレーション設計

## 1. 確定方針

標準では、言語・文化・宗教を地域や集団だけの固定属性にせず、住人単位でも関係を保持できるものとする。

- 住人ごとに使用言語、文化、宗教との関係を表現できる。
- 移住、教育、家族、人間関係、情報伝播その他の社会的過程によって、それらが変化・混合・伝播し得る。
- 文化・言語・宗教は事前歴史シミュレーションを含む歴史的過程の中で形成・変化し得る。
- 一人の住人を必ず単一の言語・文化・宗教へ排他的に所属させることは要求しない。
- 方言・宗派・文化的慣習等を標準でどこまで細分化するかは未確定とし、必要以上の詳細化は将来アドオンで拡張できる余地を持たせる。
- ランダム性を伴う場合も決定論・完全再現性の原則に従う。

## 2. 他システムとの接続

言語・文化・宗教は、住人の意思決定、家族・世代、教育・学習、情報伝播、人間関係、組織、政治、移住等と相互作用できるものとする。ただし、特定の属性から特定の行動を機械的に決定するモデルにはしない。

## 3. 今後決定が必要な事項

- 使用言語能力の粒度
- 多言語使用の表現
- 文化・宗教との関係をどの状態軸で表すか
- 改宗、離脱、混合、分岐等の具体モデル
- 方言、宗派、慣習等の標準範囲
- 言語理解と情報伝達の接続
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

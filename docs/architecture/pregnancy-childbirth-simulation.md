# 妊娠・出産シミュレーション設計

## 1. 確定方針

標準では出生を条件成立時の即時的な住人追加だけとして扱わず、妊娠から出産までの時間的過程を持つ。

- 妊娠から出産まで時間経過を伴う状態として表現する。
- 妊娠中の健康、栄養、医療、生活環境等が母体や出生へ影響し得る。この列挙は確定済みの全要因ではない。
- 出生によって新しい住人が世界状態へ加わり、既存の親子・家族・世代モデルと接続する。
- 妊娠・出産は住人の意思決定、関係、文化・制度、医療等と接続し得るが、具体的条件は今後定義する。
- 詳細な胎児医学、妊娠段階ごとの生理、出産時の詳細な合併症等を標準で最高詳細度まで扱うことは要求せず、より詳細な妊娠・出産モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 妊娠成立の標準モデル
- 妊娠期間・状態の粒度
- 健康・栄養・医療等からの影響
- 出産場所・支援者・医療との接続
- 出生時の健康状態の決定
- 多胎等をどこまで扱うか
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

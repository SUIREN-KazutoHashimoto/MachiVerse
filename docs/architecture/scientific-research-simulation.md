# 科学・研究活動シミュレーション設計

## 1. 確定方針

標準では研究を単一の研究力や技術ツリー進行値だけにせず、住人・組織・知識・設備・経済と接続する。

- 研究者や研究を行う組織が、既存知識、設備、資金、他者との交流等を利用して研究活動を行えるものとする。この列挙は確定済みの全研究要因ではない。
- 研究活動は新しい知識や技術の発見・発明につながり得る。
- 個人単位の知識、教育、職業、組織、技術革新、経済、情報伝播等と相互作用する。
- 研究成果が生じたことと、その成果が社会へ普及・利用されることは分離する。
- 仮説、実験、論文、査読、再現、学派間競争等を標準で最高詳細度まで扱うことは要求せず、より詳細な科学活動モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 研究行為・研究成果の標準粒度
- 研究者・研究組織の成立条件
- 既存知識と新規発見の具体的関係
- 設備・資金・交流等の影響モデル
- 基礎知識と応用技術の境界
- 研究成果の記録・伝播・喪失
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

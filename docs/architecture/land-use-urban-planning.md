# 土地利用・都市計画シミュレーション設計

## 1. 確定方針

標準では、土地利用・建設判断を需要だけで決定せず、権利・経済・地理・交通・社会制度等と接続する。

- 土地の所有・利用権、地価、交通、地形、需要等が土地利用・建設へ影響し得る。
- その社会・時代に都市計画、建築規制その他の土地利用制度が存在する場合、それらも建設・利用判断へ影響できるものとする。
- 世界共通で現代的なゾーニング制度が必ず存在するとは仮定しない。
- 土地利用制度は政治・統治、所有・権利、組織、文化、歴史等によって形成・変更され得る方向とする。
- 用途地域、建蔽率、容積率、建築確認等の特定の現実制度を標準要件として固定しない。
- より詳細・特殊な都市計画・建築制度は将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 土地利用状態の標準分類
- 地価・需要等との具体的接続
- 建設判断と規制適用のモデル
- 公共インフラ計画との関係
- 制度が存在しない社会での土地利用形成
- 違法建築・非公式居住等をどこまで扱うか
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

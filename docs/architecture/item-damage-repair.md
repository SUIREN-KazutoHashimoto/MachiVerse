# 物品破損・修理シミュレーション設計

## 1. 確定方針

標準では道具・家具・機械・装備等を使用可能／破棄の二値だけで扱わない。

- 物品は使用、時間、環境、事故等によって劣化・破損し得る。
- 修理、部品交換、再利用等によって状態を回復・延命できる方向とする。
- 修理には必要に応じて技能、工具、部品、材料、設備、時間、費用等が関係し得る。
- 製品品質、製造工程、保守、所有・権利、物流、職業等と接続する。
- 標準では一般物品すべてについて詳細な部品構成・故障箇所・修理工程を常時持つことは要求しない。
- より詳細な部品レベルの故障・修理モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 劣化・破損状態の標準表現
- 修理可能性・修理限界
- 部品交換と物品同一性の扱い
- 品質・使用履歴との関係
- 修理技能・工具・設備の粒度
- 廃棄・再利用・リサイクルとの接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

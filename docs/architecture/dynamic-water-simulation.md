# 河川・水域の動的変化シミュレーション設計

## 1. 確定方針

標準では河川・湖・海岸線等を世界生成時から完全固定された背景として扱わない。

- 降水、渇水、洪水、堤防、ダム、取水等によって水量・水域が変化し得るものとする。この列挙は確定済みの全要因ではない。
- 水の変化は農業、都市、交通、災害、水道、産業、生態系等へ影響し得る。
- 人工的な地形改変や水利施設と自然水系を接続する。
- 標準では流速、水位、河道変化、侵食・堆積等を高精度な流体・地形物理として常時計算することは要求しない。
- より詳細な水理・河川地形モデルは将来アドオンで拡張できる余地を持たせる。
- 水域変化も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 水量・水域の標準表現
- 河川・湖・地下水・海域の境界
- 降水・流入・流出・蒸発等の粒度
- 洪水・渇水との具体的接続
- ダム・堤防・取水等の効果
- 地形改変との相互作用
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

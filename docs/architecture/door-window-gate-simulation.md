# ドア・窓・ゲートシミュレーション設計

## 1. 確定方針

標準ではドア・窓・ゲート等を単なる通行可否フラグとして扱わず、開閉・施錠等の状態を持つ世界内オブジェクトとして扱う。

- ドア、窓、ゲート等は開閉状態を持ち得る。
- 必要に応じて施錠状態を持ち、アクセス制御モデルと接続する。
- 開閉状態は住人・物品等の通行、視界、空気・煙の移動、室内環境、建物利用等へ影響し得る。
- 火災、避難、防犯、建物内部、知覚、空気環境等と接続する。
- 標準では開き角度、隙間、開閉途中の衝突等をC相当の最高詳細度まで常時計算することは要求しない。
- 破損については物品・建物の破損モデルと接続できる方向とする。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 開閉・施錠・破損等の標準状態
- 通行判定との接続
- 空気・煙・温度等の交換への影響
- 自動ドア・大型ゲート等の扱い
- 開閉操作に必要な時間・行動
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

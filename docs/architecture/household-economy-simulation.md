# 家計シミュレーション設計

## 1. 確定方針

標準では全住人を完全に独立した経済主体としてのみ扱わず、世帯・家族等による生活資源・支出の共有を表現する。

- 世帯・家族等は住居、食料、生活用品、育児・介護等に必要な資源や支出を共有し得る。この列挙は確定済みの全共有対象ではない。
- 共有資産・共有支出と個人所有・個人収入・個人債務等は区別できるものとする。
- 世帯内の収入、必要、関係、文化等によって資源配分・消費行動が変化し得る。
- 家族・世代、住宅、消費・商品選択、雇用・職業、福祉、所有・権利等と接続する。
- 世帯という概念や共有形態は社会・文化・歴史によって異なり得るため、現代的な核家族を普遍的前提としない。
- 詳細な家計簿、個人間の全支出交渉、扶養契約等を標準で最高詳細度まで扱うことは要求しない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 世帯・共同生活単位の標準表現
- 共有資産・個人資産の境界
- 収入・支出・資源配分の意思決定
- 世帯形成・分離・死亡等による変化
- 社会・文化による差異
- 詳細領域外での簡略化

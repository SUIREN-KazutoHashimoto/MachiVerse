# 無償労働・家事・ケアシミュレーション設計

## 確定方針

標準では市場取引や賃金が発生しない活動を時間消費なしとして扱わず、住人の日常生活を構成する実際の活動として扱う。

- 家事、育児、看護・介護、家族支援等は住人の時間・体力・必要な物資や設備等を消費し得る。この列挙は網羅ではない。
- 無償労働・ケアは就業、教育、睡眠、余暇、家計、健康、ストレス、家族関係等へ影響し得る。
- 家族・世帯内で誰が担当するかは固定せず、関係、能力、時間、文化、必要性等によって変化し得る。
- 現代的な核家族や特定の性別役割を普遍的前提としない。
- 標準では家事項目ごとの詳細スケジュール、依存者ごとの精密なケア必要量、家庭内分担交渉等をC相当まで必須としない。
- 日常活動、家庭経済、子供の発達、健康、雇用、社会福祉等と接続する。
- 調整可能な数値はConfig化し、意思決定に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- ケア必要性・家事需要の標準粒度
- 担当者選択と優先順位
- 有償サービスとの代替・併用
- 詳細領域外での簡略化

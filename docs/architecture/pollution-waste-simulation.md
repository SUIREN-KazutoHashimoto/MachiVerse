# 環境汚染・廃棄物シミュレーション設計

## 1. 確定方針

標準では環境負荷を地域単位の単一数値だけに限定せず、人間活動から発生し自然・生活へ波及する状態として扱う。

- 生産、交通、廃棄、エネルギー利用等から汚染・廃棄物が発生し得るものとする。この列挙は確定済みの全発生源ではない。
- 汚染は水、土壌、大気等の環境状態と接続し、健康、農業、生態系、居住等へ影響し得るものとする。
- 廃棄物についても発生だけでなく、収集、輸送、処理等と世界内の組織・設備・物流を接続できる方向とする。ただし具体的な標準工程は今後定義する。
- 汚染・廃棄物の状態は産業構造、技術、規制、人口、都市形成等によって歴史的に変化し得るものとする。
- 化学物質ごとの詳細な反応・分解・拡散を標準で最高詳細度まで扱うことは要求せず、より詳細な環境化学等は将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準で扱う汚染・廃棄物カテゴリ
- 発生量・蓄積・拡散・減衰の粒度
- 水・土壌・大気との具体的接続
- 廃棄物処理・再利用等の標準範囲
- 健康・農業・生態系への影響モデル
- 規制・経済との接続
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

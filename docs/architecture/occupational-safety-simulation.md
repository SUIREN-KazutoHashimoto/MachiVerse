# 労働環境・職業安全シミュレーション設計

## 確定方針

標準では労働環境を生産性から切り離さず、住人の身体・心理・作業結果へ影響する世界状態として扱う。

- 労働時間、温度、騒音、危険物、機械、照明、安全設備、休憩等が影響要因になり得る。この列挙は網羅ではない。
- 労働環境は疲労、怪我、健康、ストレス、作業速度・品質、生産性、離職判断等へ影響し得る。
- 建物内部、気温・空気環境、機械設備、身体状態、作業品質、雇用、企業、医療等と接続する。
- 危険な環境でも必ず事故になる、あるいは安全設備があれば必ず事故を防げるという単純な決定則にはしない。
- 標準では詳細な労働安全規制、産業衛生測定、危険源評価等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な職業安全・産業衛生へ拡張できる余地を持たせる。
- 調整可能な数値はConfig化し、確率的な事故等も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 作業環境から住人状態への影響モデル
- 安全設備・保護具との接続
- 事故・疾病との境界
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

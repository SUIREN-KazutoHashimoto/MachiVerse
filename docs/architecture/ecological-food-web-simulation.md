# 生態系・食物網シミュレーション設計

## 1. 確定方針

標準では生態系を捕食者数と被食者数だけの独立した増減式として閉じず、植物・動物・人間活動をつなぐ食物関係として扱う。

- 種・植物群等の間に食物関係を持たせ、捕食・採食によって個体群・植生へ影響が生じ得る。
- 農業、漁業、狩猟、伐採、気候変動、災害等が食物網を通じて連鎖的に他の個体群・植生へ影響し得る。
- 食料不足、捕食圧、資源競合等が動物の移動・繁殖・死亡等へ接続する。
- 人間社会は生態系の外部ではなく、その利用・改変主体として生態系へ影響し、その変化から再び食料・産業・生活等への影響を受ける。
- 世界規模で必要な性能を確保するため、非常に多数の種・栄養・エネルギーフローを常に最高詳細度で計算することは標準要件としない。
- より詳細な生態系モデルは将来アドオンで拡張できる余地を持たせる。
- 集約モデルを利用する場合も、詳細領域との因果的整合と決定論・完全再現性を維持する。

## 2. 今後決定が必要な事項

- 標準の食物関係表現
- 種・植物群の粒度
- 捕食・採食から個体群への影響モデル
- 農業・漁業・狩猟との接続
- 詳細領域と集約領域の整合方法
- 標準と将来アドオンの境界

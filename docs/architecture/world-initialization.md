# ワールド初期化設計

## 1. 目的

本書は、MachiVerse におけるワールド開始時の初期状態生成・選択に関する要件を整理します。

## 2. 確定事項

- ワールド開始方式は外部Configで指定可能とする。
- デフォルトの開始方式は、**現実世界に似た初期条件から開始する方式**とする。
- 開始方式の選択はシミュレーション結果へ影響するため、完全再現性における「同一設定」の対象として扱う。
- 同一のワールドSeed、同一の初期化Config、同一のその他シミュレーション影響設定から生成される初期状態は決定的でなければならない。

## 3. デフォルト方式の意味

「現実世界に似た初期条件」とは、現実世界そのものを完全複製することを現時点では意味しません。

地形、人口、社会、都市、国家、技術水準、歴史等のうち、何をどの程度現実世界に近づけるか、実在データを利用するか、現実の特定年代を基準とするかは未確定です。

この要件だけを根拠に、現実世界データの利用、特定の地理データセット、特定年代、人口分布、国家境界、歴史イベント等を確定してはなりません。

## 4. Config設計上の原則

開始方式は、ソースコードへ固定された単一方式ではなく、外部Configから切り替え可能な設計とします。

ただし、利用可能な開始方式の正式な一覧、Configキー名、値表現、各方式固有の設定項目、設定不正時の扱いは今後定義します。

将来的にアドオンによる新しい初期化方式を追加できる余地を考慮しますが、現時点で具体的なアドオンAPIや初期化プラグイン方式は確定しません。

## 5. 決定論との関係

ワールド初期化は完全再現性の開始点となるため、実行時刻、OS時刻、処理速度、スレッド実行順等の非決定的要素によって初期状態が変化してはなりません。

ランダム要素が必要な場合は、MachiVerse 全体の乱数設計原則に従い、ワールドSeed等の決定的入力から結果を導出します。

## 6. 今後決定が必要な事項

- Configで選択可能にする開始方式の正式な一覧
- 「現実世界に似た」の具体的な範囲と精度
- 現実世界データを利用するか
- 現実の特定年代・時点を基準にするか
- 自然環境・人口・都市・社会・国家・技術等のどこまでを初期条件として生成するか
- 初期世界に過去の履歴を持たせる方法
- 初期化処理とワールドSeedの具体的な関係
- 初期化Configの形式・項目・検証方法
- 他の開始方式の要件
- アドオンによる開始方式拡張を行う場合の境界

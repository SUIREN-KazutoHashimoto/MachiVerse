# 軍事・戦争シミュレーション設計

## 1. 目的

本書は、MachiVerse における軍事・戦争と、住人、組織、装備、補給、地形、交通、産業、技術、政治等との関係に関する要件を整理します。

## 2. 確定事項

- 標準でも軍事・戦争を比較的深くシミュレーションする。
- 戦争を国家等に付与された単一の軍事力数値同士の比較だけで解決することを標準とはしない。
- 兵士は世界内の住人と接続された存在として扱えるものとし、軍事だけの世界から切り離された抽象駒に限定しない。
- 部隊、装備、補給、地形、交通、指揮、士気等が戦争・戦闘の結果へ影響できる設計を目指す。
- 軍事・戦争は人口、産業、物流、技術、政治、経済、地理その他の世界状態から影響を受け、その結果も再び世界状態へ影響する因果系として扱う。
- 世界自体はフル3Dでシミュレーションされるため、軍事・戦争もその世界状態と接続する。ただし、標準で一兵士の全挙動や全弾道・装備部品等を常時最高詳細度で計算することは要求しない。
- 標準モデルは世界規模で成立する必要十分以上の軍事・戦争シミュレーションを提供し、超詳細な戦術・兵器・戦闘モデル等は将来アドオンで拡張できることを設計上考慮する。
- アドオン拡張を考慮することは、現時点で具体的なアドオンAPI、プラグイン機構、拡張ポイント等を確定することを意味しない。
- 軍事・戦争にランダム性を含める場合も、MachiVerseの決定論・完全再現性の原則に従う。

## 3. 世界シミュレーションとの統合

軍事・戦争を独立したミニゲームや、世界状態から切り離された結果計算として扱うことを標準とはしません。

兵士となる住人、軍事組織、装備、生産能力、補給物資、輸送経路、地形、気候、技術、政治的意思決定等が相互に影響し、その条件から軍事行動と結果が生じる設計を目指します。

戦争による死傷、人口移動、物資消費、施設・交通への影響、経済・政治・社会への影響等も世界の因果関係へ戻せる方向とします。ただし、具体的な影響項目・計算モデルは今後定義します。

## 4. 兵士と部隊

兵士は住人モデルと接続し、職業・所属・技能・知識・意思・人間関係等との整合を考慮します。ただし、軍務への参加条件や徴募・志願等の具体制度は現時点では確定しません。

部隊は複数の住人や装備等を軍事行動上まとめる単位として扱える設計を目指します。部隊階層、編制、指揮系統、役職等の具体モデルは今後定義します。

## 5. 装備・補給・地形・交通

装備は技術・産業・資源・生産・物流と接続し、存在しない装備や供給されていない物資を軍事力の抽象値として無条件に利用できるモデルにはしません。

補給は軍事行動へ影響する標準要素とし、物資の生産、保有、輸送、消費等との関係を持たせる方向とします。

地形および交通条件も軍事行動へ影響できるものとし、MachiVerseのフル3D世界状態と整合させます。ただし、移動、視界、射程、遮蔽、弾道等の具体的な空間計算モデルは今後定義します。

## 6. 指揮・士気

指揮および士気は標準モデルで戦争・戦闘へ影響できる要素とします。

ただし、指揮命令の伝達方式、指揮官の能力、部隊の統制、士気の状態軸・変化条件等は今後定義し、現時点では具体的な数式や階層を固定しません。

## 7. 詳細度とアドオン

標準では、軍事が人口・産業・物流・技術・政治・地理等と因果的につながり、戦争の結果が世界へ意味のある影響を返せる程度まで比較的深く扱います。

一方で、一兵士の全行動、個々の弾薬・弾道、兵器内部部品、極めて詳細な戦術判断等を世界全域で常時最高精度にシミュレーションすることは標準要件としません。

より詳細な戦術、兵器、戦闘、軍制等は将来アドオンで拡張できる余地を持たせます。ただし、そのために標準モデルの性能、決定論、既存要件、コンポーネント独立性を犠牲にしてまで過度に抽象化することは求めません。

## 8. 決定論

戦闘結果、士気、意思決定その他の軍事要素に確率的要素を含める場合も、ワールドSeed、World Time、対象・文脈を識別する決定的情報等から結果を導出し、処理速度、スレッド順序、OS時刻等によって結果が変化してはなりません。

同一の完全再現性条件では、軍事・戦争の状態変化と結果も再現可能でなければなりません。

## 9. 今後決定が必要な事項

- 標準で扱う軍事・戦争要素の具体的な一覧
- 兵士と住人モデルの具体的な接続
- 徴募・志願・徴兵等の制度モデル
- 部隊の編制・階層・指揮系統
- 装備・兵器の粒度
- 弾薬・燃料その他の消耗品をどの粒度で扱うか
- 補給・兵站の具体モデル
- 地形・気候・交通が軍事行動へ与える具体的影響
- 移動・視界・射程・遮蔽・弾道等の空間モデル
- 指揮・命令伝達・統制のモデル
- 士気の状態・変化モデル
- 戦闘結果および損害の計算モデル
- 戦争が人口・経済・産業・物流・政治・社会等へ返す影響
- 外交・宣戦・講和等と政治・統治モデルの境界
- 事前歴史シミュレーションにおける軍事・戦争の簡略化範囲
- 詳細シミュレーション領域外での軍事・戦争の簡略化範囲
- 標準モデルと将来アドオン拡張の具体的な境界

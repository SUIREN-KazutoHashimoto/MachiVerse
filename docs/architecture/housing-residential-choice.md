# 住宅市場・居住選択シミュレーション設計

## 1. 確定方針

標準では住人へ居住先を機械的に割り当てるだけでなく、住宅市場と住人の生活条件を接続する。

- 家賃・価格、広さ、立地、通勤、家族構成、収入、治安等が居住選択へ影響し得る。この列挙は確定済みの全要因ではない。
- 住人は利用可能な住宅と自身の状況を踏まえて居住先を選択・変更し得る。
- 引っ越しは実際の住人の移住・移動、家族・関係、職業、交通等と接続する。
- 住宅の供給・需要は建設、土地利用、所有・権利、企業活動、人口等と相互作用できるものとする。
- 住宅ローン、仲介、詳細な賃貸契約、住宅開発市場等を標準で最高詳細度まで扱うことは要求せず、より詳細な住宅市場は将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 住宅需要・選択の具体モデル
- 世帯と居住単位の関係
- 家賃・売買価格形成との接続
- 空室・過密・ホームレス等の扱い
- 所有・賃貸その他の居住権の標準範囲
- 引っ越しの費用・物流
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 火災シミュレーション設計

## 1. 確定方針

標準では火災を建物単位の抽象イベントだけにせず、建物内部を含む比較的詳細な世界状態として扱う。

- 可燃物、建物構造、天候、周囲の建物等が延焼・鎮火へ影響できるものとする。
- `building-interior-simulation.md` の方針と整合し、必要な範囲で部屋、家具、設備等の内部要素単位でも火災・延焼を扱える方向とする。
- 煙を標準シミュレーション対象に含め、住人の健康・視認・避難等へ影響できるものとする。ただし煙流動の具体的物理モデルは今後定義する。
- 住人の避難行動と接続し、火災発生時にも住人が世界内で実際に行動するものとする。
- 消防活動を、世界内の人員・組織・車両・設備・水等と接続できるものとする。
- 火災は建物、都市、交通、医療、経済、天候・災害等へ波及し得るものとする。
- 標準で比較的深く扱うが、燃焼化学や流体力学を最高詳細度で常時計算することまでは要求せず、より詳細な火災物理等は将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 可燃性・発火・燃焼状態の標準表現
- 部屋・家具・設備等の火災粒度
- 延焼モデルと3D空間との接続
- 煙・熱の標準計算粒度
- 建物損傷・崩壊との関係
- 避難行動・経路選択との接続
- 消防組織・車両・設備・消火資源の粒度
- 山火事等の屋外火災との共通化範囲
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

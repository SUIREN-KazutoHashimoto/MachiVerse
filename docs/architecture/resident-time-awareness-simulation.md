# 住人の時刻・時間認識シミュレーション設計

## 確定方針

標準では全住人がSimulation Coreの正確なWorld Timeを常時知っているとはしない。

- Coreが保持する正確なWorld Timeと、住人が認識している時刻を分離する。
- 時計、鐘、太陽、社会的な合図等、その社会・時代・場所で利用可能な手段から時刻を把握し得る。この列挙は網羅ではない。
- 時刻を確認できない状況では、住人の時間認識は概算・不確実になり得る。
- 社会的な暦・時刻制度、予定・約束、勤務、交通、日常活動等と接続する。
- 技術・インフラ・制度の変化によって時間認識の精度や共有方法も変化し得る。
- 標準では時計個体ごとの詳細な誤差、同期機構、時刻制度運用をC相当まで必須としない。
- 時間認識に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 住人が保持する時刻認識の粒度
- 時刻確認行動と情報源
- 誤差・不確実性の表現
- 予定・遅刻判定との接続

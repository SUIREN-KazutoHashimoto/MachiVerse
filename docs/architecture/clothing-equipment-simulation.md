# 衣服・装備シミュレーション設計

## 1. 確定方針

標準では衣服・装備を住人能力への固定補正だけとして扱わず、所有・着用・利用される物品として世界状態と接続する。

- 住人が衣服、靴、防具、携行品等を所有・着用・装備できる方向とする。この列挙は確定済みの全装備分類ではない。
- 衣服・装備は気候への適応、防護、職業上の必要性、文化、社会的評価等へ影響し得る。
- 生産、品質、所有・権利、消費行動、物流、職業、戦闘等と接続する。
- 一般的な衣服・装備を常に一点ずつ独立Entityとして管理することは要求せず、既存の物品・製品の実体性方針に従う。
- 身体部位ごとの詳細な重ね着、サイズ、素材、濡れ、汚れ、詳細な摩耗等を標準で最高詳細度まで扱うことは要求せず、より詳細な衣服・装備モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準装備スロット・分類の有無と粒度
- 所有・携行・着用・保管の状態表現
- 防寒・防護・職業等への具体的影響
- 品質・劣化・故障との接続
- 文化・社会的評価との接続
- 荷物量・重量を標準でどこまで扱うか
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

# 情報の証拠・信頼性シミュレーション設計

## 1. 確定方針

標準では情報を内容だけの値として扱わず、その出所・伝達経路・証拠・信頼関係等を住人の信念形成へ接続する。

- 同じ内容の情報でも、情報源、伝達経路、付随する証拠、既存の信頼関係等によって住人ごとの信じる度合いが異なり得る。
- 情報を受信したことと、その内容を真実と認識したことを区別する。
- 直接観察、他者からの伝聞、文書・記録、組織発表等の異なる由来を区別できる方向とする。この列挙は確定済みの全情報源ではない。
- 相反する情報を受け取った場合、住人が一律に最新情報へ上書きするとは仮定しない。
- 評判・信頼、住人記憶、司法、科学研究、マスメディア、噂、秘密情報等と接続する。
- 証拠や情報源自体も誤り、偽造、欠落、劣化等の影響を受け得る方向とするが、具体的な詳細度は今後決定する。
- 標準では文書鑑定、証拠保全、詳細な論証・推論過程等を最高詳細度まで必須としない。
- 信念更新等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 情報源・伝達経路・証拠の標準表現
- 信頼度・確信度等をどのように状態化するか
- 相反情報を受信した際の信念更新
- 記憶の劣化・忘却との接続
- 証拠の偽造・消失・破壊をどこまで扱うか
- 詳細領域外での簡略化

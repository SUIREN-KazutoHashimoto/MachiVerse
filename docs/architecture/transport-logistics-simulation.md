# 移動・交通・物流シミュレーション設計

## 1. 確定方針

標準では移動・交通・物流を比較的深く扱い、単なる地点間距離・所要時間だけには抽象化しない。

- 道路、鉄道、航路等の交通網を世界状態と接続する。この列挙は確定済みの全交通種別ではない。
- 徒歩、車両、船等による移動主体・手段を実体的に扱えるものとする。
- 距離、速度、容量、費用、地形、交通網その他の状態が移動へ影響できる。
- 車両・輸送主体、積載、乗換、運行、渋滞、交通事故等も標準で比較的深く扱う方向とする。ただし具体的な粒度・計算方式は今後定義する。
- 人だけでなく、食料、資源、製品、軍需物資その他の物流と接続する。
- 交通・物流は都市形成、経済、産業、軍事、情報伝播、災害等と相互作用できるものとする。
- 世界がフル3Dである既存要件に従い、移動・交通も権威ある3D世界状態と整合させる。ただし具体的な経路探索・交通物理方式は未確定とする。
- より詳細な車両挙動、交通工学、運行制度等は将来アドオンで拡張できる余地を持たせる。
- ランダム性を伴う場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準交通手段・交通網の種類
- 車両等の実体粒度
- 経路選択・経路探索モデル
- 交通容量・渋滞のモデル
- 積載・荷役・乗換の粒度
- 公共交通・運行計画をどこまで扱うか
- 交通事故・故障等の粒度
- 道路等の建設・維持との接続
- 詳細領域外・事前歴史での簡略化
- 標準と将来アドオンの境界

# 世論・集団行動シミュレーション設計

## 1. 確定方針

標準では世論を地域・国家ごとの単一支持率だけに抽象化せず、住人の認識・価値観・人間関係・情報伝播等から形成され得るものとする。

- 個々の住人の認識、価値観、人間関係、受け取った情報等が意見形成へ影響し得る。
- 世論は個人状態の集積・相互作用として変化し、政治、経済、文化、治安、外交等へ影響し得る。
- デモ、抗議、ボイコット等の集団行動が住人・組織の意思決定から生じ得る方向とする。この列挙は確定済みの全行動ではない。
- 集団行動は単発の固定イベントではなく、参加者、目的、情報、組織化、場所、治安等の世界状態と接続できるものとする。
- 群衆心理、運動組織化、宣伝戦等を標準で最高詳細度まで扱うことは要求せず、より詳細な社会運動・群衆モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 意見・支持・不満等の標準表現
- 世論を集計状態として保持するか、必要時に導出するか
- 情報源・信頼・噂等との具体的接続
- 集団行動の発生・参加判断モデル
- 組織化・指導者等をどこまで扱うか
- 治安・政治との相互作用
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

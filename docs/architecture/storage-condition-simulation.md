# 容器・保管条件シミュレーション設計

## 確定方針

標準では物品が在庫に存在するだけで、場所や環境に関係なく同じ状態で保存できるとはしない。

- 一部の物品は容器、倉庫、冷蔵、乾燥、施錠等の適切な保管条件を必要とし得る。この列挙は網羅ではない。
- 保管条件が不適切な場合、劣化、腐敗、漏出、破損、盗難等のリスクが変化し得る。
- 保管設備には容量や利用可能状態があり得る。
- 物品位置、在庫、建物内部、電力、温熱・空気環境、衛生、腐敗、所有・アクセス権、物流等と接続する。
- 標準では容器内部の詳細な温湿度分布、包装構造、保存化学等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な包装・保管環境へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 保管条件要求の標準表現
- 保管設備容量と割当
- 環境状態から劣化への接続
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

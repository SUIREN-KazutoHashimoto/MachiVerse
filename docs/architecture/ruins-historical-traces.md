# 廃墟・歴史的痕跡シミュレーション設計

## 1. 確定方針

標準では放棄された建物・道路・設備等を自動的に世界から消去せず、必要に応じて過去の痕跡として残す。

- 廃墟、旧道、放棄設備、古い土地利用等が後世の世界状態へ残り得る。
- 後世の住人・組織がそれらを発見、再利用、解体、修復等できる方向とする。
- 歴史的痕跡は都市・建物、交通、土地利用、文化、所有・権利、資源利用等と接続する。
- 標準では非常に長期間の風化・埋没・遺跡形成・考古学的発見をC相当の最高詳細度まで常時計算することは要求しない。
- 将来アドオンによってC相当の長期風化・遺跡・考古学モデルへ拡張できる余地を持たせる。
- アドオン対応を理由として標準の性能・完全再現性・現在要件を損なわない。
- 歴史的痕跡の形成・変化も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 痕跡として残す対象の標準範囲
- 放棄・廃墟化の状態遷移
- 再利用・修復・解体との接続
- 古い道路・土地利用等の保持方法
- 風化・埋没を標準でどこまで扱うか
- 住人が過去の痕跡を認識する方法
- 詳細領域外での簡略化
- C相当アドオンとの境界。ただし具体的API・機構は現時点では定義しない

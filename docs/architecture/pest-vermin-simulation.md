# 害虫・害獣シミュレーション設計

## 1. 確定方針

標準では害虫・害獣を完全に無視せず、必要な粒度で発生・個体群状態として扱う。

- ネズミ、昆虫等に相当する害虫・害獣が、食料、ごみ、衛生、建物、気候等の条件に応じて増減し得る。この列挙は確定済みの全対象ではない。
- 害虫・害獣は食料損失、衛生悪化、疾病、建物・物品への被害等へ影響し得る。
- 駆除・清掃・衛生改善・建物管理等によって発生状況が変化し得る。
- 野生動物・感染症・食品・廃棄物・建物内部・衛生システム等と接続する。
- 標準ではすべてを個体レベルで常時追跡せず、必要に応じた集約表現を許容する。
- 標準では個体ごとの詳細移動、巣、繁殖行動、駆除抵抗性等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、それらをC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 発生・増減に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 害虫・害獣の標準分類と粒度
- 発生・繁殖・減少モデル
- 食料・衛生・疾病との接続
- 駆除・防除の標準表現
- 詳細領域外での集約方法
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

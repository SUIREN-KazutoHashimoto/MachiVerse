# 腐敗・賞味性シミュレーション設計

## 確定方針

標準では食料等の劣化し得る物品が消費されるまで永久に同一品質で保存されるとはしない。

- 食料、医薬品その他必要な物品は、時間、温度、湿度、保管状態等によって品質が低下し得る。この列挙は網羅ではない。
- 劣化によって価値・品質・安全性・利用可能性が変化し、腐敗・使用不能等になり得る。
- 物品の種類・品質・保管条件によって劣化速度や影響は異なり得る。
- 食料、医療、商品品質、在庫、物流、保管、電力、衛生、廃棄物等と接続する。
- 腐敗した物品が消費された場合の健康影響等も、関連システムと因果的に接続できる方向とする。
- 標準では微生物増殖や食品種類ごとの詳細な化学反応をC相当まで必須としない。
- 調整可能な数値はConfig化し、劣化に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 品質・鮮度状態の標準粒度
- 劣化速度の算出方法
- 集約在庫内の異なる鮮度の扱い
- 消費判断・販売価格との接続

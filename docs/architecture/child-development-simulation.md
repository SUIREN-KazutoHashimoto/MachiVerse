# 幼児・子どもの発達シミュレーション設計

## 1. 確定方針

標準では子どもの成長を年齢による単純な能力補正だけとして扱わない。

- 成長に伴って身体能力、知識、技能、自立度等が変化し得るものとする。この列挙は確定済みの全発達軸ではない。
- 家庭環境、栄養、健康、教育、人間関係等が発達へ影響し得る。
- 発達は個人知識、教育、家族・世代、健康、生理的欲求、人間関係、文化等と接続する。
- 同年齢の住人が必ず同じ能力・発達状態になるとは仮定しない。
- 認知・言語・運動等の発達段階を標準で最高詳細度まで細分化することは要求せず、より詳細な発達モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準の発達軸・状態表現
- 年齢と発達の関係
- 栄養・健康・教育等からの影響モデル
- 自立度と日常行動・意思決定の関係
- 子どもの職業・労働等を社会差としてどこまで扱うか
- 発達差・遅延等の表現範囲
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

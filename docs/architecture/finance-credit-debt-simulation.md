# 金融・信用・債務シミュレーション設計

## 1. 確定方針

標準では金融を現金・預金だけに限定せず、貸借・信用・債務を住人・企業・組織の経済活動と接続する。

- 貸借、利息、返済、信用、債務不履行、担保等をある程度扱えるものとする。この列挙は確定済みの全金融要素ではない。
- 債務・信用状態は消費、投資、事業活動、資産取得その他の意思決定へ影響し得る。
- 金融関係は住人・企業・組織等の実際の関係として形成・変化・解消し得る方向とする。
- 経済、企業活動、所有・権利、政治・統治等と相互作用できるものとする。
- 銀行制度、信用創造、証券化、金融商品、詳細な金融市場等を標準で無制限に深く扱うことは要求せず、より詳細・特殊な金融モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準金融主体・金融関係の範囲
- 信用評価の表現
- 利息・返済条件・債務不履行の具体モデル
- 担保と所有・権利の接続
- 通貨・預金・銀行を標準でどこまで扱うか
- 破産・債務整理等の扱い
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

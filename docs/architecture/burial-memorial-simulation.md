# 墓地・埋葬・追悼シミュレーション設計

## 1. 確定方針

標準では住人の死亡後に物理・社会的痕跡が必ず消えるとは仮定せず、社会・文化・宗教等に応じた死者の扱いを世界状態として扱う。

- 埋葬、火葬、墓、墓地、追悼等が社会・文化・宗教・時代に応じて行われ得る。この列挙は確定済みの全葬送形態ではない。
- 墓地・墓等は土地利用、建造物、所有・権利、宗教施設、歴史的痕跡等と接続する。
- 葬送・追悼は家族、関係、感情、記憶、宗教・文化、社会イベント等へ影響し得る。
- 放置、戦争、災害、社会崩壊等によって通常の葬送が行われない場合もあり得る。
- 標準では葬儀の詳細進行、墓石内容、墓地運営等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、詳細な葬儀進行、墓石・記念物、墓地管理等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 行動選択等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 葬送状態・墓・墓地の標準表現
- 遺体処理との接続
- 家族・宗教・土地利用との関係
- 長期的な墓地・記念物の残存
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

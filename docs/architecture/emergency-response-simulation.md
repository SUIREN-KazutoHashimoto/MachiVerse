# 救急・消防・災害対応シミュレーション設計

## 1. 確定方針

標準では事故・火災・災害へ抽象的な対応値を即時適用せず、認知・通報から実際の対応資源の派遣・活動までを世界内の過程として扱う。

- 事故・火災・災害等が認知・通報された後、対応可能な住人・組織・車両・装備等が必要に応じて現場へ実際に移動する。
- 救助、消火、救急処置、搬送、避難誘導等を実際の活動として扱える。この列挙は確定済みの全対応活動ではない。
- 距離、交通・混雑、道路状態、通信、要員、装備、施設容量等によって到着時間・対応能力が変化し得る。
- 火災、医療、交通、災害、建物損傷、通信、電力、群衆、サービス容量等と接続する。
- 標準では指令管制、詳細な隊編成、救急トリアージ、災害対策本部運用等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、指令管制・隊編成・詳細トリアージ・災害対策本部等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 派遣・優先順位等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 通報・認知・派遣の標準状態遷移
- 対応資源の選択・優先順位
- 複数事案同時発生時の資源競合
- 現場活動の標準粒度
- 医療搬送・施設容量との接続
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

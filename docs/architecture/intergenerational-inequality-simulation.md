# 世代をまたぐ資産・地位格差シミュレーション設計

## 1. 確定方針

標準では成人した住人が一律の初期条件から人生を開始するとは仮定せず、家庭・地域・社会条件が次世代へ影響するものとする。

- 家庭の資産、教育機会、人間関係、居住地、評判、文化、相続等によって次世代の機会が変化し得る。
- 所得・資産・教育・健康・職業・政治的影響力等の格差が世代をまたいで拡大・縮小し得る方向とする。
- 親世代の地位が子世代の結果を機械的に決定するとは仮定しない。
- 教育、家族、相続、住宅、職業、階層、評判・信頼、健康等と接続する。
- 標準では社会移動指標や統計モデルをC相当の最高詳細度まで必須としない。
- 地域・社会・時代によって継承の強さや経路が異なり得る。
- 状態変化等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 世代間継承する状態・影響の標準表現
- 教育・資産・関係等の影響経路
- 社会移動の標準評価方法
- 詳細領域外での簡略化

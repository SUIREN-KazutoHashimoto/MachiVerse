# 感染症シミュレーション設計

## 1. 確定方針

標準では感染症を地域単位の感染率だけで処理せず、住人・移動・生活環境等から感染が伝播するモデルを持つ。

- 住人同士の接触、移動、人口密度、衛生、免疫等が感染伝播へ影響し得る。
- 疾病ごとに感染・発症・回復等に関わる性質を持たせ、流行・拡大・収束が世界状態から生じ得るものとする。
- 医療、健康、日常行動、交通、建物、天候・環境、人口等と相互作用できるものとする。
- 感染した住人全員が同一経過を必ず辿る単純モデルには限定しない。
- 病原体変異、詳細な免疫反応、遺伝的感受性等を標準で最高詳細度まで扱うことは要求せず、より詳細な感染症・疫学モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 疾病状態・感染経路の標準粒度
- 接触の定義と計算方法
- 潜伏・発症・重症化・回復等のモデル
- 免疫の標準粒度
- 衛生・天候・環境等との具体的接続
- 検査・隔離・予防等をどこまで扱うか
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

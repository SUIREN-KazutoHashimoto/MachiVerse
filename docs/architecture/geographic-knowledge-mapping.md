# 地図・測量・地理認識シミュレーション設計

## 1. 確定方針

標準では住人・組織がSimulation Coreの真の地理状態へ自動的に完全アクセスできるとは仮定しない。

- 世界の真の地理状態と、住人・組織が認識している地理情報を分離する。
- 探索、実際の移動、測量、地図、他者からの情報伝達等によって地理知識を獲得できる方向とする。
- 地理知識は不完全・古い・誤っている場合があり得る。
- 地図等の知識媒体を作成・保有・複製・伝達できる方向とし、既存の知識媒体・情報伝播モデルと接続する。
- 地理認識は移動、交通、交易、軍事、外交、開拓、資源利用等へ影響し得る。
- 詳細な測量技術、地図制作工程、座標系、航法誤差等を標準で最高詳細度まで扱うことは要求せず、より詳細な地理・測量モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 地理知識の標準表現・粒度
- 未知・既知・不確実等の状態表現
- 探索・測量による知識獲得モデル
- 地図媒体と住人記憶の役割分担
- 古い・誤った地理情報の更新方法
- 経路探索と住人が知る経路の関係
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 夜・照明・暗闇シミュレーション設計

## 1. 確定方針

標準では昼夜をView上の見た目や単一の活動率補正だけにせず、Simulation Coreの世界状態・知覚・行動と接続する。

- 太陽光による昼夜と暗所を世界状態へ反映できるものとする。
- 技術・設備が存在する場合、人工照明によって局所的な明るさを変化させられる方向とする。
- 明るさ・暗闇は住人の視覚的知覚、交通、犯罪、労働、日常行動、建物内部等へ影響し得る。
- 人工照明は必要に応じて電力・燃料・設備等と接続する。
- Simulation Core側の明るさ状態・知覚判定と、General ViewにおけるThree.jsの視覚表現は役割を分離する。
- 詳細な光源、影、反射、照度等をCore側で高精度な光学・レンダリングとして常時計算することは標準要件とせず、より詳細な光学モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 昼夜・太陽位置の標準計算方法
- 明るさ状態の粒度
- 建物・地形等による遮光の扱い
- 人工照明の範囲・消費資源との接続
- 知覚判定に必要な明るさの表現
- 天候との接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

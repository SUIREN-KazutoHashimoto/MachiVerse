# 海洋シミュレーション設計

## 1. 確定方針

標準では海を単なる移動可能な水域・資源領域として扱わず、世界の自然環境を構成する動的な系として扱う。

- 海流、波浪・荒天、海水温等をある程度の空間・時間変化を持つ状態として扱う。
- 海洋状態は航海、漁業、気候、沿岸地域等へ影響し得る。
- 世界生成時の大規模海流は、陸海配置、気候、大規模風系等と因果的に接続する方向とする。
- 海洋状態は天候、自然災害、食料・漁業、交通・物流等と接続する。
- 標準では深度別海流、塩分、詳細な波、海洋循環等をC相当の最高詳細度まで常時扱うことは要求せず、より詳細な海洋モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 海流・海水温・波浪等の標準粒度
- 海洋と大気・気候の相互作用モデル
- 沿岸・河川との境界
- 航海・船舶への影響モデル
- 漁業・海洋生態系との接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

# 身体的移動・衝突シミュレーション設計

## 1. 確定方針

標準では、住人・車両等を単に地点間で瞬間移動させず、権威あるフル3D世界空間上の移動として扱う。

- 住人・車両等が実際の3D空間内を移動できるものとする。
- 壁、建物内部、地形その他の障害物による通行可否を扱う。
- 他の物体との基本的な衝突・占有関係を扱えるものとする。
- 移動・衝突は交通、建物内部、火災時の避難、戦争、日常行動等と接続する。
- 精密な剛体物理、転倒、押し合い、投擲、詳細な車両衝突、破片挙動等を標準要件として固定しない。
- より高度な物理シミュレーションを将来アドオンで拡張する余地は持たせるが、具体的なアドオン方式は現時点では確定しない。
- 3D空間演算も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 3D空間の座標系・単位・精度
- 衝突形状・占有状態の粒度
- 住人・車両等の移動モデル
- 経路探索との役割分担
- 動的障害物・混雑の扱い
- 物理エンジン利用の有無
- 詳細領域外での移動簡略化
- 標準と将来アドオンの境界

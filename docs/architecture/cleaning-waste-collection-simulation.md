# 清掃・ごみ回収シミュレーション設計

## 1. 確定方針

標準では建物・街路等の汚れやごみが自動消滅するとはせず、発生・蓄積・清掃・回収・運搬を世界内の活動として扱う。

- ごみ・汚れは住人生活、事業活動、施設利用等に伴って発生し得る。
- 住人、事業者、行政その他の主体が清掃・回収を行わなければ蓄積し得る。
- 蓄積は衛生、景観、害虫・害獣、火災、通行、施設利用等へ影響し得る。
- 回収された廃棄物は既存の廃棄物・物流・再利用・処分システムへ接続する。
- 標準では清掃ルート、分別回収、容器容量、収集頻度等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、清掃ルート、分別回収、容器容量、収集頻度等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 状態更新に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 汚れ・ごみの標準状態と粒度
- 発生・蓄積・清掃・回収の状態遷移
- 回収主体とサービス範囲
- 衛生・害虫・火災等への影響
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

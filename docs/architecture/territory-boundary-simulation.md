# 土地境界・領域シミュレーション設計

## 1. 確定方針

標準では土地の所有・利用・行政・国家支配を単一の「所属領域」に統合しない。

- 土地利用、所有権・利用権、行政領域、国家等の実効支配を別概念として表現できるものとする。
- これらの境界は常に一致するとは限らず、重複・不一致・変化を表現できる方向とする。
- 境界・領域は所有・権利、政治・統治、外交、軍事、土地利用、都市形成等と接続する。
- 実効支配と制度上の主張・承認等を同一視しない方向とするが、具体的な状態モデルは今後定義する。
- 地籍、筆界、詳細な測量、境界標、詳細な領有権紛争手続等を標準で最高詳細度まで扱うことは要求せず、より詳細な土地・領域制度は将来アドオンで拡張できる余地を持たせる。
- フル3D世界モデルと整合する空間状態として扱う。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 各種領域・境界の空間表現
- 所有・利用・行政・実効支配の具体的関係
- 重複・係争・未確定領域の状態表現
- 境界変化の原因・手続の粒度
- 海域・地下・上空等を標準でどこまで扱うか
- 地図・測量との接続
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

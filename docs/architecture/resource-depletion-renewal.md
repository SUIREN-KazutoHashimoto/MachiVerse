# 資源枯渇・再生可能性シミュレーション設計

## 1. 確定方針

標準では、資源を長期的に無限・固定の供給源として扱わない。

- 鉱物・化石燃料等の非再生資源は採掘・利用によって利用可能量が減少し得るものとする。
- 森林、魚類、水等の再生可能な資源は、自然条件・利用状況等に応じて再生・回復し得るものとする。この分類・列挙は確定済みの全資源分類ではない。
- 過剰利用によって資源の供給力・回復力が低下し得る。
- 資源量・供給力の変化は産業、エネルギー、食料、物流、経済、人口、政治、戦争等へ波及し得る。
- 資源ごとの詳細な地質・生態的再生過程を標準で最高詳細度まで扱うことは要求せず、より詳細な資源・地質・生態モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 資源ごとの再生可能・非再生等の分類
- 埋蔵量・利用可能量・供給力の状態表現
- 再生速度・回復条件の標準モデル
- 採掘技術と可採量の関係
- 過剰利用による劣化の扱い
- 新規資源発見等の扱い
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

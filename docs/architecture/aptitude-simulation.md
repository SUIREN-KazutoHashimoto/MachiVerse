# 才能・適性シミュレーション設計

## 1. 確定方針

標準では全住人の学習能力・分野別適性を完全に同一とせず、個人差を持たせる。

- 住人ごとに学習速度や分野別の適性等に差を持ち得る。
- 適性だけで職業・地位・成功・能力を決定しない。
- 実際の能力形成は教育、経験、訓練、健康、生活環境、社会的機会、利用可能な資源等と相互作用する。
- 技能・熟練、知識、職業、教育、身体能力等と接続する。
- 同じ適性を持つ住人でも異なる環境・経験によって異なる結果になり得る。
- 標準では非常に詳細な認知能力分類・身体能力分類・適性分類を固定的に最高詳細度まで持つことは要求しない。
- 人種等の固定的な集団分類から個人能力を機械的に決定するモデルにはしない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準適性カテゴリと粒度
- 個人差の生成・発達モデル
- 学習速度・技能形成への影響
- 年齢・健康・経験との関係
- 詳細領域外での簡略化

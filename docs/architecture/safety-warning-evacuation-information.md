# 安全標識・警報・避難情報シミュレーション設計

## 確定方針

標準では警報・避難指示が発生しただけで対象住人を自動的に避難状態へ移行させない。

- 標識、警報、放送、避難指示等は住人へ伝達される情報として扱う。
- 情報が実際に届くかは位置、知覚、通信手段、設備状態、環境等に依存し得る。
- 情報を受け取った後も、理解、信頼、危険認識、身体状態、家族・他者への配慮、利用可能な避難経路等によって行動が変化し得る。
- 情報が届かない、理解できない、信じない、避難を選ばない、避難したくてもできない場合があり得る。
- 情報・通信、知覚、危険認識、信頼、群衆、経路知識、災害、火災、救急・災害対応等と接続する。
- 標準では警報設備の詳細配置、サイレン到達の精密伝播、詳細な避難誘導計画等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な警報・避難情報伝達へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 警報・避難情報の標準状態
- 伝達範囲・知覚判定
- 警報発令主体と権限
- 避難行動への接続
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

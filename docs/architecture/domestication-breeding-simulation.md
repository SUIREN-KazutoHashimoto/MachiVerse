# 家畜化・品種改良シミュレーション設計

## 1. 確定方針

標準では家畜種・品種を世界生成時から固定された不変カテゴリとしてのみ扱わず、人間による世代をまたいだ選択・繁殖によって歴史的に形成・変化し得るものとする。

- 人間による選択的繁殖によって、行動、体格、生産性、外見その他の特徴が世代を通じて変化し得る。この列挙は確定済みの全形質ではない。
- 家畜化や品種的特徴は、人間社会の需要、利用目的、飼育環境、技術、文化等と接続する。
- 繁殖には実際の個体・世代交代を伴う方向とし、家畜・ペットの生命サイクルと接続する。
- 特徴の継承は既存の遺伝・世代モデルと整合させる。
- 同一種・同一品種であっても個体差を持ち得る。
- 標準では詳細な血統管理、遺伝評価、量的遺伝形質、精密な交配計画等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、これらをC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 遺伝・繁殖に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 家畜化進行の標準表現
- 遺伝・形質継承との接続
- 人間による繁殖選択の意思決定
- 品種概念の標準粒度
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

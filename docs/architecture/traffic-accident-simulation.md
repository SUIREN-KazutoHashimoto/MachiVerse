# 交通事故シミュレーション設計

## 確定方針

標準では交通事故を地域単位の抽象確率イベントだけとして扱わず、実際に移動している主体と交通環境から発生し得る事故として扱う。

- 車両、人、動物等の実際の位置・経路・移動状態を事故要因へ接続する。
- 速度、混雑、視界、天候、道路状態、技能、疲労、設備状態等が事故発生可能性へ影響し得る。この列挙は網羅ではない。
- 事故は住人・動物の負傷、車両・設備の損傷、積荷への影響、道路閉塞、渋滞、救急対応等につながり得る。
- Full-3D移動・衝突、交通物流、天候、知覚、車両状態、一般事故、救急等と整合させる。
- 標準では詳細な車両力学、衝突変形、乗員への精密な衝撃伝達等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な交通事故物理へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。
- 事故判定に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 移動・衝突モデルと事故判定の境界
- 速度等の事故影響粒度
- 事故後の通行状態・現場処理
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

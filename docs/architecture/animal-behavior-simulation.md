# 動物知覚・行動シミュレーション設計

## 1. 確定方針

標準では動物を固定経路と単純確率だけで移動させず、生存・繁殖等に必要な内部状態と周囲の知覚に基づいて行動させる。

- 空腹、危険、繁殖、群れ等の必要な内部状態を持ち得る。この列挙は確定済みの全内部状態ではない。
- 食料、捕食者、人間、環境等を必要な範囲で知覚し、行動選択へ反映する。
- 人間住人と同一の心理・価値観モデルをそのまま適用することは標準要件としない。
- 移動はフル3D空間・通行可能性・地形・水域等と接続する。
- 種によって行動傾向が異なり得る。
- 将来アドオンによって、種別の詳細行動学、記憶、群れ・縄張り・社会関係等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 行動選択に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準の内部状態
- 動物の標準知覚範囲・対象
- 種ごとの行動差の表現方法
- 群れ・縄張りを標準でどこまで扱うか
- 詳細領域外での行動簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

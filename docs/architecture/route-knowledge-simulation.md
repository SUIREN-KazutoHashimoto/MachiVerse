# 交通経路知識シミュレーション設計

## 確定方針

標準では全住人がCore上の道路・通路・交通網と常に最適な経路を知っているとはしない。

- Core上の実際の経路網と、住人が知っている経路情報を分離する。
- 未訪問地域、道路新設・閉鎖、工事、災害、交通網変更等によって住人の経路知識が不完全・古い場合がある。
- 不完全な知識によって遠回り、誤った経路選択、迷い等が起こり得る。
- 移動、地理知識・地図、情報伝達、交通、予定・到着時刻等と接続する。
- 新たな移動経験、地図、案内、他者からの情報等によって経路知識を更新し得る。
- 標準ではランドマーク記憶、方向感覚、詳細な道順学習等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な空間認知・経路学習へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 経路知識の標準表現
- 経路探索へ渡す既知ネットワークの構成方法
- 情報の陳腐化・更新方法
- 詳細領域外での簡略化
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

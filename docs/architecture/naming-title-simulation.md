# 名前・姓・称号・呼称シミュレーション設計

## 1. 確定方針

標準では住人へ世界生成時に固定ランダム名を割り当てるだけとせず、名前・姓・称号・呼称を文化・言語・家族・身分・組織・時代等と接続する。

- 名前、姓、称号、呼称等が存在し得る。この列挙は確定済みの全呼称体系ではない。
- 命名は文化、言語、家族、地域、宗教、身分、組織等の影響を受け得る。
- 結婚、養子、地位変化、組織加入、改名等によって名前・姓・称号・呼称が変化し得る方向とする。
- 同一人物が相手・状況・制度によって異なる呼称で認識される場合を許容する。
- 大量に用意した固有名詞プールを決定論的に利用できる設計と整合させる。
- 標準では言語ごとの詳細な命名文法、語源変化、音韻変化等をC相当の最高詳細度まで必須としない。
- 名前割当等に確率的要素を含む場合もWorld Seed・World Time等に基づく決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 名前・姓・称号・呼称の標準データ表現
- 固有名詞プールの構造とカテゴリ
- 命名・改名・呼称選択の規則
- 同名人物の識別方法
- 言語・文化シミュレーションとの接続

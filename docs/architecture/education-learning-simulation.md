# 教育・学習シミュレーション設計

## 1. 確定方針

標準では、教育・学習を単純な知識値加算だけで処理せず、複数の学習経路と世界状態を接続する。

- 家庭、徒弟、学校、組織内教育、自学等の複数経路から学習できる方向とする。この列挙は確定済みの全経路一覧ではない。
- 教師、施設、教材、学習時間、費用、本人の状態等が学習へ影響できるものとする。具体的な影響要因・式は今後定義する。
- `technology-simulation.md` の個人単位の知識・技能と接続する。
- 知識を得たことだけで特定職業に就くとは決めつけず、既存の職業方針を維持する。
- 教育制度は組織、経済、文化、政治、技術等と接続し、歴史的に変化し得る。
- 教科・カリキュラム・試験・資格制度を常に詳細シミュレーションすることは標準要件とせず、詳細化は将来アドオンで拡張できる余地を持たせる。
- ランダム性を伴う場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 学習対象・知識・技能の具体的構造
- 習得速度、忘却、熟練のモデル
- 教師・教材・施設の影響粒度
- 教育機会と費用・階層・地域差の関係
- 資格等を標準でどこまで扱うか
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 消費行動・商品選択シミュレーション設計

## 1. 確定方針

標準では消費を必需品カテゴリの自動消費に限定せず、住人が具体的な商品・サービスと購入先を比較・選択する比較的詳細なモデルを持つ。

- 価格、所得、必要性、品質、評判、嗜好、距離、在庫等が商品・購入先の選択へ影響し得る。この列挙は確定済みの全要因ではない。
- ブランドや提供主体に対する継続的な選好・忠誠が形成・変化し得るものとする。
- 広告・宣伝や情報・評判が商品認識と選択へ影響し得る。
- 住人は複数候補を比較し得るが、常に完全情報・完全合理的な最適選択をするとは仮定しない。
- 衝動的・非計画的な購買等も、住人の心理・状況と接続して起こり得る方向とする。
- 商品選択は市場・価格、企業、在庫、物流、日常行動、評判・信頼、情報伝播等と接続する。
- C相当の比較的深い消費者行動を標準範囲とするが、無制限な心理学的・マーケティング的詳細化までは要求しない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 商品候補の認知・探索方法
- 品質・嗜好・ブランドの状態表現
- 比較・購入意思決定の具体モデル
- 広告効果と評判の境界
- 代替品・補完品の扱い
- サービス消費の扱い
- 衝動買い等の非計画行動の粒度
- 事前歴史・詳細領域外での簡略化

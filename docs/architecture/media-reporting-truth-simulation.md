# 報道内容と真実の分離シミュレーション設計

## 1. 確定方針

標準では報道内容がSimulation Core上の真実と自動的に一致するとは仮定しない。

- Core上で実際に発生した事実と、メディア・住人・組織が認識している情報を明確に分離する。
- メディアは自身が取得できた情報を基に報道するため、情報不足、誤認、誤報、偏り、意図的な編集等によって真実と異なる内容が広がり得る。
- 情報を受信した住人が、その内容を真実として信じるとは限らない。
- 情報源、既存の信頼、他の情報との整合等が受容に影響し得る。
- 広告・説得、情報操作、世論、評判・信頼、政治、犯罪、戦争等と接続する。
- 標準では記事文章そのものや全主張を詳細な自然言語単位で生成・追跡するC相当を必須としない。
- 将来アドオンによって、記事・主張単位の詳細な内容生成・追跡等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 誤り・編集等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 報道内容の標準表現
- Core上の事実との参照関係
- 誤報・偏り・編集の発生モデル
- 訂正・更新・反論をどこまで扱うか
- 受信者の信念更新との接続
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 危険認識・回避シミュレーション設計

## 確定方針

標準ではCoreが把握する客観的な危険度を住人が常に正確に知り、自動的に最適回避するとはしない。

- 住人は知覚、経験、記憶、教育、他者・組織からの情報等を通じて危険を認識し得る。
- 危険を知らない、知覚できない、見落とす、誤解する、過小評価・過大評価する場合がある。
- 認識した危険に対しても、目標、義務、恐怖、他者への配慮、利用可能な経路・資源等によって異なる行動を取り得る。
- 危険認識は避難、移動、労働、消費、災害対応、事故回避等へ影響し得る。
- 知覚、情報・証拠、記憶、感情、ストレス、個人目標、地理・経路知識等と接続する。
- 標準では特定の詳細なリスク認知心理理論をC相当まで必須としない。
- 判断に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 客観的危険と主観的認識の標準表現
- 危険情報の更新・忘却
- 回避行動選択への接続

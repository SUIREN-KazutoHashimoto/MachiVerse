# 乱数・ID・数値決定論設計

## 確定方針

第205〜209問は C / C / C / B / C を採用する。後続のQ252およびQ266で、診断範囲と未来Entity IDの意味を補足・具体化する。

### 決定論的乱数

- World SeedとWorld Timeを乱数生成の基礎入力とする。
- 乱数は対象・用途・イベント等の決定論的な論理コンテキストに結び付ける。
- システム、Entity、イベント等の論理コンテキストごとに乱数ストリームを分離可能な設計とする。
- 共有状態型PRNGをスレッドや呼び出し順で順次消費し、その消費順が世界結果を変える設計を禁止する。
- 無関係な場所で乱数利用を追加しても、論理的に無関係な結果へ乱数列のずれが波及しないことを標準要件とする。
- OS時刻、壁時計、スレッドID、タスク完了順、非決定論的呼び出し回数を世界乱数のエントロピーとして使用しない。
- 同一World Timeで同種の独立した乱数抽選が複数必要な場合の識別コンテキスト構成は今後決定する。

### 永続Entity ID

- 保存・再開・リプレイを通じて同一Entityを識別できる永続IDを持たせる。
- メモリアドレス、スレッドID、実行時の非決定論的生成順を永続IDの意味として使用しない。
- 並列に生成されるEntityでも、同一の再現条件ならID割当結果がスレッド実行順・完了順に依存しないことを標準要件とする。
- Q266により、未来に出生・生成されるすべてのEntity IDを世界生成時に事前列挙・予約する必要はない。
- 未来EntityのIDは、出生・生成事象を一意に識別する決定論的な論理コンテキストから生成可能とする。
- 同一World Seed、同一のシミュレーション影響Config、同一Operation集合・順序・適用時刻および同一の因果的生成事象からは、同じEntity IDが得られなければならない。
- IDの具体的形式、ビット幅、階層性、生成アルゴリズムは現時点では固定しない。

### 並列集約

- 世界結果へ影響する合計、平均、最小最大、競合選択その他の集約は決定論的な順序または決定論的に同値な方式で行う。
- スレッド終了順やタスク完了順を集約順として使用しない。
- Coreの実行スレッド数をConfigで1〜16の範囲で変更しても、World Seed、シミュレーション影響Config、操作集合・順序・適用時刻等の再現条件が同一なら世界結果を変化させない。
- 並列化方式の具体的APIや実装機構は固定しない。

### 浮動小数点・プラットフォーム差

- 対応対象となる環境間でも可能な限り再現性を維持する。
- ただし現時点では、異なるCPU、OS、ランタイム等をまたぐ全浮動小数演算についてビット単位の完全一致を標準要件とはしない。
- この判断は論理的な決定論要件を弱めるものではない。処理順、乱数、ID、競合解決等の制御可能な非決定論は排除する。
- 対応プラットフォーム範囲と数値再現性の保証境界は今後決定する。
- 将来、必要性と実現可能性が確認された場合に、より強い数値再現性へ拡張することを妨げない。

### 決定論違反の検出

Q209で決定論違反を自動検出可能にする方針を採用し、Q252で標準範囲を次のように明確化する。

- 開発・テストでは同一再現条件を複数回実行し、世界状態の一致を自動検証できることを標準要件とする。
- 標準機能では、定期的または検証時にWorld State等の整合性ハッシュまたは同等の検証情報を比較し、不一致を検出可能にする。
- 状態ハッシュ診断そのものが世界状態やシミュレーション結果へ影響してはならない。
- **標準機能では、不一致箇所の詳細な自動局所化や、Operation履歴・Config・World Timeとの高度な相関解析までは必須としない。**
- これらの高度な決定論診断は将来アドオンで拡張可能とする。
- ハッシュアルゴリズム、保持期間、検証粒度、常時有効か検証時のみか等は今後決定する。

## 保存・リプレイとの関係

- 保存された世界を同じ再現条件から再開した場合、乱数コンテキスト、Entity ID、決定論的集約規則を維持する。
- リプレイはスレッドスケジューリングや実行速度を記録して再現する方式へ依存しない。
- シミュレーション影響Configは再現条件として扱う。
- 保存・復旧後も同一の因果的生成事象へ別IDを再割当てしてはならない。

## 今後決定が必要な事項

- 乱数コンテキストの具体的構成
- 乱数生成アルゴリズム
- Entity IDの形式と生成規則
- 決定論的集約方式
- 対応プラットフォームと数値再現性保証範囲
- 状態ハッシュ／検証情報の粒度とアルゴリズム
- 大規模世界での決定論検証コストの制御方法
- 高度な決定論診断アドオンの具体仕様

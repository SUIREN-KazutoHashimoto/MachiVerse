# 建設工程シミュレーション設計

## 1. 確定方針

標準では建設を資金・材料・時間の条件成立後に完成物が即時出現する処理として扱わず、複数工程を持つ実際の活動として扱う。

- 建設は整地、基礎、躯体、設備、仕上げ等の複数工程を持ち得る。この列挙は確定済みの全工程ではなく、対象構造物や技術によって異なり得る。
- 各工程には労働者、材料、道具・機械、設備、搬入、技術、時間等が関与し得る。
- 天候、資材不足、設備故障、人員不足等によって進捗が変化・停止し得る。
- 住人の物理的作業要件に従い、必要な作業では住人が実際の作業場所へ到達し、必要な物品・設備へアクセスできることを前提とする。
- 建設は物品運搬、物流、製造、企業、契約、土地・権利、地形改変等と接続する。
- 実際の建築・土木工学を最高詳細度まで完全再現することは標準要件としない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準工程の表現方法と粒度
- 工程間の依存関係
- 材料・設備・労働投入から進捗への影響
- 天候・事故・故障等による中断モデル
- 道路・建物・地下構造物等での工程差
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

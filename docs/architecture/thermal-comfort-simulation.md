# 体温・暑熱寒冷シミュレーション設計

## 1. 確定方針

標準では外気温から健康・活動へ直接補正するだけでなく、住人の暑熱・寒冷状態を世界状態と接続する。

- 住人に暑さ・寒さへの生理的状態を持たせられるものとする。
- 気温、風、雨雪、衣服、建物、暖房・冷房、活動等がその状態へ影響し得る。この列挙は確定済みの全要因ではない。
- 暑熱・寒冷状態は健康、疲労、睡眠、行動、作業能力等へ影響し得る。
- 天候、衣服・装備、建物内部、エネルギー、健康等と相互作用する。
- 詳細な人体熱収支、発汗、湿度影響、素材ごとの熱伝導等を標準で最高詳細度まで扱うことは要求せず、より詳細な温熱生理モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 暑熱・寒冷状態の標準表現
- 気温・風・雨雪等からの影響モデル
- 衣服・建物・暖冷房の効果
- 年齢・健康等による個人差
- 熱中症・低体温症等との接続
- 室内外の温熱状態の粒度
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

# 物品の発見・探索シミュレーション設計

## 確定方針

標準では所有している物品であっても、住人が常に現在位置を正確に知っているとはしない。

- Core上の実際の物品位置と、住人が記憶・認識している位置を分離する。
- 置き忘れ、他者による移動、盗難、記憶の陳腐化等によって「存在するが見つけられない」状態が起こり得る。
- 必要な物品を見つけられない場合、住人は探索に時間を使い得る。
- 物品位置、住人記憶、知覚、所有・占有、盗難、日常活動、物理作業等と接続する。
- 標準では部屋内を視線単位で走査する詳細な視覚探索や探索順序をC相当まで必須としない。
- 探索に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 物品位置記憶の標準粒度
- 探索開始・終了条件
- 知覚可能範囲と探索結果の接続
- 集約された物品の探索表現

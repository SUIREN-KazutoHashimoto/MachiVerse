# 物品・製品シミュレーション設計

## 1. 確定方針

標準では、物品・製品をすべて常時個体Entityとして追跡するのではなく、種類と数量を基本としつつ、必要な場面では在庫・輸送・所有・使用に必要な単位まで追跡できるものとする。

- 同種・同質の大量物品は数量としてまとめて扱える。
- 在庫、輸送、販売、保管、消費等で必要な範囲ではロット・単位等を区別できる方向とする。ただし具体的単位は未確定とする。
- 自動車、機械、武器等を標準ですべて必ず個体追跡することは要求しない。
- 一方、個別性が世界の因果へ重要な物品について、必要に応じて個体として扱える余地を持たせる。
- 物品は生産、企業、市場、所有・権利、物流、住人の日常行動、軍事、建物等と接続する。
- 製造・移動・使用・故障等の履歴をどの物品まで保持するかは今後定義する。
- より詳細な個体追跡・製品構成・耐久・部品モデル等は将来アドオンで拡張できる余地を持たせる。
- ランダム性を伴う場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 数量管理と個体管理の切替基準
- ロット・在庫単位の表現
- 品質・状態・耐久等を標準でどこまで扱うか
- 所有・占有・利用との接続
- 製造履歴・流通履歴の保持範囲
- 故障・修理・廃棄の標準粒度
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

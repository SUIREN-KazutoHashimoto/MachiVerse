# インフラのネットワーク依存シミュレーション設計

## 確定方針

標準では個々のインフラ施設が正常であれば、それだけで孤立して完全に機能するとはしない。

- 水道、電力、通信、交通等は必要に応じてネットワークとして接続される。この列挙は網羅ではない。
- 上流設備、供給源、接続経路、中継設備等の故障・容量不足・破壊によって、離れた場所へ障害が波及し得る。
- 局所的な設備が正常でも、必要な上流供給や経路が失われればサービスが低下・停止し得る。
- ネットワーク障害は住民生活、企業、医療、通信、物流、消防、上下水道等へ二次的・連鎖的な影響を与え得る。
- 電力・通信、水・衛生、交通、保守・故障、災害、戦争等の各既存システムと横断的に接続する。
- 標準では各インフラについて高度なネットワーク工学モデルをC相当まで必須としない。
- 将来アドオンで各インフラをC相当の詳細モデルへ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 共通して必要なネットワーク状態の抽象度
- 各インフラ固有モデルとの責務境界
- 容量不足・障害伝播の標準粒度
- 復旧・迂回・代替供給との接続
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 建物内部シミュレーション設計

## 1. 確定方針

標準では建物内部もフル3D世界の一部として比較的実体的に扱い、住人が実際に内部を移動・利用できる方向とする。

- 室内空間は権威あるフル3D世界状態と整合させる。
- 部屋、扉、家具、設備等を住人が実際に利用・移動できる方向とする。この列挙は確定済みの全内部要素一覧ではない。
- 建物内部は用途、収容、生活、業務、生産、教育、行政、医療その他の活動と接続できるものとする。
- 世界規模で全建物内部を常時最高詳細度にシミュレーションすることは要求せず、必要に応じた詳細度制御・簡略化を前提とする。
- Diverが建物内部でも世界の一住人として行動できる設計を目指す。
- 建物外部・内部の移動、所有・利用権、物品、日常行動、職業、組織等と接続する。
- 建築構造、家具、小物、設備、配管等をどこまで標準で詳細化するかは今後定義する。
- より高度・特殊・詳細な建築・設備・室内シミュレーションは将来アドオンで拡張できる余地を持たせる。
- ランダム性を伴う場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 室内空間の表現方式
- 部屋・扉・階段・通路等の標準要素
- 家具・設備の標準粒度
- 建物内部経路探索の方式
- 収容能力・利用制約のモデル
- 建物用途と内部構造の関係
- 破損・火災・災害時の内部状態
- 詳細領域外・未訪問建物内部の簡略化
- 事前歴史生成時の内部生成範囲
- 標準と将来アドオンの境界

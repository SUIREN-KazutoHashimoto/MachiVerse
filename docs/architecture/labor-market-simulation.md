# 労働市場シミュレーション設計

## 確定方針

標準では空いている仕事へ住人を自動割当せず、求職と求人の相互作用から雇用を成立させる。

- 住人は仕事を探し、企業・組織等は必要に応じて求人する。
- 技能・知識、賃金、勤務地、評判、労働条件、本人の希望等がマッチングへ影響し得る。この列挙は網羅ではない。
- 失業、人手不足、転職、採用難等が世界状態から自然に発生し得る。
- 職業、技能・熟練、雇用関係、企業、教育、移住、交通、評判等と接続する。
- 標準では求人媒体、応募書類、面接、複数段階選考等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な採用過程へ拡張できる余地を持たせる。
- マッチングに確率的要素を含む場合もWorld Seed・World Time等に基づく決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 求職・求人状態の標準表現
- 候補探索範囲と情報取得
- マッチング・採否の決定方法
- 詳細領域外での簡略化
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

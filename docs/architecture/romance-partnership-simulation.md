# 恋愛・パートナー関係シミュレーション設計

## 1. 確定方針

標準では、家族形成を単純なマッチング処理だけにせず、住人同士の関係と生活条件から関係が形成・変化し得るものとする。

- 出会い、人間関係、相性、価値観、生活状況、社会・文化等が関係形成へ影響し得る。
- 交際、同居、結婚、別離等につながり得る方向とする。この列挙は確定済みの全関係状態ではない。
- 特定の結婚制度・家族制度を世界共通の固定ルールとして強制しない。
- 既存の家族・世代、人間関係、住居、経済、文化、宗教、社会制度等と接続する。
- 関係は固定ではなく、時間・経験・環境・他者との関係によって変化し得る。
- 非常に細かな恋愛心理等を標準で無制限に深く扱うことは要求せず、より詳細な関係モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 関係形成・維持・解消の状態表現
- 相性・価値観・生活条件等の具体的影響
- 同居・婚姻制度と文化・法の接続
- 出生・家族形成との具体的接続
- 複数のパートナー関係等を標準でどこまで扱うか
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 家畜・ペットシミュレーション設計

## 1. 確定方針

標準では家畜を農場の生産能力だけ、ペットを住人の属性だけとして扱わず、必要な生物実体として世界に存在させる。

- 家畜・ペットは所有・管理対象となり得る実際の生物として存在し、飼育、給餌、繁殖、病気、死亡、移動等の状態・過程を持つ。
- 所有・権利、農業・食料、住人の日常活動、健康・感染症、物流等と接続する。
- 家畜・ペットは必要に応じて個体として3D空間を移動・利用できるものとする。
- 飼育環境、食料、水、健康等が生存・生産等へ影響し得る。
- 標準では全個体について詳細な性格、訓練、血統、行動学等を最高詳細度まで扱うことは要求しない。
- 将来アドオンによって、個体ごとの詳細な性格・訓練・血統・行動学等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 家畜・ペットの標準個体状態
- 所有・飼育関係の表現
- 給餌・水・飼育設備との接続
- 生産物・繁殖・健康の標準モデル
- 野生化・譲渡等をどこまで扱うか
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 住人の日常行動シミュレーション設計

## 1. 確定方針

標準では、住人の日常行動を大きな時間ブロックだけに抽象化せず、比較的細かい生活行動まで個別にシミュレーションする。

- 仕事、睡眠、食事、買物、余暇、家事、人間関係上の行動等を住人の意思決定対象として扱える方向とする。この列挙は確定済みの全行動一覧ではない。
- 住人は必要、予定、職業、人間関係、距離、交通手段、資金、健康、天候、情報、文化等の世界状態から行動を選択し、実際に世界内を移動・滞在・利用できるものとする。
- 食事一回や商品の選択、細かな余暇、家事等も標準で比較的深く扱う方向とするが、一挙手一投足や身体動作の逐次物理再現までは要求しない。
- 行動は建物内部、交通、所有物、企業・市場、情報、人間関係、健康等と接続する。
- Diverも世界の外部操作主体ではなく、同じ世界状態と因果の中に存在する住人として扱える方向を維持する。
- 詳細度は性能と両立させ、詳細領域外・多数住人・事前歴史等では因果と決定論を維持した簡略化を可能とする。
- ランダム性を伴う場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準日常行動カテゴリ
- 行動選択・予定・習慣の具体モデル
- 行動時間粒度
- 食事・買物・余暇・家事等の標準詳細度
- 移動と活動場所選択の接続
- 同時行動・複数目的の扱い
- 睡眠・疲労・健康との関係
- 詳細領域外・事前歴史での簡略化
- 標準と将来アドオンの境界

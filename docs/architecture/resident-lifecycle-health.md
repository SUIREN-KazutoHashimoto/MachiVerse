# 住人の生死・身体・健康シミュレーション設計

## 1. 目的

本書は、MachiVerse における住人の出生、成長、加齢、健康、負傷、疾病、回復、障害、死亡等に関する要件を整理します。

## 2. 確定事項

- 住人には出生、成長、加齢、負傷、病気、回復、障害、死亡等のライフサイクル・身体状態を持たせる。
- 栄養、睡眠、衛生、環境、労働、戦争その他の世界状態が健康へ影響できる設計とする。
- 健康状態は住人の行動、労働、移動、生活、家族、経済その他へ影響できるものとする。
- 標準では比較的深く扱うが、臓器・細胞・分子レベルまで常時詳細シミュレーションすることは要求しない。
- より高度・専門的な医療、生理、疾病モデル等は将来アドオンで拡張できる余地を持たせる。
- 健康・疾病・回復・死亡等に確率的要素を含める場合も、MachiVerse の決定論・完全再現性の原則に従う。

## 3. 世界との因果接続

住人の健康を独立した単一数値だけで扱うことを標準とはせず、食料・栄養、住環境、衛生、労働負荷、気候・環境、事故、戦争等と接続できる設計を目指します。

一方で、具体的な身体部位、疾病分類、症状、治療、医療行為等の標準粒度は今後定義します。

## 4. 標準モデルとアドオン

標準では、住人の一生と世界の因果関係を成立させるために必要な身体・健康状態を比較的深く扱います。ただし、生物医学的な全階層を完全再現することは標準要件としません。

より詳細な生理学、医療、疾病、障害、治療等は将来アドオンで拡張できる余地を持たせます。具体的なアドオンAPI等は現時点では確定しません。

## 5. 今後決定が必要な事項

- 年齢・成長段階の具体モデル
- 身体状態・健康状態の標準粒度
- 疾病・負傷・障害の標準カテゴリ
- 栄養・睡眠・衛生・環境・労働等との具体的な接続
- 医療・治療・回復の標準粒度
- 出生・死亡条件の具体モデル
- 事前歴史シミュレーションでの簡略化範囲
- 詳細シミュレーション領域外での簡略化範囲

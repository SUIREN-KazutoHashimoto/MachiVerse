# 住人の記憶シミュレーション設計

## 1. 確定方針

標準では、住人が現在の知識・関係だけを持つのではなく、重要な個人的経験を記憶として保持できるものとする。

- 住人は、自身にとって意味のある出来事・経験を記憶として保持できる方向とする。
- 記憶は時間経過等によって忘却・弱化し得る。
- 記憶は感情、信頼、人間関係、意思決定、情報の解釈等へ影響し得る。
- 世界の真の履歴、住人が知っている情報、住人が信じている内容、住人自身の記憶を必要に応じて区別できる設計とする。
- 全30Hz状態や人生中の全出来事を個人ごとに永久保存することは標準要件としない。
- 非常に詳細なエピソード記憶、連想、記憶変容等を標準で無制限に深く扱うことは要求せず、より詳細な認知・記憶モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 記憶対象となる出来事の選別方法
- 記憶の強度・重要度等の状態表現
- 忘却・想起のモデル
- 感情・信頼・評判・意思決定との接続
- 情報・知識・信念との境界
- 死亡後・世代間で記憶そのものをどこまで継承しないか
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

# 群衆・混雑シミュレーション設計

## 1. 確定方針

標準では多数の住人が同一空間を利用しても互いの移動へ影響しないとは仮定せず、空間容量と混雑を移動・活動へ反映する。

- 道路、歩道、駅、建物、通路、出入口等へ住人が集中すると、移動速度低下、滞留、通行困難等が起こり得る。
- Full-3Dの物理移動・衝突・占有モデルと整合させる。
- 建物内部、扉・門、交通施設、社会イベント、避難等のボトルネックへ影響する。
- 混雑を認識した住人が経路・時刻・目的地等を変更し得る方向とする。
- 標準では詳細な群集流体モデル、身体圧力、群集事故力学等をC相当の最高詳細度まで必須としない。
- 必要な数値パラメータはConfig化する。
- 状態更新に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 混雑・空間容量の標準表現
- 移動速度・経路選択への影響
- 車両混雑と歩行者混雑の境界
- 避難・イベントとの接続
- 詳細領域外での簡略化

# 外交シミュレーション設計

## 1. 確定方針

標準では外交を国家間の単一の友好度・敵対度だけに限定せず、政治・組織・経済・軍事等と接続した関係として扱う。

- 条約、交渉、同盟、貿易関係、領土問題、外交使節等を表現できる方向とする。この列挙は確定済みの全外交要素ではない。
- 国家・統治組織その他の関係主体による意思決定から外交関係が変化し得るものとする。
- 外交は政治・統治、軍事・戦争、経済・市場、資源、交通・物流、情報等と相互作用できるものとする。
- 外交関係を固定パラメータとせず、歴史的な出来事・利害・関係の結果として形成・変化し得る方向とする。
- 条約条文、国際法、外交儀礼等を標準で無制限に詳細化することは要求せず、より詳細・特殊な外交制度は将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 外交主体の具体的範囲
- 条約・同盟等の標準類型と状態表現
- 交渉・要求・譲歩等の意思決定モデル
- 領土・主権・承認等との関係
- 貿易・制裁等を標準でどこまで扱うか
- 宣戦・停戦・講和等と軍事モデルの境界
- 情報・認識差が外交へ与える影響
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

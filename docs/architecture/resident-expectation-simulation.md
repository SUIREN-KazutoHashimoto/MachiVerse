# 住人の将来予想・期待シミュレーション設計

## 確定方針

標準では住人が現在状態だけで意思決定するとはせず、入手した情報や経験から不完全な将来期待を持ち得る。

- 将来の価格、収入、危険、天候、雇用等について期待・予想を形成し得る。この列挙は網羅ではない。
- 期待は過去の経験、現在の知識・情報、記憶、信頼する情報源等から形成され、Core上の未来を正確に知るものではない。
- 期待は貯蓄、投資、移住、購買、就業、避難その他の行動へ影響し得る。
- 新情報や予想外の出来事によって期待は更新され得る。
- 住人ごとに同じ情報から異なる期待を持ち得る。
- 標準では詳細な確率分布、予測アルゴリズム、予測精度学習等をC相当まで必須としない。
- 期待形成に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 期待状態の標準粒度
- 記憶・情報・性格との接続
- 期待更新の条件
- 長期目標・計画との関係

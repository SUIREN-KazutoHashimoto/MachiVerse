# 事故・損害の責任シミュレーション設計

## 確定方針

標準では事故・破損・負傷等の損害が発生した際に、原因主体との社会的・制度的関係を消去しない。

- 社会・時代の法、慣習、契約等に応じて責任、賠償、保険請求、処罰、紛争等が発生し得る。この列挙は網羅ではない。
- Core上の物理的・歴史的な原因関係と、社会制度上で認定される責任を区別する。
- 証拠、情報、記録、信頼、司法制度等によって責任認定が実際の原因と一致しない場合もあり得る。
- 保険、契約、犯罪・司法、財産権、企業、事故、評判・信頼等と接続する。
- 現代的な民事責任法を全社会・全時代へ普遍的に適用しない。
- 標準では詳細な民事責任法、過失割合、訴訟手続等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な責任・損害紛争制度へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 損害事象と責任主張の標準表現
- 賠償・保険・司法への接続
- 原因関係と制度上の認定の分離方法
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

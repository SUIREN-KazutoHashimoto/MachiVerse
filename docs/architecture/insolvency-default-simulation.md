# 債務不履行・破産シミュレーション設計

## 1. 確定方針

標準では支払い不能時に債務を単純消去せず、債務不履行とその社会・経済的結果を世界状態として扱う。

- 住人、企業、組織等が債務を履行できない場合、支払い遅延、契約違反、資産処分、信用低下、事業停止等が生じ得る。この列挙は確定済みの全結果ではない。
- 債務不履行の処理は社会・時代の法、慣習、制度、契約等によって異なり得る。
- 資産処分を行う場合は所有・権利および実際の世界資産と接続する。
- 信用・債務、契約、企業、家計、財産、司法、評判・信頼等と接続する。
- 債務不履行が債権者側の資金繰りや他の契約へ波及し得る。
- 標準では詳細な倒産法、債権順位、再建・清算手続等をC相当の最高詳細度まで固定的に必須としない。
- 将来アドオンによって、詳細な倒産法・債権順位・再建・清算手続等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 処理に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 支払い不能・債務不履行の標準状態
- 債権者・債務者への波及
- 資産処分と所有権移転
- 信用・評判への影響
- 社会・時代ごとの制度差
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

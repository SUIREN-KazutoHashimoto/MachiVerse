# 時刻・暦・予定シミュレーション設計

## 1. 確定方針

標準ではSimulation Coreの物理的な世界時間と、社会が利用する暦・時刻・予定を同一概念として固定しない。

- 世界のシミュレーション時間進行を権威ある時間基準として持つ。
- 社会・時代に応じて暦、曜日、祝祭日、勤務時間、予定等を表現できる方向とする。
- 社会的な時間制度は住人の日常行動、仕事、教育、商業、宗教・文化、組織活動等へ影響し得る。
- 異なる社会が異なる暦・時間制度を利用する可能性を排除しない。
- 暦・予定等は歴史・文化・政治・宗教・技術等によって変化し得るものとする。
- 複数暦法の詳細な歴史的変遷、詳細な時刻制度、タイムゾーン等を標準で最高詳細度まで扱うことは要求せず、より詳細な時間制度は将来アドオンで拡張できる余地を持たせる。
- 世界時間に基づく全ての確率的処理は既存の決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- Simulation Core内部の世界時間表現
- 日・季節・年等と自然現象の関係
- 標準の暦・時刻制度の抽象度
- 予定・勤務時間等の状態表現
- 複数社会間の時刻・暦変換
- General Viewでの時間表示との境界
- 事前歴史での時間制度変化
- 標準と将来アドオンの境界

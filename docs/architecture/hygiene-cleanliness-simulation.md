# 衛生・清潔シミュレーション設計

## 1. 確定方針

標準では衛生を地域単位の単一指標だけにせず、住人・住居・水・廃棄物等と接続する。

- 住人や住居等に衛生・清潔に関わる状態を持たせられるものとする。
- 水、入浴・洗浄、排泄、廃棄物、人口密度等が衛生状態へ影響し得る。この列挙は確定済みの全要因ではない。
- 衛生状態は健康、感染症、社会行動等へ影響し得る。
- 上下水道、住居・建物内部、廃棄物、医療、日常行動等と相互作用する。
- 衛生に関する行動・基準は社会・文化・技術・利用可能資源によって異なり得るものとする。
- 衣類・部屋・物品ごとの詳細な汚染や病原体付着を常時追跡することは標準で要求せず、より詳細な衛生・感染媒体モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 住人・住居等の衛生状態の標準表現
- 入浴・洗浄・排泄等の行動粒度
- 水量・水質との具体的接続
- 廃棄物・下水との接続
- 感染症リスクへの影響モデル
- 文化・技術差の表現
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

# 住所・場所の社会的識別シミュレーション設計

## 1. 確定方針

標準では場所をSimulation Core上の座標だけで社会的に識別するとはせず、社会・時代に応じた地名・住所・所在地情報を扱う。

- 地名、道路名、番地、建物名、地区名等の場所識別体系が形成・変更され得る。この列挙は確定済みの全体系ではない。
- 住人・組織・施設等は、社会的に認識される住所・所在地情報を持ち得る。
- 地理知識・地図、郵便・通信、公的記録、行政区域、移住、企業活動等と接続する。
- 社会的な住所情報とCore上の実際の位置は別概念として扱い、古い住所、誤認、名称変更等による不一致が起こり得る。
- 現代的な道路住所や郵便番号体系を普遍的前提としない。
- 標準では詳細な住所体系生成、郵便番号、行政住所変更履歴等をC相当の最高詳細度まで必須としない。
- 状態更新に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 地名・住所の標準表現
- 実座標・地理知識・公的記録との関係
- 名称変更・境界変更時の扱い
- 住所不明・誤認・旧住所の扱い
- 郵便・物流・通信との接続
- 詳細領域外での簡略化

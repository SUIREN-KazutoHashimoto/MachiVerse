# 国境・検問シミュレーション設計

## 確定方針

標準では法的な国境線を越えた瞬間にSimulation Coreが自動的に通行可否を強制するとはしない。

- 法的・制度的な国境や領域と、実際の監視・検問・取締能力を分離する。
- 検問所、人員、施設、道路、地形、通信、情報等によって越境の監視可能性が変化し得る。
- 監視されていない場所や能力が不足した場所では、許可されていない越境も物理的に可能になり得る。
- 通行許可、身分・公的記録、移住、領域、外交、治安、軍事、密輸等と接続する。
- 社会・時代によって国境制度は異なり得るため、現代的な入国管理制度を普遍的前提としない。
- 標準では詳細な入国審査、税関検査、検問手順等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な国境・税関運用へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 検問所・監視範囲の標準状態
- 越境許可と実際の通過判定の接続
- 非公式経路の扱い
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

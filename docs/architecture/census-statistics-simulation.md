# 国勢調査・統計シミュレーション設計

## 確定方針

標準では国家・行政・組織がSimulation Coreの人口・経済・社会状態を即座かつ完全に取得できるとはしない。

- 国勢調査、届出、行政記録、各種調査等を通じて統計情報を形成し得る。この列挙は網羅ではない。
- 調査能力、人員、制度、交通、通信、記録品質、対象者の協力等によって欠落、遅延、誤差が生じ得る。
- Core上の真の世界状態と、組織が把握・集計した統計を分離する。
- 統計は行政、財政、政策、企業活動、研究、報道等の判断材料になり得る。
- 公的記録、情報・通信、地理的支配能力、人口統計、行政組織等と接続する。
- 標準では標本調査、推計手法、詳細な統計機関運営等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な統計調査・推計へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 統計情報の標準状態と粒度
- 調査・集計の更新周期
- 欠落・誤差・改訂の表現
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 動物疾病・人獣共通感染症シミュレーション設計

## 1. 確定方針

標準では感染症を人間だけの現象に限定せず、野生動物・家畜・ペット等にも疾病が存在し得るものとする。

- 動物間で感染が成立し得る。
- 接触、飼育、移動、環境その他の条件によって伝播し得る。この列挙は確定済みの全伝播経路ではない。
- 条件によっては動物と人間の間でも感染し得る。
- 動物疾病は個体・個体群の健康、繁殖、死亡、移動、畜産、生態系等へ影響し得る。
- 人間側の感染症シミュレーション、医療、衛生、家畜、野生動物、食料、生態系等と接続する。
- 社会・技術に応じて隔離、治療、予防、家畜管理等の対応が行われ得る。
- 標準では獣医学的な詳細疾病分類、動物種ごとの高度な免疫モデル、病原体生態等をC相当の最高詳細度まで必須としない。
- 感染・発症等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 動物疾病の標準状態表現
- 種間感染の標準モデル
- 人獣共通感染の成立条件
- 家畜管理・野生動物・人間感染症との接続
- 詳細領域外での簡略化

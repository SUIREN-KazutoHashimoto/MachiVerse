# 解体・撤去シミュレーション設計

## 1. 確定方針

標準では建物・設備等を解体指示によって即時消去せず、資源と作業を必要とする物理的過程として扱う。

- 解体・撤去には労働、道具・機械、時間等が必要となり得る。
- 解体途中の構造状態を世界状態として保持し、通行、安全、周辺利用等へ影響させる方向とする。
- 解体によって廃材、再利用可能な資材、廃棄物等が発生し得る。
- 発生物は物品・在庫・運搬・廃棄物・資源利用等の既存モデルと接続する。
- 建物・構造物の損傷、廃墟、土地利用、建設工程、住人の物理的作業等と接続する。
- 部材ごとの詳細な解体順序、詳細な分別・再資源化、危険物処理等を標準で最高詳細度まで固定的に扱うことは要求せず、より詳細な解体モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 解体工程の標準粒度
- 解体進捗から3D構造状態への反映
- 廃材・再利用可能資材・廃棄物の分類
- 解体時の事故・環境影響
- 所有権・契約・行政制度との接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

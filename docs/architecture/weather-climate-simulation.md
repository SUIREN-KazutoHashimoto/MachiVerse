# 天候・気候シミュレーション設計

## 1. 確定方針

標準では、季節・平均気候だけでなく、日常的な天候を時間的・空間的に変化させる。

- 雨、雪、風、気温等の日常的な天候を表現できるものとする。この列挙は確定済みの全気象要素ではない。
- 天候は地域ごとに異なり、時間とともに変化し得る。
- 地形、水域、気候帯、海流、大規模風系その他の既存自然状態と因果的に接続できる方向とする。
- 天候は農業、交通、健康、災害、生活その他の世界状態へ影響できるものとする。
- 本格的な数値気象予報モデル相当の大気・海洋物理を標準で最高詳細度に計算することは要求しない。
- より詳細な気象・気候物理モデルは将来アドオンで拡張できる余地を持たせる。
- 天候生成に確率的要素を含める場合も決定論・完全再現性の原則に従う。

## 2. 長期気候との関係

日常天候と長期的な気候状態を同一の固定値として扱わず、気候が天候の傾向へ影響し、長期的な自然変化が社会へ波及できる設計を目指す。

ただし、長期気候変動の原因・時間尺度・フィードバックを標準でどこまで計算するかは今後定義する。

## 3. 今後決定が必要な事項

- 標準気象要素
- 時間・空間解像度
- 気象状態の生成・遷移モデル
- 地形・海流・風系等との具体的接続
- 季節モデル
- 長期気候変動の標準範囲
- 農業・交通・健康・災害等への具体的影響
- 詳細領域外の気象・気候簡略化
- 事前歴史シミュレーションでの簡略化
- 標準と将来アドオンの境界

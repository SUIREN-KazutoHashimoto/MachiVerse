# 公共空間シミュレーション設計

## 確定方針

標準では道路以外の公共・共用空間を単なる未使用地として扱わず、実際の3D空間として社会活動に利用される世界状態とする。

- 広場、公園、市場空間、港湾の共用部分等が存在し得る。この列挙は網羅ではない。
- 公共空間は移動、商業、交流、余暇、イベント、政治活動、宗教・文化活動、治安等に利用され得る。
- 実際の位置、形状、入口、通行可能性、混雑、周辺施設等が利用へ影響し得る。
- 公共であっても常に無条件・無制限に利用可能とは限らず、社会・時代の制度や実効的管理によって利用条件が変化し得る。
- Full-3D空間、土地利用、群衆、社会イベント、商業、治安、政治・集団行動等と接続する。
- 標準では詳細な時間帯別利用規則、占用許可、空間利用計画等をC相当まで必須としない。

## 今後決定が必要な事項

- 公共空間の標準分類と状態
- 利用権・管理権との接続
- 一時占用・イベント利用の表現
- 混雑・通行との接続

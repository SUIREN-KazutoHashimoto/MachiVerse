# 再利用・リサイクルシミュレーション設計

## 1. 確定方針

標準では廃材・使用済み製品等を単純に消滅させず、回収・再使用・修理・再加工・リサイクルの対象にできる。

- 廃材、使用済み製品、解体材、副産物等は、状態や材料種に応じて再使用、修理、再加工、材料回収等へ回せる。
- 回収・処理には労働、設備、技術、輸送、保管、エネルギー等が必要となり得る。
- 回収された資源・材料は品質・状態等に応じて再び生産・建設・修理等へ利用できる。
- 解体、廃棄物、物品品質、材料、物流、企業、資源枯渇等と接続する。
- リサイクル可能だからといって無損失・無限循環できるとは仮定しない。損失・品質低下等の具体モデルは今後定義する。
- 標準では材料別の詳細回収率、汚染、詳細分離工程等を最高詳細度まで固定的に再現することは要求せず、より詳細なモデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 再使用・修理・再加工・材料回収の標準区分
- 回収可能性と品質・状態の関係
- 処理設備・技術要件
- 回収・選別・輸送コスト
- 廃棄物・汚染との接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

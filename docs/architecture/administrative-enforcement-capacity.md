# 徴税・行政執行能力シミュレーション設計

## 確定方針

標準では法律・税率・行政命令を設定しただけで、その内容が対象全体へ自動的かつ完全に適用されるとはしない。

- 徴税・行政執行には行政職員、記録、情報、交通、通信、施設、治安、対象者の協力等が必要になり得る。この列挙は網羅ではない。
- 制度が存在しても、能力不足によって脱税、未徴収、未把握、行政空白、執行遅延等が発生し得る。
- 法制度上の権限と、現実に行使できる行政能力を分離する。
- 税・財政、政治・行政、公的記録、通信、交通、治安、地理的支配等と接続する。
- 社会・時代によって行政制度・徴税方法は異なり得るため、現代的行政を普遍的前提としない。
- 標準では詳細な税務調査、徴収手続、行政組織運用等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な徴税・行政執行へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 行政能力の標準表現
- 執行対象の把握方法
- 未執行・部分執行の状態
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 犯罪組織・非公式組織シミュレーション設計

## 1. 確定方針

標準では、犯罪組織・非公式組織を治安値の一部として抽象化するだけでなく、世界内の実在する組織として比較的深く扱う。

- 犯罪組織、ギャング、秘密結社等も、既存の組織形成・人間関係・経済・権力と接続して成立し得る。この列挙は確定済みの全組織種別ではない。
- ある活動・組織が違法かどうかは、その社会・地域の法制度・慣習・統治状態等によって決まり、世界共通の固定犯罪属性だけで判断しない。
- 縄張り、密輸網、資金洗浄、内部抗争等も標準で比較的深く扱う方向とする。ただし具体的な分類・アルゴリズムは今後定義する。
- 組織内の役割、権力関係、利益配分、忠誠・離反等を既存の組織・人間関係モデルと接続できるものとする。
- 犯罪・司法・公共安全、企業・市場、物流、政治・統治、外交、評判・信頼等へ波及し得る。
- 詳細な個別犯罪手口や特殊犯罪経済を無制限に標準化することは要求せず、さらに深いモデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準で扱う非公式・犯罪組織の類型
- 縄張り・勢力圏の表現
- 密輸・非合法物流と通常物流の接続
- 資金洗浄と金融・企業活動の接続
- 内部抗争・分裂・統合のモデル
- 公権力・他組織との関係
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 人口統計シミュレーション設計

## 1. 確定方針

標準では、詳細シミュレーション対象領域の人口統計を独立した架空の統計値として住人実体から切り離さない。

- 詳細シミュレーション対象領域では、人口、年齢構成、出生、死亡等の統計は原則として実在する住人の状態・出来事から集計する。
- 世界規模の処理性能を確保するため、詳細領域外等では住人・人口状態を集約・簡略化したモデルで扱うことを許容する。
- 詳細モデルと集約モデルの間で人口・年齢構成・その他必要な状態の整合性を維持する方向とする。
- 世界全域で常に全住人を個体として保持するC相当の方式は標準では必須としない。
- 一方で、将来アドオンによってC相当の全世界個体シミュレーションへ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 集約・展開を含む処理も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 詳細領域と集約領域の定義
- 集約人口状態に保持する情報
- 個体状態から統計への集計方法
- 集約領域から詳細領域へ移行する際の個体展開方法
- 詳細領域から集約領域へ移行する際の情報保持方法
- 移住等による領域間移動との接続
- 外部簡略シミュレーションとの関係
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

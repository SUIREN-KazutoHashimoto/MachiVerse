# 人口統計シミュレーション設計

## 1. 確定方針

標準では、人口統計を独立した架空の統計値として住人実体から切り離さない。

- 詳細シミュレーション対象では、人口、年齢構成、出生、死亡等の統計は原則として実在する住人の状態・出来事から集計する。
- Q190およびQ265に従い、デフォルト構成では世界規模で可能な限り住人の存在、永続ID、重要な永続状態を個体単位で保持する方向とする。
- **個体として存在・識別されることと、常時高頻度・高詳細度で更新されることを分離する。**
- 遠隔地域や現在重要度の低い対象では、同一性・因果・必要状態を維持したまま、更新頻度や計算詳細度を下げることを許容する。
- デフォルトCであっても、世界全域の全住人を30Hzで一律に詳細更新することを意味しない。
- Configで集約・簡略化方式を選択する場合は、人口・年齢構成・財産・関係・履歴その他必要状態の整合性を維持し、詳細化・再集約によって不自然な増減や別個体化を起こしてはならない。
- 詳細度の昇格・降格、集約・展開を含む処理は決定論・再現性の原則に従う。
- 将来アドオンによって、標準より高い頻度・詳細度で世界規模の個体シミュレーションを行うことは可能とするが、世界規模の個体同一性保持そのものをアドオン専用要件とはしない。

## 2. Q083との整合

Q083で採用した「世界全域を常時全個体詳細シミュレーションすることを標準必須としない」という方針は、Q190/Q193およびQ265によって次のように具体化された。

- 必須でないのは、**全世界を常時同じ高詳細度・高更新頻度で計算すること**である。
- 一方、デフォルトでは可能な限り世界規模で個体の存在・永続ID・重要状態を保持する。
- 必要に応じて更新頻度・計算詳細度を下げても、同じ住人が別人として再生成されるような扱いにはしない。

## 3. 今後決定が必要な事項

- 世界規模で個体保持する住人状態の最小集合
- 詳細度ごとの更新頻度と計算内容
- Configで選択可能な集約方式の具体的意味
- 個体状態から統計への集計方法
- 集約状態を使用する場合の保持情報と復元方式
- 移住等による詳細度境界の移動との接続
- 外部簡略シミュレーションとの関係
- 標準より高詳細な世界規模個体更新を行う将来アドオンとの境界

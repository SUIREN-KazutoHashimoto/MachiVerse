# 運搬能力・重量シミュレーション設計

## 確定方針

標準では住人・動物・車両等が任意量の物品を無制限に運搬できるとはしない。

- 運搬主体には必要な粒度で運搬能力を持たせる。
- 物品の量、重量、大きさ等によって、一度に運べる量や必要な輸送手段が変化し得る。
- 過大な荷物は運搬不能、複数回輸送、複数人作業、車両・動物・機械の利用等につながり得る。
- 住人の身体状態、技能、道具、車両状態等が実効的な運搬能力へ影響し得る。
- 物理物流、物品位置、住人の身体状態、車両、動物、建設、採掘、製造等と接続する。
- 標準では荷物の重心、荷姿、持ち方、詳細な積載配置・荷崩れ等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な積載・運搬物理へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 重量・容積・運搬能力の標準単位と粒度
- 複数主体による共同運搬
- 疲労・速度への影響
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

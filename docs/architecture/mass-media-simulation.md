# 新聞・放送・マスメディアシミュレーション設計

## 1. 確定方針

標準ではマスメディアを地域全体へ情報を即時配布する抽象機能として扱わず、情報を収集・編集・発信する社会的主体として扱う。

- 新聞社、放送組織その他の媒体主体は、必要に応じて実際の組織として成立し得る。
- 情報の収集、編集、発信を行い、利用可能な印刷・通信・放送等の技術とインフラによって到達範囲・速度・利用可能性が変化し得る。
- メディア組織は企業、政治組織、公的組織等として成立し得る方向とし、単一の制度形態を普遍的前提としない。
- 情報・通信、広告・説得、世論、政治、企業、知識媒体等と接続する。
- 標準では記事・番組単位の詳細な制作工程、編集方針、視聴率、媒体市場等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、記事・番組制作、編集方針、媒体市場等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 情報伝播等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- メディア主体の標準状態
- 情報収集・編集・発信の標準粒度
- 媒体技術と到達範囲・速度の関係
- 読者・視聴者への到達条件
- 広告・政治・企業との関係
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 住人の物理的作業シミュレーション設計

## 1. 確定方針

標準では「建設する」「採掘する」等のジョブ進捗だけを抽象的に加算するのではなく、住人が世界内の作業場所へ実際に到達し、必要な物品・設備を利用して作業する。

- 住人は原則として作業場所へ物理的に移動して作業する。
- 作業には必要に応じて道具、設備、材料、技術、技能等が関与する。この列挙は確定済みの全要因ではない。
- 作業場所へ到達できない、必要な設備・物品を利用できない等の状況では、原則としてその作業は成立しない。
- 建設、採掘、製造、修理、農業、医療等、世界内で実作業を伴う各システムと接続する。
- 標準では姿勢、手足、工具の物理位置、個々の作業動作等をC相当の最高詳細度まで常時計算することは要求しない。
- 住人の作業時間・成果・消耗等は生理状態、健康、技能、道具・設備、環境等と接続し得る。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 作業場所・作業対象の標準表現
- 必要物品・設備・技能等の要求表現
- 作業進捗・成果の計算方法
- 複数住人による共同作業
- 作業中断・再開の扱い
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

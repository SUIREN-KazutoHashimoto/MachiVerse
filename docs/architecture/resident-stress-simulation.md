# 住人のストレス・精神的負荷シミュレーション設計

## 1. 確定方針

標準では住人の精神的負荷を無視せず、生活・身体・社会環境から蓄積・回復する状態として扱う。

- 過労、睡眠不足、貧困、病気、人間関係、危険、災害、戦争等が精神的負荷の要因となり得る。この列挙は確定済みの全要因ではない。
- 精神的負荷は時間経過、休息、安全な環境、生活改善、人間関係等によって回復し得る。
- 負荷は判断、感情、健康、仕事・学習効率、睡眠、対人関係、日常活動等へ影響し得る。
- 同じ出来事に対する負荷や回復には人格、記憶、関係、身体状態等による個人差を持ち得る。
- ストレスを単なる一方向の罰則値ではなく、既存の心理・身体・社会モデルと相互作用する状態として扱う。
- 標準では具体的な精神疾患分類、診断基準、詳細な精神医療・心理治療過程等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、精神疾患・診断・治療等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 状態変化に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 精神的負荷の標準状態表現
- 負荷蓄積・回復モデル
- 感情・身体健康・睡眠との相互作用
- 行動・意思決定への影響
- 長期化した負荷を標準でどこまで扱うか
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 障害・慢性的状態シミュレーション設計

## 1. 確定方針

標準では長期的な身体・健康状態を一時的な能力低下だけとして扱わない。

- 住人は先天的・後天的な長期状態を持ち得るものとする。
- 状態によって身体機能や生活上の制約が変化し得る。
- 同じ身体・健康状態でも、教育、補助具、医療、住環境、交通、職業、周囲の支援等によって実際の生活への影響が変化し得る。
- 知識が職業を自動決定しない既存方針と同様に、障害・慢性的状態から職業不能・社会参加不能等を機械的に決めつけない。
- 健康、医療、身体部位別負傷、教育、職業、住宅、福祉等と接続する。
- 非常に細かな医学的分類、症状群、詳細なリハビリ過程等を標準で最高詳細度まで扱うことは要求せず、より詳細なモデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 長期状態の標準表現
- 身体機能と活動制約の関係
- 補助具・医療・リハビリの標準範囲
- 環境・制度側の障壁や支援をどこまで表現するか
- 加齢・負傷・疾病との接続
- 回復・悪化・安定の状態遷移
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

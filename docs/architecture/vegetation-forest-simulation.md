# 植物・森林シミュレーション設計

## 1. 確定方針

標準では植生を固定的な土地属性だけとして扱わず、時間と環境・人間活動によって変化する植物群落として扱う。

- 森林、草地、農地その他の植生は、成長、枯死、繁殖、遷移等によって変化し得る。
- 伐採、火災、気候、土壌、水、人間活動等によって植生状態が変化し得る。この列挙は確定済みの全要因ではない。
- 世界因果上重要な植物は必要に応じて個体として表現できるものとし、世界全域で全植物を常時個体化することは標準要件としない。
- 生態系、食料・農業、資源利用、火災、気候、土壌劣化・回復等と接続する。
- 将来アドオンによって、樹木を原則一本単位、主要植物を個体単位で成長させるC相当のモデルへ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 植生生成・成長・集約等も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 植物群落の標準空間表現
- 成長・繁殖・枯死・遷移の標準モデル
- 個体化する植物の条件
- 火災・伐採・農業・気候との接続
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 建設計画・設計情報シミュレーション設計

## 1. 確定方針

標準では建設対象の完成形だけを直接指定して即時に施工へ移るのではなく、着工前の計画・設計情報を世界内の因果へ組み込む。

- 建物、道路、設備等について計画・設計情報を持ち、着工前に場所、規模、必要資源等を決定できるものとする。この列挙は確定済みの全設計情報ではない。
- 計画は着工前・施工中に変更、中止、延期され得る。
- 計画・設計は土地・権利、資金、契約、技術、需要、行政制度等と接続し得る。
- 設計情報と実際に施工された世界状態は別概念とし、施工途中・変更・失敗によって一致しない場合を許容する。
- 設計・計画に必要な知識や職業を既存の個人知識・職業・組織モデルと接続できる方向とする。
- 図面、詳細寸法、構造計算、設計変更履歴等を標準で最高詳細度まで再現することは要求せず、より詳細な設計モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 計画・設計情報の標準表現
- 設計主体・承認主体の表現
- 必要資源・工程との接続
- 計画変更・中止の意思決定モデル
- 法規・土地利用・権利との接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

# 標準化・規格・互換性シミュレーション設計

## 1. 確定方針

標準では、同等の技術を持つ部品・設備・インフラ等が自動的に完全互換であるとは仮定しない。

- 寸法、規格、方式等の違いによって互換性が変化し得るものとする。
- 企業、業界、国家、その他の組織等による標準化活動が起こり得る方向とする。
- 標準化・互換性は生産、部品供給、修理・保守、貿易、交通・通信等のインフラ、技術普及等へ影響し得る。
- 異なる地域・文明・組織で独立に発展した技術が、同程度の機能を持っていてもそのまま相互運用できるとは限らない。
- 規格自体も歴史的に成立・競合・普及・変更・衰退し得るものとする。
- 非常に細かな部品寸法、現実の工業規格体系、詳細な認証試験等を標準で最高詳細度まで扱うことは要求せず、より詳細な標準化モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 規格・方式・互換性の標準表現
- 互換・部分互換・非互換等の粒度
- 標準化を行う主体と意思決定モデル
- デファクト標準と制度的標準をどこまで区別するか
- 変換器・アダプタ等による相互運用の扱い
- 規格競争・移行コストのモデル
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

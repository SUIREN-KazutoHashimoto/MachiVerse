# 通貨・貨幣シミュレーション設計

## 1. 確定方針

標準では世界共通の抽象通貨を唯一の交換手段として固定せず、社会・時代によって異なる貨幣制度が歴史的に成立できるものとする。

- 複数の通貨、貨幣、その他の交換手段が同時に存在し得る。
- 各交換手段は受容される地域・社会・主体や交換価値等が異なり得る。
- 貨幣制度は政治、経済、技術、信用、歴史等によって形成・変化・衰退し得る。
- 異なる通貨・交換手段間の交換を表現できる方向とする。
- 市場・価格、契約、信用・債務、税・公共財政、企業、家計等と接続する。
- 標準では現代的な中央銀行・法定通貨制度を普遍的前提としない。
- 貨幣発行、通貨供給、インフレ、金融政策等の詳細度は今後個別に決定し、B選択だけからC相当を自動的に標準要件とはしない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 通貨・交換手段の標準状態
- 受容範囲・交換価値の形成モデル
- 通貨間交換の標準モデル
- 貨幣制度の成立・変化・消滅
- 物理貨幣と記録型資産の境界
- 詳細領域外での簡略化

# 通貨・貨幣シミュレーション設計

## 1. 確定方針

標準では世界共通の抽象通貨を唯一の交換手段として固定せず、社会・時代によって異なる貨幣制度が歴史的に成立できるものとする。

- 複数の通貨、貨幣、その他の交換手段が同時に存在し得る。
- 各交換手段は受容される地域・社会・主体や交換価値等が異なり得る。
- 貨幣制度は政治、経済、技術、信用、歴史等によって形成・変化・競合・衰退し得る。
- 異なる通貨・交換手段間の交換を表現できる方向とする。
- 市場・価格、契約、信用・債務、税・公共財政、企業、家計等と接続する。
- 標準では現代的な中央銀行・法定通貨制度を普遍的前提としない。
- Q279により、**通貨発行、通貨供給量、発行主体および基本的な金融政策を標準シミュレーションの範囲に含める。**
- 通貨の発行主体、供給調整、信用との関係、制度的な管理方法等は、社会・時代・制度の歴史的形成によって異なり得る。
- 通貨発行・供給調整制度そのものが成立・変更・競合・衰退し得る世界状態として扱う。
- 物価上昇・下落等は貨幣供給だけの単純な固定式で決めず、採用する経済モデルの因果関係から生じ得るものとする。具体モデルは詳細設計で決定する。
- 高度な金融市場モデル、高度な金融政策モデル等は将来アドオンで拡張可能とする。
- 確率的要素を含む場合も決定論・再現性の原則に従う。

## 2. Q120からQ279への更新

Q120時点では貨幣発行・通貨供給・金融政策の標準範囲を未確定としていたが、Q279で上記範囲を標準要件として確定した。したがって、これらを未確定事項として扱わない。

ただし、中央銀行、政策金利、公開市場操作等の特定の現代制度をすべての社会へ適用することは要求しない。

## 3. 今後決定が必要な事項

- 通貨・交換手段の標準状態表現
- 受容範囲・交換価値の形成モデル
- 通貨間交換の標準モデル
- 貨幣制度の成立・変化・消滅条件
- 発行主体・発行行為・供給量の具体的状態表現
- 基本的金融政策として標準で持つ操作・制度の具体的範囲
- 物理貨幣と記録型資産の境界
- 詳細領域外での簡略化
- 高度な金融市場・金融政策アドオンとの境界

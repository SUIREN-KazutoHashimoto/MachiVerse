# 所有・権利シミュレーション設計

## 1. 目的

本書は、MachiVerse における土地、建物、物品、資金、生産設備等の保有・利用と、社会制度上の所有権・利用権その他の権利に関する要件を整理します。

## 2. 確定事項

- 住人や組織が土地、建物、物品、資金、生産設備等を所有・保有・利用する状態をシミュレーションできるものとする。
- 所有を世界共通の単一かつ絶対的な `OwnerId` 相当の概念だけで表現することを標準とはしない。
- 物理的な「誰が保持・占有・使用しているか」と、社会制度上の「誰にどのような権利が認められているか」を概念上分離できる設計とする。
- 財産に関する権利のあり方は社会・政治・法・慣習・歴史によって異なり得るものとする。
- 個人所有、組織所有、共同体的な権利、国家等による権利、慣習的利用等を表現できる余地を持たせるが、現時点で具体的な権利類型一覧は確定しない。
- 売買、貸借、相続、没収等による権利変化を扱える方向とし、その有効性や意味は当該社会の法・慣習・制度と接続できるものとする。
- 標準では所有・財産権・利用権等を比較的深く扱う一方、現実のあらゆる財産法・契約法・登記制度等を完全再現することは要求しない。
- より複雑・特殊・詳細な財産制度や契約制度等は将来アドオンで拡張できることを設計上考慮する。
- アドオン拡張を考慮することは、現時点で具体的なアドオンAPI、プラグイン機構、拡張ポイント等を確定することを意味しない。
- 所有・権利の状態変化にランダム性を含める場合も、MachiVerseの決定論・完全再現性の原則に従う。

## 3. 物理的状態と社会的権利の分離

標準では、物や土地について「誰が実際に保持・占有・使用しているか」と「社会制度上、誰がどの権利を持つと認められているか」を同一の状態として固定しません。

例えば、権利者と実際の利用者が異なる状態や、法制度上の権利と現実の支配状態が一致しない状態を表現できる余地を持たせます。

これにより、貸借、占有、共同利用、権利紛争、没収等を世界の社会制度と接続できる設計を目指します。ただし、それぞれの具体的モデルは今後定義します。

## 4. 社会・制度による違い

財産に関するルールを全世界へ一律に適用することを標準とはしません。

土地や建物等について、個人、家族・共同体、組織、統治主体等のどの主体にどの権利が認められるかは、地域・社会の法、慣習、政治制度、歴史等によって異なり得るものとします。

権利制度そのものも歴史的に形成・変化し得る方向とし、政治・統治シミュレーション、組織シミュレーション、経済シミュレーション等と整合させます。

## 5. 権利の移転・変化

売買、貸借、相続、贈与、没収その他は、財産に関する状態を変化させる候補です。ただし、この列挙を確定済みの標準取引・権利変化一覧とはしません。

ある移転・契約等が社会制度上有効か、誰にどの権利が残るか等は、当該社会の法・慣習・制度と接続できるものとします。

経済上の取引が成立したことと、社会制度上の権利移転が成立したことを常に同一イベントとして扱うかどうかも今後詳細化します。

## 6. 経済・建物・組織・政治との接続

所有・権利モデルは独立した台帳だけではなく、経済活動、建物・土地利用、組織活動、政治・統治等へ影響できる状態として扱います。

住人・組織の資産、生産設備、住宅、商業施設、農地、資源利用等と接続し、誰が何を利用できるか、収益を得られるか、移転できるか等へ権利状態が影響できる方向とします。

具体的な契約、収益権、担保、課税、登記、紛争処理等のモデルは今後定義します。

## 7. 標準モデルとアドオン

標準では、経済・政治・建物・組織・住人の因果関係を成立させるため、所有・占有・利用と社会的権利の違いを扱える程度まで比較的深くシミュレーションします。

一方で、現実のあらゆる財産法、契約法、登記制度、複雑な権利分割等を標準で完全再現することは要求しません。

より高度・特殊・詳細な財産制度や契約制度等は将来アドオンで拡張できる余地を持たせます。ただし、そのために標準モデルの性能、決定論、既存要件、コンポーネント独立性を犠牲にしてまで過度に抽象化することは求めません。

## 8. 決定論

権利移転、相続その他の所有・権利状態変化に確率的要素を含める場合も、ワールドSeed、World Time、対象・文脈を識別する決定的情報等から結果を導出し、処理速度、スレッド順序、OS時刻等によって結果が変化してはなりません。

同一の完全再現性条件では、所有・権利状態の変化も再現可能でなければなりません。

## 9. 今後決定が必要な事項

- 標準で扱う所有・占有・利用・その他権利の具体的な種類
- 権利主体として扱う住人・組織・共同体・統治主体等の範囲
- 土地・建物・物品・資金・設備等で権利モデルをどこまで共通化するか
- 共同所有・共同利用等の表現
- 売買・貸借・贈与・相続・没収等の具体モデル
- 契約の表現と履行・不履行
- 権利紛争と司法・治安・実力支配との関係
- 登記・記録・証明等を標準で扱うか
- 担保・債権等を標準経済モデルへどこまで含めるか
- 課税と所有・利用権の関係
- 土地利用と領域・主権・管轄権との関係
- 権利制度自体の歴史的形成・変化モデル
- 事前歴史シミュレーションでの簡略化範囲
- 詳細シミュレーション領域外での簡略化範囲
- 標準モデルと将来アドオン拡張の具体的な境界

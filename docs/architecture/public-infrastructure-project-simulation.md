# 公共工事・大規模インフラ計画シミュレーション設計

## 1. 確定方針

標準では行政等が費用を支払った瞬間に公共インフラが生成される方式を採らず、計画から施工までの社会的・物理的過程を持たせる。

- 行政、企業、その他の組織等が道路、橋、鉄道、上下水道その他の大規模インフラを計画・整備できる方向とする。この列挙は確定済みの全インフラ種別ではない。
- 公共工事・大規模インフラ計画には、計画、予算・資金確保、必要な土地・権利の確保、契約、資材調達、施工等が関与し得る。
- 政治・統治、公共財政、契約、土地・権利、企業、物流、建設工程等と接続する。
- 資金不足、土地問題、資材不足、労働力不足、政治的変更等によって延期・縮小・変更・中止され得る。
- 完成したインフラだけでなく建設途中状態も世界状態として扱う。
- 入札、複数業者間の詳細な調達、複雑な公共調達制度等を標準で最高詳細度まで固定的に再現することは要求せず、社会・時代によって制度が異なり得る。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 公共工事プロジェクトの標準状態
- 計画主体・施工主体・資金主体の関係
- 土地・権利確保の具体的接続
- 契約・資材調達・施工への遷移
- 計画変更・中止・失敗のモデル
- 社会・時代ごとの制度差
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

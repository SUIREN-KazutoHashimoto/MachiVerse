# 広告・宣伝・情報操作シミュレーション設計

## 1. 確定方針

標準では広告・宣伝を売上等への単純な補正値だけとして扱わず、情報発信と住人の認識を接続する。

- 企業、政治組織、その他の主体が目的を持って情報を発信できる方向とする。
- 発信された情報は既存の通信・情報伝播経路を通じて住人へ到達し得る。
- 情報が到達したことと、それを住人が信じる・行動へ反映することは分離する。
- 広告・宣伝は認識、評判、商品選択、世論等へ影響し得る。
- 情報操作や意図的な偏った情報発信も表現できる方向とするが、具体的な分類・手法は今後定義する。
- 媒体別の高度なターゲティング、詳細なキャンペーン設計、詳細なプロパガンダ戦等を標準で最高詳細度まで扱うことは要求せず、より詳細なモデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 発信主体・情報媒体の標準範囲
- 広告・宣伝・一般情報・虚偽情報等の境界
- 到達・注目・信用・行動変化の具体モデル
- 発信コスト・規模・頻度
- 規制・検閲等との関係
- 商品広告と政治的宣伝等の共通化範囲
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

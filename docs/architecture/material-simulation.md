# 素材・材料シミュレーション設計

## 1. 確定方針

標準では素材・材料を木材、金属、石材等のごく粗い大分類だけで扱わず、技術・製造・建設上の差異を表現できる比較的細かな材料種を持つ。

- 鉄、銅、石灰岩、粘土、木材種等のように、用途・加工方法・入手方法・性質等に差が生じ得る材料種を扱う。この列挙は確定済みの全材料種ではない。
- 材料種の違いは製造、建設、修理、耐久性、品質、技術要件等へ影響し得る。
- 材料は地下資源、採掘、林業、農業、製造、物流、建設、修理、廃棄・再利用等と接続する。
- 標準では合金組成、純度、含水率、結晶状態等を材料科学として最高詳細度まで常時計算することは要求しない。
- より詳細な材料科学モデルは将来アドオンで拡張できる余地を持たせる。
- 材料状態が世界結果へ影響する場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準の材料分類体系
- 材料種ごとの標準特性
- 材料と技術・製造工程の対応
- 品質・耐久・修理との接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

# 技能・熟練度シミュレーション設計

## 1. 確定方針

標準では「技術・知識を知っていること」と「実際に上手く実行できること」を同一視せず、技能・熟練度を別状態として扱う。

- 技能・熟練は実践、教育、訓練、経験等によって向上し得る。
- 長期間使用しない技能は低下し得る。
- 同じ知識を持つ住人でも、技能・熟練度によって作業速度・品質・成功可能性等が異なり得る。
- 技能は職業、教育、製造、建設、修理、医療、運転・操縦等の各活動と接続する。
- 住人の知識状態、個人差、健康・疲労、使用可能な道具・設備等と相互作用する。
- 標準では非常に細かな運動技能、技能転移、詳細な学習曲線等を最高詳細度まで固定的に扱うことは要求しない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 技能分類と粒度
- 熟練度の表現方法
- 学習・訓練・実践による変化
- 未使用による低下モデル
- 知識・適性・健康等との接続
- 詳細領域外での簡略化

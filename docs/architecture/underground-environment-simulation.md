# 地下環境シミュレーション設計

## 1. 確定方針

標準では地下空間を地上と同一環境として扱わず、C相当の比較的詳細な地下環境シミュレーションを行う。

- 地下空間では光、換気、温度、煙、空気環境、水等を空間状態として扱い、居住・作業・交通・火災・健康等へ影響させる。
- 換気については単一の「換気良好度」だけでなく、地下空間・通路・開口部・換気設備等を通じた空気の流れを比較的詳細に扱う方向とする。
- 酸素その他のガス・煙等について、必要な濃度分布や移動を空間的に表現できる方向とする。標準で扱う成分は今後定義する。
- 火災時の煙・空気環境、住人の健康・知覚・避難、採掘・地下交通・地下施設の運用等と接続する。
- 地下水・浸水等の水環境とも接続する。
- C相当を標準範囲とするが、汎用CFDとして現実の流体を無制限の精度で解くことまでは要求しない。MachiVerseの世界因果に必要な詳細度を優先する。
- 空気流・ガス濃度等の計算も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準で追跡する空気・ガス成分
- 空気流・換気の空間粒度と計算方式
- 温度・湿度等をどこまで扱うか
- 煙・火災モデルとの具体的接続
- 地下水・浸水との接続
- 換気設備・電力・故障との接続
- 住人健康・知覚への閾値・影響モデル
- 詳細領域外での簡略化

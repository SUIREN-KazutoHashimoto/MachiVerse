# 政治体制変化シミュレーション設計

## 1. 確定方針

標準では政治体制を国家生成時に固定するのではなく、歴史的な世界状態から変化し得るものとする。

- 権力関係、文化、経済、戦争、世論、組織等が統治制度の変化へ影響し得る。この列挙は確定済みの全要因ではない。
- 王政から別制度への移行、中央集権化・分権化等の体制変化が、固定イベントではなく世界内部の因果関係から生じ得る余地を持たせる。
- 政治体制の変化は政治・統治、社会階層、組織、軍事、外交、経済、文化等と相互作用できる。
- 特定の政治制度を世界共通の進化段階として固定しない。
- 憲法、議会制度、選挙制度、官僚機構等を標準で最高詳細度まで組み替え可能にすることは要求せず、より詳細・特殊な制度モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 政治体制を構成する標準要素
- 制度変更の発生・成立条件
- 革命、クーデター、改革、継承等との関係
- 権力主体・統治組織との接続
- 政治体制変更時の法・行政・軍事等への反映
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

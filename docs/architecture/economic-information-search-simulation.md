# 経済情報探索シミュレーション設計

## 確定方針

標準では住人が利用可能な店舗、価格、在庫、求人等を自動的かつ完全に知るとはしない。

- 住人は観察、口コミ、広告、通信、過去の経験等を通じて選択肢を知り得る。この列挙は網羅ではない。
- 知らない店舗・商品・求人等は、原則として意思決定の候補にならない。
- 保持している情報は古い、不完全、誤っている場合がある。
- Core上の真の市場状態と住人が認識する市場情報を分離する。
- 情報・通信、広告、評判、消費、労働市場、店舗在庫、価格形成等と接続する。
- 標準では探索コストや探索戦略をC相当の最高詳細度まで必須としない。
- 意思決定に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 経済情報の保持・鮮度の標準表現
- 情報探索を開始する条件
- 選択候補集合の形成方法
- 詳細領域外での簡略化

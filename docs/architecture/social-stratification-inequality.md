# 社会階層・格差シミュレーション設計

## 1. 確定方針

標準では社会階層を固定クラスとして先に割り当てるのではなく、住人間の差異と社会構造の結果として形成され得るものとする。

- 所得、資産、職業、教育、人間関係、権力等の差が社会的階層形成へ影響し得る。この列挙は確定済みの全要因ではない。
- 形成された階層・格差は、教育機会、雇用、政治参加、結婚その他の社会的機会へ再び影響し得る。
- 社会階層は地域・時代・社会制度によって異なり、固定された単一モデルには限定しない。
- 格差や階層は経済、家族、教育、政治、文化、所有・権利等と相互作用できる。
- 身分制度・階級制度等を標準で最高詳細度に固定することは要求せず、より特殊・詳細な制度は将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 階層を明示状態として持つか、他状態から導出するか
- 社会的評価・地位・権力の表現
- 世代間継承との関係
- 教育・雇用・結婚等への具体的影響
- 制度化された身分と非制度的階層の関係
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 死後の物理的・社会的影響シミュレーション設計

## 1. 確定方針

標準では住人を死亡時点で即座に世界から完全消去せず、死亡によって生じる物理的・社会的因果を必要な期間だけ保持する。

- 死亡後も遺体、所有物、相続、家族・知人の記憶、組織上の空席、葬送等が世界へ影響し得る。この列挙は確定済みの全死後影響ではない。
- 死亡は家族・世代、所有・権利、契約、組織、職業、住人記憶、文化・宗教等と接続する。
- 遺体は必要な範囲で物理的な世界状態として扱える方向とする。
- 標準では遺体の詳細な変化、葬儀・墓地・宗教儀礼等をC相当の最高詳細度まで常時扱うことは要求しない。
- 将来アドオンによって、遺体のより詳細な変化や葬送・墓地・宗教儀礼等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 死亡後の状態変化・確率的要素も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 死亡後に保持する住人状態と保持期間
- 遺体の標準状態・処理
- 所有物・相続との接続
- 家族・知人・組織への影響モデル
- 葬送を標準でどこまで扱うか
- 墓地・埋葬等と土地利用の関係
- 事前歴史・詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

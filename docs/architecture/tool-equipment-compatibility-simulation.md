# 道具・設備の適合性シミュレーション設計

## 確定方針

標準では同一カテゴリに属する道具・設備なら無条件にすべての作業へ利用できるとはしない。

- 作業には必要な種類、性能、互換性等を満たす道具・設備が必要になり得る。
- 適切な道具がない場合、作業不能となるほか、代用品によって速度、品質、安全性、失敗率等が変化し得る。
- 技術、規格・互換性、技能・熟練、物理作業、製造、建設、修理・保守等と接続する。
- 道具・設備の故障や劣化も利用可能性・作業結果へ影響し得る。
- 標準では工具寸法、接続規格の全詳細、刃・ビット等の個別適合関係をC相当まで必須としない。
- 将来アドオンでC相当の詳細な工具・設備適合モデルへ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 作業要求と道具能力の標準表現
- 代用品利用時の影響
- 規格・互換性モデルとの境界
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

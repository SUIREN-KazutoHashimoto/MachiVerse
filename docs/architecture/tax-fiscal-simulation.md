# 税・財政シミュレーション設計

## 1. 確定方針

標準では国家・自治体等の財政を単一の予算値だけにせず、税収・支出・行政能力等と接続する。

- 税収、公共支出、行政、軍事、医療、インフラ等への資金配分を表現できる方向とする。この列挙は確定済みの全歳入・歳出項目ではない。
- 税率、徴収能力、景気、人口構成等によって財政状態が変化し得る。
- 財政状態は公共サービス、行政能力、軍事、建設・保守、医療その他へ影響し得る。
- 税・財政制度自体も政治・統治制度、経済、社会状況、歴史等によって変化し得るものとする。
- 特定の現代的税体系を全世界へ固定適用しない。
- 税目ごとの詳細制度、地方交付、国債市場、複雑な財政移転等を標準で無制限に深く扱うことは要求せず、より詳細・特殊な財政制度は将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 課税主体・財政主体の具体的範囲
- 標準的な歳入・歳出カテゴリ
- 徴税・徴収能力のモデル
- 予算決定・支出配分の意思決定モデル
- 公債・借入を標準でどこまで扱うか
- 財政破綻・支払不能等の扱い
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

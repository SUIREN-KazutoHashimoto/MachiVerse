# 地下地質シミュレーション設計

## 1. 確定方針

標準では地下を一様な岩盤として扱わず、フル3D世界の内部に地質的な差異を持たせる。

- 地層、岩種、土壌、地下資源等が三次元的に分布し得るものとする。この列挙は確定済みの全地質要素ではない。
- 地質状態は掘削難度、資源分布、地下水、地下構造物の安全性等へ影響し得る。
- 地下地質は世界生成時の自然条件から決定論的に生成され、地上地形・プレート・資源等の既存モデルと因果的に接続する方向とする。
- 標準では断層、褶曲、鉱脈形状、地質年代等をC相当の最高詳細度まで常時扱うことは要求しない。
- 将来アドオンによって、断層・褶曲・詳細な鉱脈形状・地質年代等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 具体的なVoxel、SDF、CSG、メッシュ等の地形・地下データ構造は現時点では確定しない。

## 2. 今後決定が必要な事項

- 標準の地層・岩種・土壌分類
- 地下地質の空間粒度
- 地上地形・プレート・資源生成との因果関係
- 地質状態から掘削難度等への影響モデル
- 地下水との接続
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

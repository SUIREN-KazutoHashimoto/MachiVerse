# 電力・通信インフラシミュレーション設計

## 1. 確定方針

標準では、電力・通信を地域単位のサービス有無だけに抽象化せず、世界内の設備・供給能力・障害等と接続する。

- 発電所、送配電設備、通信設備等を世界内の設備として表現できる方向とする。この列挙は確定済みの全設備ではない。
- 電力・通信には供給・到達範囲、容量、利用可能性等を持たせられるものとする。
- 設備の破壊・故障等によって停電や通信断が発生し、生活、産業、交通、医療、情報伝播その他へ波及し得る。
- 資源・エネルギー、建物、企業、交通・物流、災害、戦争等と接続する。
- 電力潮流、周波数安定性、詳細な通信経路・帯域制御等を工学的に深く扱うモデルは標準では要求せず、将来アドオンによる拡張対象とする。
- 標準モデルの性能・決定論・既存要件を、将来の詳細アドオンのために犠牲にしない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準電力・通信設備の分類
- 供給範囲・容量・需要の表現
- 障害・復旧モデル
- エネルギー資源・発電との具体的接続
- 通信技術と情報伝播との具体的接続
- インフラ建設・維持・所有・運営との関係
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

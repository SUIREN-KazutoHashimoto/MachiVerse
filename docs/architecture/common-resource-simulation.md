# 共有地・共有資源シミュレーション設計

## 確定方針

標準ではすべての土地・資源に必ず単独所有者が存在するとはしない。

- 私有・公有に加え、共同利用地、共有林、漁場、放牧地等の複数主体が利用する資源を表現できる。この列挙は網羅ではない。
- 所有権、利用権、管理権、実際の利用を分離可能とする。
- 利用条件は社会・時代・地域の慣習、制度、契約、組織等によって異なり得る。
- 複数主体の利用が競合し、資源量・利用可能性・社会関係等へ影響し得る。
- 財産権、領域、土地利用、資源、漁業・狩猟、農業、生態系、組織等と接続する。
- 標準では詳細な利用枠配分、共同管理規則、共有資源ガバナンスをC相当まで必須としない。

## 今後決定が必要な事項

- 共有利用権の標準表現
- 利用者集合・資格の扱い
- 競合利用の解決粒度
- 所有・利用・管理状態との接続

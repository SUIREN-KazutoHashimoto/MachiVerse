# 待ち行列・サービス容量シミュレーション設計

## 1. 確定方針

標準では店舗、医療、行政その他のサービス要求を即時処理せず、サービス提供主体・設備の有限な処理能力と詳細な待ち行列を世界状態として扱う。

- 店員、窓口、医師、設備、受付等には利用可能時間と処理能力があり得る。この列挙は確定済みの全サービス資源ではない。
- 需要が処理能力を上回る場合、待ち時間、待ち行列、予約待ち等が発生し得る。
- C相当を標準とし、必要な領域では窓口・サービス単位のキュー、予約枠、優先順位、キャンセル、割当等を扱えるものとする。
- 利用者は実際の時間を消費し、待ち時間や混雑を理由に利用先変更・離脱・予定変更等を行い得る。
- サービス担当者の勤務、技能、健康、設備故障、営業時間等によって実効容量が変化し得る。
- 医療、行政、店舗、交通、教育、娯楽等のサービスと接続する。
- C相当であっても、すべてのサービスを同一の待ち行列アルゴリズムへ固定することや、現実の全予約制度を再現することは現時点では要求しない。
- 状態更新・割当に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- キュー・予約・優先順位の標準表現
- サービス容量の算出方法
- 到着・受付・処理・完了・離脱の状態遷移
- 複数窓口・複数担当者への割当
- 緊急度等による優先処理との接続
- 詳細領域外での簡略化

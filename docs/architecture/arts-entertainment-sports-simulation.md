# 芸術・娯楽・スポーツシミュレーション設計

## 1. 確定方針

標準では、芸術・娯楽・スポーツを住人の満足度補正だけにせず、文化・産業・組織・個人活動として比較的深く扱う。

- 芸術、音楽、文学、娯楽、競技等が文化・技術・経済・組織・住人の嗜好等から生まれ得る。この列挙は確定済みの全分野ではない。
- 個々の作品、競技、大会、流派等を標準で比較的細かく扱える方向とする。
- 制作者、演者、選手、観客、主催組織、施設、商品・サービス、収益等を既存の住人・職業・組織・企業・市場と接続できるものとする。
- 人気・流行・評判・文化的影響が情報伝播、人間関係、地域・集団の文化等を通じて形成・変化し得る。
- 作品・競技等は歴史的に生まれ、発展・分岐・衰退・復興し得る方向とする。
- 非常に詳細な創作内容そのものや競技ルールの完全再現を全分野で標準要求することはせず、さらに専門的なモデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 作品・競技・大会・流派等の共通状態表現
- 人気・流行・評価の形成モデル
- 制作・上演・競技・観戦等の日常行動との接続
- 施設・設備・商品・興行との接続
- 著作・所有・権利を標準でどこまで扱うか
- 国際・地域間の文化伝播との接続
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

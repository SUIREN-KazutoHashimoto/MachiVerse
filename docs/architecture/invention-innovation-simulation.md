# 発明・技術革新シミュレーション設計

## 1. 確定方針

標準では、条件を満たした社会へ技術が自動解禁されるだけのモデルにはせず、実際の住人・組織から発明・発見が生じ得るものとする。

- 既存知識、必要性、研究・試行、利用可能資源等が発明・発見へ影響し得る。この列挙は確定済みの全要因ではない。
- 発明・発見は住人または組織に帰属し得て、成立後は情報・教育・人間関係・組織・市場等を通じて他者へ伝播し得る。
- `technology-simulation.md` の細粒度技術単位と個人単位知識の方針に従い、「技術が世界に存在すること」と「誰が知っているか・使えるか」を分離する。
- 発明・革新は需要、経済、資源、戦争、文化、教育等と相互作用できるものとする。
- 研究行為・実験・設計・失敗・改良の連鎖を標準で最高詳細度まで常時シミュレーションすることは要求せず、より詳細な研究開発モデルは将来アドオンで拡張できる余地を持たせる。
- 発明・発見に確率的要素を含める場合も、ワールドSeed、World Time、対象・文脈を識別する決定的情報等から結果を導出し、決定論・完全再現性を維持する。

## 2. 今後決定が必要な事項

- 発明・発見の発生判定モデル
- 住人と組織による研究の役割分担
- 試行・失敗・改良を標準でどこまで扱うか
- 新技術と既存技術の依存関係表現
- 発見の独立再発見・同時発生の扱い
- 知識伝播・教育・市場との具体的接続
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 評判・信頼シミュレーション設計

## 1. 確定方針

標準では、社会的評価を単一の評判値だけに集約せず、個人間の信頼と社会的評判をある程度分離して扱う。

- 「AがBをどの程度信用しているか」のような個人間の信頼状態を持てるものとする。
- 個人、企業、組織等について、より広い社会・地域内で形成される評判も表現できる方向とする。
- 実際の経験、観察、情報伝播、噂等によって信頼・評判が変化し得る。
- 信頼・評判は取引、人間関係、雇用、協力、政治、犯罪、情報の受容等へ影響し得る。
- 世界の真の状態と、住人が知っている情報・信じている内容を分離する既存方針と整合させる。
- 話題・分野ごとの非常に細かな評判や情報源ごとの信用を標準で無制限に詳細化することは要求せず、必要に応じて将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 個人間信頼と社会的評判の状態表現
- 経験・情報・噂からの更新モデル
- 信頼・評判の忘却・回復・毀損
- 組織・企業・公的機関等への評判の扱い
- 情報源の信用との接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

# 犯罪・司法・治安シミュレーション設計

## 1. 目的

本書は、MachiVerse における違法行為、犯罪、捜査、逮捕、裁判、処罰、治安機関等と、住人、法、社会制度、組織、経済、建物、政治等との関係に関する要件を整理します。

## 2. 確定事項

- 犯罪・司法・治安を標準でも比較的深くシミュレーションする。
- 犯罪を世界状態と無関係に一定確率で発生するだけのランダムイベントとして扱うことを標準とはしない。
- 住人が利益、困窮、価値観、人間関係、機会、法への認識その他の状態から、違法となり得る行為を選択する可能性を持てる設計とする。ただし具体的な犯罪意思決定要因は今後定義する。
- 行為そのものへ世界共通かつ絶対的な「犯罪」属性を固定することを標準とはせず、その社会・地域に適用される法、慣習、制度等によって違法性・扱いが異なり得るものとする。
- 警察、裁判所、刑務所等に相当する治安・司法機能を、世界内の組織、建物、職業、人員、予算等と接続できるものとする。
- 捜査、逮捕、裁判、処罰等はある程度実体を持つ標準モデルとし、単一の治安値や犯罪率だけですべてを処理することを標準とはしない。
- 一件ごとの司法手続や捜査技法等を世界全域で常時最高詳細度に再現することは標準要件としない。
- より詳細・特殊な刑法、裁判制度、捜査、刑罰、治安制度等は将来アドオンで拡張できることを設計上考慮する。
- アドオン拡張を考慮することは、現時点で具体的なアドオンAPI、プラグイン機構、拡張ポイント等を確定することを意味しない。
- 犯罪・司法・治安にランダム性を含める場合も、MachiVerseの決定論・完全再現性の原則に従う。

## 3. 行為と違法性の分離

標準では、行為自体の発生と、その行為が特定社会において違法・犯罪として扱われるかを概念上分離できるものとします。

同一または類似する行為であっても、地域、時代、法制度、慣習、統治主体等によって合法・違法や処遇が異なり得る設計を目指します。

法や制度が歴史的に変化した場合、それまで合法だった行為が違法になる、またはその逆が生じ得る余地を持たせます。具体的な法表現・適用判定モデルは `politics-governance-simulation.md` と整合させて今後定義します。

## 4. 住人の意思決定との関係

違法となり得る行為は、住人から切り離された統計イベントだけではなく、住人の意思決定から発生し得るものとします。

利益、生活上の困窮、価値観、人間関係、機会、リスク認識、法や規範への認識等は影響要因の候補ですが、この列挙を確定済みの入力項目とはしません。

また、特定条件を満たした住人が必ず犯罪を行うような単純決定規則を標準とはせず、`resident-behavior.md` の個人意思決定方針と整合させます。

## 5. 治安・捜査

治安維持や捜査を、地域ごとの単一数値だけで完結させることを標準とはしません。

治安・捜査を担う組織、人員、職業、施設、予算、装備等を世界内の状態と接続できるものとし、それらの能力・配置・活動が治安や事件対応へ影響できる方向とします。

事件の認知、通報、捜査、証拠、容疑、逮捕等をどの粒度で標準モデルへ含めるかは今後定義します。

## 6. 司法・処罰

裁判・司法判断・処罰等についても、単に違法行為が発生した時点で固定ペナルティを即時適用するだけのモデルを標準とはしません。

司法機関、適用法、当事者、事件情報等との関係を持ち、捜査・逮捕・司法判断・処罰等が一定の過程を持てる設計を目指します。

ただし、現実のあらゆる訴訟手続、証拠法、刑事手続、刑罰制度等を標準で完全再現することは要求しません。

## 7. 他システムとの接続

犯罪・司法・治安は、住人の生活、所有・権利、経済、組織、建物、政治・統治、人間関係等と相互作用できるものとします。

例えば窃取等による物理的占有の変化と社会制度上の所有権が一致しない状態は、`property-rights-simulation.md` の物理的状態と社会的権利を分離する方針と整合させます。

治安悪化や司法制度への信頼等が移住、経済活動、政治等へ影響する可能性もありますが、具体的な影響項目・計算モデルは今後定義します。

## 8. 標準モデルとアドオン

標準では、法・制度が実際の住人行動や社会へ意味を持ち、違反時に世界側が反応できる程度まで犯罪・司法・治安を比較的深く扱います。

一方で、刑法各論、詳細な訴訟手続、証拠法、捜査技法、刑務所運営等を無制限に細分化することは標準要件としません。

より高度・特殊・詳細な刑法、裁判制度、捜査、刑罰、治安制度等は将来アドオンで拡張できる余地を持たせます。ただし、そのために標準モデルの性能、決定論、既存要件、コンポーネント独立性を犠牲にしてまで過度に抽象化することは求めません。

## 9. 決定論

住人の違法行為選択、事件の発覚、捜査、司法判断その他に確率的要素を含める場合も、ワールドSeed、World Time、対象・文脈を識別する決定的情報等から結果を導出し、処理速度、スレッド順序、OS時刻等によって結果が変化してはなりません。

同一の完全再現性条件では、犯罪・司法・治安の状態変化も再現可能でなければなりません。

## 10. 今後決定が必要な事項

- 標準で扱う違法行為・事件の粒度
- 法・慣習・規範と違法性判定の関係
- 住人が法や規範をどの程度認識するか
- 犯罪・違法行為に関する意思決定モデル
- 被害者・目撃者・通報等の扱い
- 事件の発覚・未発覚のモデル
- 捜査・証拠・容疑・逮捕等の標準粒度
- 治安機関の組織・人員・設備・予算との接続
- 裁判・司法判断の標準粒度
- 刑罰・処遇の標準範囲
- 民事紛争と刑事・治安の境界
- 権利紛争と司法・実力支配の関係
- 犯罪組織等と一般組織モデルの関係
- 治安・司法への社会的信頼等を扱うか
- 事前歴史シミュレーションでの簡略化範囲
- 詳細シミュレーション領域外での簡略化範囲
- 標準モデルと将来アドオン拡張の具体的な境界

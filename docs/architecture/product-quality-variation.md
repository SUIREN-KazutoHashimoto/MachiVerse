# 製品品質・個体差シミュレーション設計

## 1. 確定方針

標準では同種の製品が常に完全に同一品質であるとは仮定しない。

- 製造技術、設備、材料、作業者等によって製品・ロット等の品質差が生じ得る。この列挙は確定済みの全品質要因ではない。
- 品質差は価格、評判、故障率、耐久性、消費者の商品選択等へ影響し得る。
- 製造工程・品質管理・歩留まりと接続する。
- 同種品を常に一個ずつ独立Entityとして保持することは要求せず、既存の物品・製品の実体性方針に従って必要な単位で集約できるものとする。
- 個々の製品へ詳細な製造誤差・性能値・使用履歴を広範に持たせることは標準要件として固定せず、より詳細な個体追跡は将来アドオンで拡張できる余地を持たせる。
- 品質差に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 品質状態の標準表現
- 個品・ロット・在庫単位の使い分け
- 材料・設備・技能等から品質への影響モデル
- 品質検査・不良判定との接続
- 品質と価格・評判・故障率の具体的関係
- 中古品・修理品等をどこまで区別するか
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

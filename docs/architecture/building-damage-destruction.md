# 建物損傷・破壊シミュレーション設計

## 1. 確定方針

標準では建物を単一耐久値だけで扱わず、損傷状態をある程度区別する。

- 一部損傷、使用不能、修復、倒壊等を区別できる方向とする。
- 火災、災害、戦争、老朽化等によって状態が変化し得る。
- 建物内部、住人避難、所有・権利、企業活動、インフラ、保守等と接続する。
- 標準では壁・床・柱等の構造部位ごとの損傷と崩壊伝播をC相当の最高詳細度まで常時計算することは要求しない。
- 将来アドオンによってC相当の詳細な構造損傷・崩壊モデルへ拡張できる余地を持たせる。
- アドオン対応を理由として標準の性能・完全再現性・現在要件を損なわない。
- 損傷・破壊の結果も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 建物損傷状態の標準分類
- 部分使用可能性の表現
- 損傷原因ごとの影響モデル
- 修復・建て替えとの関係
- 建物内部との状態同期
- 倒壊物・瓦礫を標準でどこまで扱うか
- 詳細領域外での簡略化
- C相当アドオンとの境界。ただし具体的API・機構は現時点では定義しない

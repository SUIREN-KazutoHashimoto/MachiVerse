# 狩猟・漁業シミュレーション設計

## 1. 確定方針

標準では狩猟・漁業を地域資源から一定量を抽象取得するだけの処理とはせず、住人・組織が実際に対象地域へ到達し、利用可能な手段で資源を獲得する活動として扱う。

- 狩猟者・漁業者は必要に応じて対象地域へ実際に移動する。
- 道具、罠、船その他の手段を利用し得る。この列挙は確定済みの全手段ではない。
- 天候、地形、季節、資源量、技能、知識、設備等が結果へ影響し得る。
- 野生動物・魚類資源の存在量や分布と接続し、乱獲等によって将来の資源量へ影響し得る。
- 取得した獲物・水産物は物品・食料として運搬、保管、加工、販売、消費へ接続する。
- 標準では足跡追跡、詳細な漁場探索、射撃・捕獲過程、漁具特性等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、これらをC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 成否に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 狩猟・漁業活動の標準粒度
- 対象個体・個体群との接続
- 漁場・狩猟場の状態表現
- 捕獲量・成功率に影響する標準要因
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 野生動物シミュレーション設計

## 1. 確定方針

標準では野生動物を地域ごとの単一個体数だけとして扱わず、種ごとの個体群と必要な個体実体を組み合わせて扱う。

- 種ごとに生息域、食料、繁殖、死亡、移動、捕食等によって個体群が変化し得る。この列挙は確定済みの全要因ではない。
- 詳細な世界因果に必要な動物は実際の個体としてフル3D空間を移動できるものとする。
- 世界全域で全ての動物を常時個体化することは標準要件とせず、必要に応じて集約モデルを利用できる。
- 生態系、気候、植生、狩猟、農業、人間活動、災害等と接続する。
- 将来アドオンによって、より広範な大型動物の常時個体化、群れ、縄張り、詳細行動等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 集約・個体化を含む処理も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 種・個体群の標準表現
- 個体化する条件と集約する条件
- 生息域・移動・繁殖・死亡の標準モデル
- 詳細領域と集約領域間の整合
- 人間社会との相互作用
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

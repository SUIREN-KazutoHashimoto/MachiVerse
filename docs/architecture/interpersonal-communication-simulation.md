# 会話・対人コミュニケーションシミュレーション設計

## 1. 確定方針

標準では住人同士の交流を単一の「交流した」イベントだけとして扱わず、接触可能性と目的を伴うコミュニケーションとして扱う。

- 実際に対面可能、または利用可能な通信手段によって接続可能な相手との間でコミュニケーションが成立し得る。
- 情報交換、依頼、交渉、相談、雑談等の異なる目的を表現できる。この列挙は確定済みの全会話目的ではない。
- 会話によって情報・噂・秘密等が伝達され、人間関係、評判・信頼、感情、契約・取引等へ影響し得る。
- 同じ情報を伝えた場合でも、相手が理解・信用・受容するとは限らない。
- 対面会話は物理的位置・知覚・行動と、遠隔会話は通信ネットワーク等と接続する。
- 標準では発話文そのものの生成や全会話履歴・発話意図を自然言語レベルで詳細追跡するC相当を必須としない。
- 将来アドオンによって、発話文生成、詳細な会話履歴・発話意図等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 会話・反応に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 会話内容・目的の標準表現
- 対面・遠隔会話の成立条件
- 情報伝達との接続
- 関係・感情・信頼への影響
- 会話の時間消費・日常活動との関係
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

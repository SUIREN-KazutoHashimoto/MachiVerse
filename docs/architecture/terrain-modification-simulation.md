# 地形改変シミュレーション設計

## 1. 確定方針

標準では世界生成後の地形を完全固定せず、人間活動や自然作用によって変更可能とする。

- 掘削、盛土、採掘、道路・運河・堤防建設等によって地形をある程度変更できるものとする。この列挙は確定済みの全地形改変ではない。
- 地形改変は建設、採掘、交通、水系、災害、軍事、土地利用等と接続する。
- 地形改変後もフル3D世界として整合し、地下空間、トンネル、切土、盛土等を表現できる必要がある。
- 標準では土砂量の厳密な物理追跡、詳細な崩落・堆積・掘削土運搬等をC相当の最高詳細度まで常時扱うことは要求しない。
- より詳細な地盤・土砂・掘削モデルは将来アドオンでC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準の性能・完全再現性・現在要件を損なわない。
- 地形改変も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 地形表現方式
- 掘削・盛土等の編集単位
- 地盤・岩盤等の区分
- 改変可能深度・規模
- 構造物との境界
- 水系との相互作用
- 詳細領域外での簡略化
- C相当アドオンとの境界。ただし具体的API・機構は現時点では定義しない

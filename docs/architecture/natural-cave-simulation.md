# 自然洞窟生成シミュレーション設計

## 1. 確定方針

標準では洞窟を必要時に無関係なランダム配置として追加するのではなく、地下地質・水等の自然条件と接続して形成する。

- 地質、水その他の自然条件から自然洞窟・地下空洞が世界生成時に形成され得るものとする。
- 長期的な自然変化によって洞窟・地下空洞が形成・変化し得る方向とする。
- 洞窟はフル3D地形の内部空間として成立し、地表を単一床面として扱う方式には依存しない。
- 洞窟内部は住人・動物等の移動、地下水、地下環境、資源、歴史的利用等と接続できるものとする。
- 標準では溶食、鍾乳石、地下河川、洞窟成長等をC相当の最高詳細度まで常時計算することは要求せず、世界因果に必要な範囲で表現する。
- 確率的要素を含む場合もWorld Seed等に基づく決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 洞窟生成に利用する自然条件
- 洞窟形状・規模・密度の生成方式
- 地下水・河川との接続
- 洞窟の長期的変化の標準粒度
- 生態系・住人利用との接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

# 副産物・生産廃棄物シミュレーション設計

## 1. 確定方針

標準では製造・採掘・精錬等から目的製品だけが生成されるとは仮定せず、必要に応じて副産物・生産廃棄物を発生させる。

- 製造、採掘、精錬その他の工程から副産物、残渣、廃棄物等が発生し得る。
- 発生物は処理、保管、輸送、販売、再利用、再加工、廃棄等の対象になり得る。
- 副産物・廃棄物は汚染源や追加資源として社会・環境へ影響し得る。
- 製造工程、材料、物質保存、廃棄物・汚染、物流、企業、再利用・リサイクル等と接続する。
- 標準ではほぼ全工程について詳細な副生成物組成・化学反応を最高詳細度まで常時計算することは要求しない。
- 将来アドオンによって、詳細な副生成物組成・化学反応等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 発生・処理結果も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準で扱う副産物・廃棄物カテゴリ
- 工程ごとの発生モデル
- 品質・有害性・再利用可能性の表現
- 保管・輸送・処理の要件
- 汚染・環境影響との接続
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

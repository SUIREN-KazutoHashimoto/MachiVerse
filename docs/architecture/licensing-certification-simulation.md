# 資格・免許・社会的認定シミュレーション設計

## 1. 確定方針

標準では実際の技能・知識を持つことと、社会・制度上その行為を許可されていることを同一視しない。

- 社会・時代によって資格、免許、身分、組織内認定等が存在し得る。
- これらは特定業務、設備、場所、権限等への制度上の許可・制限へ影響し得る。
- 実際の能力があっても制度上許可されない場合、また資格を持っていても実能力が不足する場合を表現できる方向とする。
- 職業、教育、組織、法律・行政、アクセス制御、契約等と接続する。
- 資格・免許制度そのものは社会・歴史によって成立・変化・消滅し得るため、現代的制度を普遍的前提としない。
- 標準では試験制度、更新、監査、資格体系等を最高詳細度まで固定的に扱うことは要求しない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 資格・免許・認定の標準表現
- 発行主体・認定主体の表現
- 取得・失効・取消・更新の扱い
- 業務・設備・区域のアクセス制御との接続
- 違反時の法・組織的結果
- 詳細領域外での簡略化

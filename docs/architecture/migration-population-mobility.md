# 人口移動・移住シミュレーション設計

## 1. 確定方針

標準では人口移動を地域ごとの統計的な人口増減だけで処理せず、実際の住人が移住を判断し、世界内を移動するものとする。

- 仕事、家族、住宅、治安、所得、災害、戦争等が移住判断へ影響し得る。この列挙は確定済みの全要因ではない。
- 移住する住人は、利用可能な交通手段・経路を使って実際に移動する方向とする。
- 移住は住宅、雇用、家族、人間関係、交通、治安、経済、政治、災害等と相互作用できる。
- 移住先での生活条件や社会関係も、その後の定住・再移住等へ影響し得る。
- 難民、集団移住、移民ネットワーク、国境管理、在留制度等を標準で最高詳細度まで扱うことは要求せず、C相当の詳細化は将来アドオンで拡張できる余地を持たせる。
- 標準モデルの性能・決定論・既存要件を、将来の詳細アドオンのために犠牲にしない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 移住判断の具体的要因・重み
- 世帯・家族単位の移住と個人移住の関係
- 住居・雇用確保と移住順序
- 一時移動・季節移動・定住の境界
- 国境・制度による移動制約の標準範囲
- 災害・戦争時の大規模人口移動の簡略化
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 生物多様性・絶滅シミュレーション設計

## 1. 確定方針

標準では種・個体群を世界生成時から永久に固定された存在として扱わず、環境と人間活動によって分布・個体数・存続状態が長期的に変化し得るものとする。

- 生息地破壊、気候変化、乱獲、外来種的侵入、災害、疾病その他の要因によって地域絶滅・世界絶滅が起こり得る。この列挙は確定済みの全要因ではない。
- 条件が改善した場合、再定着や個体群回復が起こり得る。
- 種・個体群の変化は食物網、農業、漁業、狩猟、森林、生態系サービス、人間社会等へ波及し得る。
- 人間は生態系の外部存在ではなく、利用・保護・土地利用・汚染等を通じて生物多様性へ影響する主体として扱う。
- 標準では突然変異、自然選択、種分化等を含む長期進化をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、進化・種分化等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 個体群変動等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 種・個体群の標準状態表現
- 地域絶滅と世界絶滅の判定
- 再定着・回復モデル
- 外来種的侵入を標準でどこまで扱うか
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

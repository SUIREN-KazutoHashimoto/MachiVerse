# 秘密・機密情報シミュレーション設計

## 1. 確定方針

標準では情報を世界全体で公開・非公開の二値だけとして扱わず、誰がその情報を知っているかを世界状態として扱う。

- 秘密・機密情報は限定された住人・組織・役割等の間だけで共有され得る。
- 情報の共有、伝達、漏洩、盗取、諜報、内部告発等によって知識主体の範囲が変化し得る。この列挙は確定済みの全経路ではない。
- 情報へアクセスできる制度上の権限と、実際に情報を知っていることは別概念として扱えるものとする。
- 外交、軍事、犯罪・非公式組織、企業、政治、通信、アクセス権等と接続する。
- 秘密情報が漏洩した場合、その情報が自動的に世界中へ共有されるとは仮定せず、通常の情報伝播経路に従う。
- 標準では暗号方式、諜報技術、情報分類制度等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、暗号方式、諜報技術、詳細な情報分類制度等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 漏洩・発見等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 情報ごとの認知主体の標準表現
- 組織内共有・権限との関係
- 漏洩・諜報・内部告発等の標準モデル
- 秘密の部分的開示をどこまで扱うか
- 情報媒体・通信との接続
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

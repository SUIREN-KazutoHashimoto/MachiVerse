# 人間・野生動物衝突シミュレーション設計

## 1. 確定方針

標準では野生動物による被害を単なる地域ペナルティとしてのみ扱わず、野生動物と人間の生活圏・生産活動が実際に衝突する現象として扱う。

- 野生動物が農地へ侵入する、家畜を襲う、人を攻撃する、集落・都市へ入り込む等が実際の行動として起こり得る。この列挙は確定済みの全衝突形態ではない。
- 住人・組織は防除、駆除、保護、柵・設備の設置、移住その他の対応を取り得る。この列挙は確定済みの全対応ではない。
- 衝突の発生は動物の分布・行動、生息地、食料、季節、土地利用、人間活動等と接続する。
- 被害は農業、畜産、健康、安全、経済、世論、行政等へ波及し得る。
- 保護や駆除の方針は社会・文化・制度によって異なり得る。
- 標準では個体ごとの高度な学習、人間回避、詳細な縄張り行動等をC相当の最高詳細度まで必須としない。
- 発生や行動に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 衝突イベントの標準粒度
- 野生動物行動との接続
- 農業・畜産被害の状態表現
- 防除・駆除・保護の効果
- 詳細領域外での簡略化

# 水・上下水道シミュレーション設計

## 1. 確定方針

標準では、水を地域ごとの供給量だけに抽象化せず、自然水系・施設・生活・産業と接続する。

- 河川、湖、地下水等からの取水を世界状態と接続できるものとする。この列挙は確定済みの全水源ではない。
- 取水、供給、利用、排水、処理を因果的につなげられる方向とする。
- 水供給施設や管路等を世界内の設備・インフラとして扱えるものとする。
- 水不足、汚染、設備障害等が住人の生活、健康、農業、産業、都市等へ影響し得る。
- 水圧、管路流量、漏水、詳細な水処理工程等を工学的に深く扱うモデルは標準では要求せず、将来アドオンによる拡張対象とする。
- 標準モデルの性能・決定論・既存要件を、将来の詳細アドオンのために犠牲にしない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準水源・給排水設備の分類
- 供給能力・需要・貯水の粒度
- 水質・汚染との接続
- 排水・下水処理の標準粒度
- 水道が存在しない社会・時代の水利用
- 災害・停電等による機能停止
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 相続シミュレーション設計

## 1. 確定方針

標準では住人の死亡時に財産を機械的に均等分配せず、社会・時代・制度・関係に応じた継承過程として扱う。

- 財産、債務、権利等は、その社会の法、慣習、契約、家族関係等に応じて継承され得る。
- 相続人不在、相続争い、未確定状態、受領拒否等が起こり得る方向とする。
- 所有権、契約、債務、家族、税、公的記録、司法等と接続する。
- 相続結果は世代間の資産・地位格差へ影響し得る。
- 標準では詳細な遺言制度、相続順位、遺産管理、相続税、詳細な相続紛争手続等をC相当の最高詳細度まで必須としない。
- 社会ごとに異なる制度を許容し、現代的な相続法を普遍的前提としない。
- 判断・分配等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 継承対象となる財産・債務・権利の標準表現
- 相続人候補の決定方法
- 相続未確定中の資産管理
- 紛争・司法との接続
- 詳細領域外での簡略化

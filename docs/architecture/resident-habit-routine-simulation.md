# 住人の習慣・生活パターンシミュレーション設計

## 1. 確定方針

標準では住人が毎回ゼロから全行動を再計画するのではなく、経験と生活条件から習慣・繰り返し行動を形成できるものとする。

- 通勤、食事、買い物、睡眠、余暇、家事等について習慣・生活パターンが形成され得る。この列挙は確定済みの全習慣ではない。
- 習慣は職業、住居、家族、交通、店舗、健康、文化、季節・時刻等と接続する。
- 環境、仕事、家族、健康、経済状態等の変化によって習慣が崩れたり、新しい習慣へ変化したりし得る。
- 習慣は意思決定コストを抑える通常行動として利用できる一方、必要に応じて目標・緊急事態等によって上書きされ得る方向とする。
- 個人差を持ち、同じ条件の住人が必ず同じ生活パターンになるとは仮定しない。
- 標準では非常に詳細な個人ルーティン学習、心理学的条件付け等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、詳細な習慣学習・条件付け等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 習慣形成等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 習慣・生活パターンの標準表現
- 習慣形成・強化・消失の条件
- 日程・カレンダー・目標との優先関係
- 環境変化による再計画
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

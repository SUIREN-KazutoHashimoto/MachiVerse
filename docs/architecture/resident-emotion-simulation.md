# 住人感情シミュレーション設計

## 1. 確定方針

標準では住人心理を単一の幸福度やストレス値だけへ縮約せず、複数の感情状態が行動・判断へ影響するものとする。

- 喜び、怒り、恐怖、悲しみ、不安等に相当する複数の感情状態を表現できる。この列挙は確定済みの全感情ではない。
- 感情は出来事、記憶、人間関係、身体状態、生活環境等によって変化し得る。
- 感情は意思決定、対人関係、仕事、消費、危険回避等へ影響し得る。
- 同じ出来事に対して全住人が同じ感情反応を示すとは仮定しない。
- 既存の住人心理、記憶、関係、健康、日常活動等と接続する。
- 標準では詳細な心理学理論、複雑な感情混合、長期気分、感情調整等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、それらをC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 感情変化に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準感情状態と表現方法
- 感情の発生・減衰・持続モデル
- 人格・価値観・記憶との関係
- 意思決定への影響方法
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

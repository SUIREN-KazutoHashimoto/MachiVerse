# 書物・文書・知識媒体シミュレーション設計

## 1. 確定方針

標準では保存された知識を社会単位の知識量だけに抽象化せず、知識を保持・伝達する媒体を世界状態と接続する。

- 書物、文書、その他の記録媒体等が知識・情報を保存・伝達する実体として存在し得るものとする。
- 図書館、学校、組織、個人等が知識媒体を保有・利用できる方向とする。この列挙は確定済みの全保有主体ではない。
- 知識媒体へのアクセスは教育、研究、技術伝播、文化、宗教、行政、歴史記録等へ影響し得る。
- 媒体の作成・複製・移動・喪失等を世界内の技術・生産・物流・災害・戦争等と接続できるものとする。
- 個々の版・写本・内容差・劣化・複製履歴等を標準で最高詳細度まで扱うことは要求せず、より詳細な文書史・出版モデルは将来アドオンで拡張できる余地を持たせる。
- 世界の真の履歴と、世界内住人が媒体へ記録した内容は同一視しない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 知識媒体の標準分類
- 媒体に保持する情報・知識の粒度
- 作成・複製・閲覧・伝達の具体モデル
- 読み書き能力・言語との接続
- 所有・アクセス制御・秘密情報との関係
- 媒体の劣化・消失を標準でどこまで扱うか
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

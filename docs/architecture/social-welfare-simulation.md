# 社会保障・福祉シミュレーション設計

## 1. 確定方針

標準では社会保障・福祉を住人への固定補正として扱わず、その社会・時代に存在する制度と財政・行政を接続する。

- 失業給付、年金、生活支援、医療支援等を表現できる方向とする。この列挙は確定済みの全制度ではない。
- 制度が存在する場合、財政、資格条件、行政能力等によって実際の給付・支援が左右され得る。
- 社会保障・福祉制度自体が政治、経済、人口構成、文化、歴史等によって形成・変更・廃止され得る方向とする。
- 支援は住人の所得、健康、消費、就業、居住等へ影響し得る。
- 特定の現代的福祉国家モデルを全世界へ固定適用しない。
- 給付制度ごとの非常に詳細な条件・審査、複雑な社会保険制度等を標準で最高詳細度まで扱うことは要求せず、より詳細な制度は将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準で表現する支援制度の粒度
- 資格条件・給付額等の状態表現
- 行政による申請・認定をどこまで扱うか
- 財政・税・公的保険との具体的接続
- 不正・漏給等をどこまで扱うか
- 制度が存在しない社会での相互扶助との関係
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

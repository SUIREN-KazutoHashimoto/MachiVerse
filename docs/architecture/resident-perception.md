# 住人の知覚シミュレーション設計

## 1. 確定方針

標準では、周辺で発生した出来事を距離だけで住人へ自動通知せず、住人が実際に知覚可能だったかをある程度考慮する。

- 視覚では視界、遮蔽物、距離、明るさ等を考慮できるものとする。
- 聴覚では距離や音の到達等を考慮できるものとする。
- 実際に見聞きできた出来事が、`information-communication-simulation.md` の住人ごとの情報・認識へ接続する。
- 建物内部、地形、天候、火災・煙、日常行動等と知覚を接続できるものとする。
- 世界の真の状態と、住人が知覚・認識した状態を分離する既存方針を維持する。
- 視野角、詳細な音響、嗅覚、細かな注意対象等まで深く扱うモデルは標準では要求せず、将来アドオンによる拡張対象とする。
- 標準モデルの性能・決定論・既存要件を、将来の詳細アドオンのために犠牲にしない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 視覚・聴覚の標準計算粒度
- 視界判定・遮蔽判定の方式
- 光・暗所の標準表現
- 音源・音到達の抽象度
- 注意・認識・記憶との境界
- 視覚・聴覚以外の感覚を標準でどこまで扱うか
- 詳細領域外での知覚簡略化
- 標準と将来アドオンの境界

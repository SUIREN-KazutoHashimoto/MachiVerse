# 家族・世代・遺伝シミュレーション設計

## 1. 目的

本書は、MachiVerse における家族関係、親子関係、出生、世代交代、世代間継承、必要十分な範囲の遺伝的要素に関する要件を整理します。

## 2. 確定事項

- 親子関係を世界内の実体的な関係として扱えるものとする。
- 出生によって次世代の住人が実際に増え、世代交代が進む設計とする。
- 家系・血縁関係が複数世代にわたって継続・分岐し得るものとする。
- 財産、文化、言語、知識、社会的立場その他が世代間で伝わり得る設計とする。ただし、それぞれの具体的な継承条件は今後定義する。
- 遺伝については、容姿や身体的傾向等、世界シミュレーション上必要十分な範囲を標準で扱う方向とする。
- 詳細な遺伝学・遺伝子レベルのシミュレーションは標準要件とせず、より深いモデルは将来アドオンで拡張できる余地を持たせる。
- 出生、遺伝的特徴、世代間継承等に確率的要素を含める場合も、MachiVerse の決定論・完全再現性の原則に従う。

## 3. 家族・親子関係

家族を単なる同居人数や世帯サイズの集約値として扱うことを標準とはせず、必要な範囲で個人同士の親子・家族関係と接続できる設計を目指します。

婚姻、養子、同居、扶養その他の家族制度を標準でどこまで扱うかは今後定義し、特定の家族制度を世界共通の絶対形として固定しません。

## 4. 世代間継承

財産・権利、文化、言語、宗教、知識、社会的地位等は、親子・家族・社会制度等を通じて世代間に影響を与え得るものとします。

ただし、「親が持つ状態を子が自動的にコピーする」単純モデルを標準とはせず、制度、教育、家庭環境、社会環境、本人の経験等との因果関係を今後詳細化します。

## 5. 遺伝

遺伝的要素は、住人の容姿や身体的傾向等を自然に世代継承させるための必要十分な範囲を標準とします。

遺伝子配列、分子遺伝学、極めて詳細な遺伝疾患等を標準で完全再現することは要求しません。

## 6. 今後決定が必要な事項

- 標準で扱う家族・親族関係の種類
- 出生条件・出生間隔等の具体モデル
- 家族形成・解消の具体モデル
- 世帯と家族の関係
- 財産・権利の相続との接続
- 文化・言語・宗教・知識の世代間伝達
- 社会的地位・職業等の世代間影響
- 遺伝対象とする身体的特徴の具体範囲
- 養子等の非血縁的親子関係をどう扱うか
- 事前歴史シミュレーションでの簡略化範囲
- 詳細シミュレーション領域外での簡略化範囲
- 標準モデルと将来アドオン拡張の具体的な境界

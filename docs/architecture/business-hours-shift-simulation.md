# 営業時間・営業日・シフトシミュレーション設計

## 1. 確定方針

標準では店舗・施設等を常時利用可能とはせず、社会的な営業時間・営業日・勤務シフトによって利用可能性が変化するものとする。

- 店舗、役所、学校、工場、医療施設等は営業時間・営業日・シフト等を持ち得る。この列挙は確定済みの全施設ではない。
- 利用可能時間は社会の暦、文化、制度、人員状況、需要、組織方針等によって変化し得る。
- 営業中であっても担当者不在、設備故障、混雑、災害等によって実効的に利用できない場合がある。
- カレンダー・予定、日常活動、雇用、待ち行列、施設利用等と接続する。
- 標準では非常に詳細な勤務表、交代制、臨時営業、予約枠管理等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、詳細な勤務表・交代制・臨時営業・予約枠管理等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 時刻・予定処理は世界時間・社会的カレンダーの既存原則と整合し、決定論・完全再現性を維持する。

## 2. 今後決定が必要な事項

- 営業時間・営業日の標準表現
- 勤務シフトとの関係
- 休日・文化・制度との接続
- 臨時休業・延長営業等の扱い
- サービス容量・予約との接続
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

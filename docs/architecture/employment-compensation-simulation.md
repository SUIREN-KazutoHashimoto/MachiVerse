# 雇用関係・賃金シミュレーション設計

## 確定方針

標準では職業フラグと定期収入だけで雇用を表現せず、住人と雇用主体の間に実際の雇用関係を持たせる。

- 仕事内容、勤務時間、報酬・賃金、勤務地等を雇用関係に関連付けられる。
- 雇用、解雇、退職、賃金不払い等が世界内の出来事として発生し得る。
- 実際の勤務・物理作業・日常活動・企業活動・契約・家計・労働市場と接続する。
- 雇用されているだけで、勤務していない時間について生産が自動発生するとはしない。
- 標準では給与計算、残業、各種手当、詳細な雇用契約条項等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な給与・雇用条件管理へ拡張できる余地を持たせる。
- 社会・時代によって雇用形態は異なり得るため、現代的な雇用制度を普遍的前提としない。
- 調整可能な数値はConfig化し、決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 雇用関係の標準状態
- 賃金支払周期と不払い処理
- 勤務実績と報酬の接続
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

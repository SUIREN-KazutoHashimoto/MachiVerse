# 地下構造物シミュレーション設計

## 1. 確定方針

地下空間をトンネルだけの特例として扱わず、フル3D世界内の通常の空間・構造物として成立させる。

- トンネル、地下室、地下鉄、地下倉庫、鉱山坑道等を三次元の構造物・空間として扱えるものとする。この列挙は確定済みの全地下構造物ではない。
- 地下構造物内部では床・壁・天井・開口部等の必要な空間境界を表現でき、住人や物体が内部を利用・移動できる方向とする。
- 地下構造物は建築・建物内部、交通、物流、採掘、土地・領域、地形改変等と接続する。
- 地表を単一の床面として扱うことで地下空間が成立しなくなる設計は不可とする。
- Simulation Coreの権威ある3D状態から、General Viewが地下空間内部を正しく描画するために必要な状態を取得できることを前提とする。
- 地下都市や巨大地下施設も標準モデルの組み合わせによって表現可能な方向とするが、その専用の高度な環境制御モデルまで自動的に標準要件とはしない。
- 具体的な地形・構造物データ構造は現時点では確定しない。

## 2. 今後決定が必要な事項

- 地形と人工地下構造物の境界表現
- 地下構造物の空間粒度
- 建設・掘削工程との接続
- 地下交通経路の表現
- 所有・行政領域との関係
- General Viewへ公開する地下3D状態
- 詳細領域外での簡略化

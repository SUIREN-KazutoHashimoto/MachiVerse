# 一般事故シミュレーション設計

## 確定方針

標準では戦争・災害・疾病以外の通常生活が常に安全であるとはせず、日常活動や作業に伴う事故を因果的に扱う。

- 転倒、作業事故、落下、機械事故その他の一般事故が発生し得る。この列挙は網羅ではない。
- 事故発生可能性は環境、行動、技能、疲労、健康、設備状態、安全設備等から影響を受け得る。
- 事故は負傷、物品・設備損傷、作業中断、救急対応等につながり得る。
- 物理移動、職業安全、作業品質、設備劣化、住人健康、救急・医療等と接続する。
- 標準では詳細な事故力学や身体への衝撃計算をC相当まで必須としない。
- 事故判定に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 一般事故の標準分類と状態遷移
- リスク要因の合成方法
- 負傷・物損への接続
- 詳細領域外での簡略化

# 建設途中状態シミュレーション設計

## 1. 確定方針

標準では構造物を完成時まで世界から隠し、完成瞬間に出現させる方式を採らない。

- 建設途中の基礎、骨組み、壁、未完成道路・設備等を必要に応じて実際の世界状態として保持する。
- 建設途中状態はフル3D空間上に存在し、通行可能性、安全性、作業、景観、周囲の利用等へ影響し得る。
- 完成前の部分を住人・車両等が無条件に完成物として利用できるとは仮定しない。
- 建設の進捗によって世界の物理状態が段階的に変化する方向とする。
- 建設途中で中止・放棄された場合、その時点の構造物が廃墟・歴史的痕跡として残り得る。
- 建設工程、建物内部、物理移動・衝突、事故・安全、解体等と接続する。
- 仮設足場・資材山・施工機械配置等を標準で最高詳細度まで常時表現することは要求せず、必要な世界因果を優先する。
- 状態変化は決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 工程進捗から3D構造状態への反映方式
- 建設途中状態の空間粒度
- 未完成部分の通行・利用・衝突判定
- 建設中事故・安全性との接続
- 中止・放棄時の状態遷移
- 詳細領域外での簡略化

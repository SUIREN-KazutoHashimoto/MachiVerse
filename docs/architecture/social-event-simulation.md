# 集会・祭り・観戦等の社会イベントシミュレーション設計

## 1. 確定方針

標準では集会・祭り・スポーツ観戦等を地域への抽象的効果だけとして扱わず、場所・時間・参加者を伴う実際の社会イベントとして扱う。

- イベントは開催場所・時間を持ち、参加する住人は必要に応じて実際に会場へ移動する。
- 参加・不参加は住人の関心、文化、関係、費用、距離、予定、情報認知等によって変化し得る。
- イベントは消費、交通・混雑、人間関係、情報伝播、治安、企業活動等へ影響し得る。
- 芸術・娯楽・スポーツ、宗教・文化、政治・集団行動等の既存システムと接続する。
- 標準では会場座席、入退場管理、詳細な進行プログラム等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、会場座席・入退場管理・詳細なイベント進行等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- イベント参加等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- イベントの標準状態・分類
- 主催者・会場・参加者の関係
- 参加意思決定
- 容量・混雑・サービスとの接続
- 中止・延期・途中離脱の扱い
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

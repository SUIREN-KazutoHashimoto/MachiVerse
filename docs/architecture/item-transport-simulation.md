# 物品運搬シミュレーション設計

## 1. 確定方針

標準では在庫間の物品移動を単なる時間付き転送として扱わず、住人・車両等が物品を実際に運搬する。

- 住人、車両その他の運搬主体が物品を積載・携行し、三次元空間を移動して目的地へ運ぶ。
- 運搬中の物品は送信元在庫から即座に目的地在庫へ存在移行した扱いにはしない。
- 積載容量、利用可能な運搬手段、経路、交通状態、荷役等が運搬へ影響し得る。この列挙は確定済みの全要因ではない。
- 物流、在庫、企業活動、日常行動、物理移動、車両等と接続する。
- 標準では箱・荷物等の物理配置、積み方、重心、荷崩れ等をC相当の最高詳細度まで常時計算することは要求しない。
- 将来アドオンによって、積載配置・重心・荷崩れ等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 運搬処理も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 運搬中物品の標準状態表現
- 積載容量・重量等の標準粒度
- 荷役・積み替え処理
- 複数運搬主体間の引き渡し
- 運搬中の破損・紛失等をどこまで扱うか
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

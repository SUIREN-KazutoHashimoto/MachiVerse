# 予定・約束・予約シミュレーション設計

## 確定方針

標準では未来の行動をその時点になって初めて決定するだけでなく、住人・組織が未来時刻に対する予定・約束・予約等を保持できる。

- 仕事、診療、会合、交通、社会イベント等に未来の予定を設定し得る。この列挙は網羅ではない。
- 複数の予定が競合した場合、調整、遅刻、欠席、キャンセル等が起こり得る。
- 予定は日常活動、社会カレンダー、待ち行列・予約枠、交通、雇用、医療、イベント、対人関係等と接続する。
- 移動時間や予期しない出来事によって予定どおりに到着・実行できない場合がある。
- 標準では複雑な参加者間スケジューリングや高度なカレンダー最適化をC相当まで必須としない。
- 将来アドオンでC相当の詳細なスケジュール調整へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 予定・約束・予約の標準状態
- 競合解決と優先順位
- 遅刻・欠席・キャンセル処理
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

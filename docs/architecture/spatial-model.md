# 空間モデル設計

## 1. 目的

本書は、MachiVerse の世界シミュレーションにおける空間表現の上位要件を定義します。

## 2. 基本前提

MachiVerse の標準シミュレーションは **フル3D** で行います。

これは一般ビュー上の表示だけを3D化するという意味ではなく、シミュレーションコアが扱う世界モデル自体を三次元空間として成立させることを意味します。

世界を構成する対象の位置、空間的関係、環境との関係等を設計する際は、2D平面だけで完結することを標準前提にしません。

## 3. 設計上の意味

フル3Dであることは、今後の世界モデル、自然環境、居住、移動、構造物その他の空間を伴う要素を設計する際の共通前提とします。

ただし、フル3Dという要件だけを根拠として、以下を自動的に確定してはなりません。

- 使用する3Dエンジンまたは描画エンジン
- 物理エンジンの採用有無
- 物理演算の精度
- 座標系
- 単位系
- 浮動小数点表現
- 空間分割方式
- 衝突判定方式
- 地形表現方式
- 高さ表現方式
- メッシュ、Voxel、Heightmap等の具体的データ構造
- GPU利用方式
- 一般ビューのレンダリング方式
- カメラ方式
- VR等の表示・入力方式

これらは性能、完全再現性、世界モデル、アドオン対応その他の要件と合わせて別途設計します。

## 4. 完全再現性との関係

三次元空間を扱う場合も、MachiVerse の標準実装における完全再現性要件を維持します。

同一World Seed、同一設定、同一操作から得られる世界状態が、スレッド実行順、処理速度その他の非決定的な実行要因によって変化してはなりません。

3D座標、空間演算、衝突・接触・距離・範囲等の計算が世界状態へ影響する場合、それらも決定論を維持できるよう設計する必要があります。

具体的な数値表現や演算規則は未確定です。

## 5. アドオンとの関係

将来的なアドオンも、標準の三次元世界へ機能を追加・拡張できることを見据えて設計します。

ただし、アドオン対応のためだけに標準空間モデルを過剰に抽象化したり、現在の性能・完全再現性・コンポーネント独立性を犠牲にしたりしません。

アドオン向けの具体的な3D空間API、拡張ポイント、データアクセス方式は未確定です。

## 6. 現時点で確定している事項

- MachiVerse の標準シミュレーションはフル3Dとする。
- 3Dは表示だけではなく、世界シミュレーションの空間モデルそのものに適用する。
- 標準世界モデルを2D平面のみで成立する前提にはしない。
- フル3Dであっても標準実装の完全再現性要件を維持する。
- 具体的な3D技術、座標系、物理方式、描画方式は未確定とする。

## 7. 今後決定が必要な事項

- 座標系と原点・軸の定義
- 世界空間の単位系
- 座標・回転・尺度等の数値表現
- 空間の範囲と精度
- 地形・地下・水域・空中等の具体的な空間表現
- 空間検索・空間分割方式
- 3D空間演算の決定論保証方式
- 必要な衝突・接触等の扱い
- Simulation CoreとGeneral View間で公開する3D状態の範囲
- 3D空間に対するアドオン拡張境界

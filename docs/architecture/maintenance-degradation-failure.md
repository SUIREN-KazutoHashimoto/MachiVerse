# 故障・老朽化・保守シミュレーション設計

## 1. 確定方針

標準では、建物・機械・車両・インフラ等が建設・製造後に永続的に新品性能を維持するモデルにはしない。

- 使用、時間経過、環境、事故等によって劣化・故障し得るものとする。
- 点検、修理、交換、保守等によって状態を維持・回復できる方向とする。
- 保守には人員、技能、部品・資材、設備、時間、費用等が必要になり得る。
- 保守不足や故障は停電、断水、交通障害、事故、生産低下、通信障害その他へ波及し得る。
- 建物、交通、企業・生産、電力・通信、水道、医療、軍事等と接続する。
- 部品単位の詳細な故障モード、寿命分布、保全工学等を標準で最高詳細度まで扱うことは要求せず、より詳細な保守・信頼性モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 劣化・耐久状態の標準表現
- 対象ごとの故障粒度
- 使用量・環境・経年の影響モデル
- 点検・修理・交換の判断モデル
- 部品・資材・技能との接続
- 故障による事故・二次障害の扱い
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 通信ネットワークシミュレーション設計

## 1. 確定方針

標準では通信技術を獲得しただけで距離・設備に関係なく即時通信できるとは仮定せず、利用可能な通信手段と物理・社会インフラを介して情報が伝達されるものとする。

- 郵便、電信、電話、無線、デジタル通信等の通信手段を、社会・時代・技術に応じて表現できる。この列挙は確定済みの全通信手段ではない。
- 通信可能性、遅延、到達範囲、容量等は、設備、ネットワーク、距離、障害、運用状態等によって変化し得る。
- 通信設備・ネットワークは世界内インフラとして、建設、保守、電力、所有、組織等と接続する。
- 障害・災害・戦争・設備故障等によって通信が遅延・遮断・劣化し得る。
- 情報・通信、マスメディア、行政、企業、軍事、住人の日常活動等と接続する。
- 標準では通信パケット、周波数、交換機、ルーティング等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、通信パケット、周波数、交換機、詳細ルーティング等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 通信伝達も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 通信手段・ネットワークの標準表現
- 遅延・容量・到達範囲のモデル
- 物理設備と論理的接続関係
- 障害・復旧の扱い
- 情報伝播モデルとの接続
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

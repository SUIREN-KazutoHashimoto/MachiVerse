# 土地・生態系の劣化と回復シミュレーション設計

## 1. 確定方針

標準では、土地・生態系を世界生成時から固定された背景として扱わず、人間活動と自然条件によって長期変化する状態として扱う。

- 土壌劣化、森林減少、砂漠化、汚染蓄積、生態系回復等が起こり得るものとする。この列挙は確定済みの全環境変化ではない。
- 農業、資源採取、都市化、汚染、気候、災害その他の要因と相互作用できるものとする。
- 劣化だけでなく、利用圧の低下、自然回復、人為的な保全・復旧等による回復も表現できる方向とする。
- 土地・生態系状態の変化は食料生産、資源、健康、居住、経済、人口等へフィードバックし得る。
- 生物種間相互作用、詳細な植生遷移等を標準で最高詳細度まで扱うことは要求せず、より詳細な生態系モデルは将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 土地・生態系状態の標準指標
- 劣化・回復速度と条件
- 農業・森林・水・汚染との具体的接続
- 保全・復旧活動の扱い
- 気候変動との相互作用
- 生物多様性を標準でどこまで扱うか
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

# 組織の役職継承シミュレーション設計

## 1. 確定方針

標準では国家、企業、宗教組織その他の組織における重要役職の交代を即時ランダム置換として扱わず、制度・慣習・権力関係に応じた後継過程として扱う。

- 指導者・重要役職が死亡、辞任、失脚等によって空席になり得る。
- 選挙、任命、世襲、内部競争等、組織・社会・時代に応じた後継方法が存在し得る。この列挙は確定済みの全方式ではない。
- 後継過程は組織内の役割、権限、関係、評判、派閥、法・慣習等と接続し得る。
- 継承の遅延・失敗・対立によって組織機能低下、分裂、権力闘争等が発生し得る方向とする。
- 政治、企業、宗教、軍事、犯罪・非公式組織等と接続する。
- 標準では詳細な選挙手続、派閥工作、候補者選定、就任手続等をC相当の最高詳細度まで必須としない。
- 判断・競争等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 重要役職・空席状態の標準表現
- 組織ごとの後継規則表現
- 複数候補の競合処理
- 継承中の権限・意思決定
- 組織分裂・継続性との接続

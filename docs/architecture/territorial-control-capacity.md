# 国家・組織の地理的支配能力シミュレーション設計

## 確定方針

標準では領有・支配を宣言した土地で、その国家・組織の制度が自動的かつ完全に機能するとはしない。

- 法的領域、主張する領域、実効支配を区別する。
- 実効的な支配能力は人員、施設、交通、通信、治安、軍事、情報、地理条件等に依存し得る。この列挙は網羅ではない。
- 遠隔地、戦争地域、治安悪化地域、交通困難地域等では徴税、警察、行政、情報収集その他の能力が弱まる・失われる場合がある。
- 同じ地域でも行政・治安・徴税・軍事等の機能ごとに支配能力が一致しない場合があり得る。
- 領域・境界、政治・行政、徴税、治安、軍事、交通、通信、国境、統計等と接続する。
- 標準では地域・行政機能ごとの支配能力をC相当の最高詳細度まで必須としない。
- 将来アドオンでC相当の詳細な地域別行政・統治能力へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 実効支配能力の標準表現
- 機能別能力の粒度
- 領域状態との接続
- 支配能力の拡大・縮小過程
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

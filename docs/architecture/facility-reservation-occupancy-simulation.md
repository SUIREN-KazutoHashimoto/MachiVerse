# 建物・設備の利用予約と占有シミュレーション設計

## 1. 確定方針

標準では部屋・設備等を無制限に同時利用できるとはせず、利用可能数・占有・予約・権限による競合を扱う。

- 部屋、ベッド、机、機械、会議室等は必要に応じて同時利用可能数や占有状態を持つ。この列挙は確定済みの全対象ではない。
- 利用競合は予約、先着、権限、組織ルール等によって解決され得る。
- 利用中の資源は他の住人・組織から利用できない、または利用条件が変化し得る。
- 建物内部、医療、宿泊、教育、製造、企業活動、待ち行列・サービス容量等と接続する。
- 標準では座席・机・ベッド等の詳細な割当最適化や複雑な予約運用をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、詳細な割当最適化、予約運用、資源スケジューリング等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 割当・競合解決に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 占有・予約状態の標準表現
- 利用可能数と容量の関係
- 予約と待ち行列の境界
- 権限・優先順位との関係
- 解放・取消・無断利用等の扱い
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

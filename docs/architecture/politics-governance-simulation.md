# 政治・統治シミュレーション設計

## 1. 目的

本書は、MachiVerse における政治、統治、行政、法、権力、国家等のシミュレーションに関する要件を整理します。

## 2. 確定事項

- 標準でも政治・統治を比較的深くシミュレーションする。
- 国家や自治体等を、単なる領域所有者や固定パラメータの集合としてのみ扱わない。
- 政治・統治は住人、組織、経済、文化、技術、軍事、外交その他の世界要素と相互作用できるものとする。
- 法、税、行政、治安、外交、軍事、権力の移行・競争等は標準モデルで扱う候補とし、世界の因果関係に必要な範囲を標準側へ含める。
- 政治制度や統治組織は、可能な限り過去の社会的・歴史的因果関係を持って形成・変化するものとする。
- 標準モデルは「少し深め」の政治・統治シミュレーションを提供する一方、あらゆる制度・手続きを無制限に詳細化することは目的としない。
- より高度・特殊・詳細な政治制度、統治制度、議会制度等は将来アドオンで拡張できることを設計上考慮する。
- アドオン拡張を考慮することは、現時点で具体的なアドオンAPI、プラグイン機構、拡張ポイント等を確定することを意味しない。
- 政治・統治にランダム性を含める場合も、MachiVerseの決定論・完全再現性の原則に従う。

## 3. 基本方針

政治・統治は、国家ごとにあらかじめ決められた政体ラベルや数値を付与するだけのモデルを標準とはしません。

住人、組織、人間関係、経済活動、文化、技術、地理条件、過去の出来事等との相互作用を通じて、統治のあり方や権力関係が形成・維持・変化し得る設計を目指します。

ただし、標準で保持する政治的状態、制度の表現方法、意思決定主体、権限モデル等の具体的なデータ構造は今後定義します。

## 4. 標準で扱う深さ

標準モデルでは、世界の歴史的因果関係へ大きく影響する政治・統治要素を必要十分以上に扱い、単なる背景設定にはしません。

法、税、行政、治安、外交、軍事、権力競争、指導者・統治主体の交代等は標準範囲の候補です。選挙、世襲、任命その他の権力移行方式についても扱える設計を考慮しますが、現時点で特定方式を必須とはしません。

政治上の決定は経済、組織、住人の生活、技術普及、移住、外交・軍事等へ影響でき、逆にそれらの状態が政治・統治へ影響できるものとします。

## 5. 国家・自治体等の形成と変化

国家、自治体その他の統治主体は、世界生成時に理由なく完成形として配置するだけではなく、事前歴史シミュレーションを含む過去の因果関係から可能な限り形成されるものとします。

統治主体の成立、拡大、縮小、分裂、統合、消滅、制度変化等を表現できる方向とします。ただし、それぞれの具体的な発生条件や領域支配モデルは今後定義します。

国家・自治体と一般的な組織とのモデル上の関係についても今後詳細化し、`organization-simulation.md` と整合させます。

## 6. 標準モデルとアドオン

標準では、政治・統治が世界の因果関係を十分に生み出せる程度まで比較的深く扱います。

一方で、現実に存在する、または仮想的に考えられるあらゆる憲法制度、議会手続、官僚制度、選挙制度、政党制度等を標準で完全再現することは要求しません。

標準範囲を超える詳細な政治制度や特殊な統治モデルは、将来アドオンで追加できる余地を持たせます。ただし、そのために標準モデルの性能、決定論、既存要件、コンポーネント独立性を犠牲にしてまで過度に抽象化することは求めません。

## 7. 決定論

政治的意思決定、制度変化、権力移行、外交等に確率的要素を含める場合も、ワールドSeed、World Time、対象・文脈を識別する決定的情報等から結果を導出し、処理速度、スレッド順序、OS時刻等によって結果が変化してはなりません。

同一の完全再現性条件では、政治・統治の状態変化も再現可能でなければなりません。

## 8. 今後決定が必要な事項

- 標準で扱う政治・統治要素の具体的な一覧
- 法および制度の表現方法
- 税・行政・公共サービスの具体的モデル
- 治安・司法との関係
- 政治的意思決定主体と権限の表現
- 指導者・統治主体の選出・継承・交代モデル
- 住人の政治的意思・支持・参加をどこまで個人単位で扱うか
- 政党、派閥、利益集団等の扱い
- 国家・自治体等と一般組織モデルの関係
- 領域、主権、管轄権等の具体的表現
- 外交・条約・国際関係のモデル
- 軍事・戦争モデルとの境界
- 経済・文化・宗教・技術等との相互作用
- 事前歴史シミュレーションでの政治・統治モデルの簡略化範囲
- 詳細シミュレーション領域外での簡略化範囲
- 標準モデルと将来アドオン拡張の具体的な境界

# 生理的欲求シミュレーション設計

## 1. 確定方針

標準では空腹・飲水・睡眠を一日単位の単純な消費確認にせず、比較的詳細な住人の生理状態と行動として扱う。

- 空腹、喉の渇き、疲労、睡眠欲求等を住人状態として持ち、時間経過・活動・環境等によって変化させる。
- 実際の食事・飲水・睡眠行動によって状態が変化するものとする。
- 食事については単なる食料量だけでなく、栄養素別の摂取・代謝を標準シミュレーション対象に含める方向とする。
- 睡眠については睡眠段階等の内部状態を標準で扱える方向とし、睡眠の量・質が疲労・健康・行動等へ影響し得る。
- 活動量、健康、年齢、環境等による生理的差異を表現できる方向とする。
- 食料・水、健康、日常行動、住居、職業、天候等と相互作用する。
- C相当の比較的深い生理モデルを標準範囲とするが、人体の分子・細胞レベルまで無制限に再現することは要求しない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準の栄養素分類と代謝モデル
- エネルギー消費・活動量との関係
- 水分状態の具体的表現
- 睡眠段階・睡眠品質の標準粒度
- 食事回数・量・内容の意思決定モデル
- 年齢・健康状態等による必要量差
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

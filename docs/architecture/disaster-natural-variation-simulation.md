# 災害・自然変動シミュレーション設計

## 1. 目的

本書は、MachiVerse における地震、噴火、洪水、干ばつ、嵐、山火事等の災害・自然変動と、地形、プレート、気候、水系、植生、建物、人口、物流、経済、政治等との関係に関する要件を整理します。

## 2. 確定事項

- 災害を世界状態と無関係な単発ランダムイベントとしてだけ発生させることを標準とはしない。
- 地震、噴火、洪水、干ばつ、嵐、山火事等を、可能な範囲で既存の自然状態・自然過程から因果的に発生させる方向とする。
- 地形、地殻・プレート、気候、水系、植生その他の自然状態が災害発生や規模へ影響できる設計を目指す。
- 災害は建物・インフラの損傷、死傷、物流停止、食料不足、移住、経済、政治、社会等へ波及し得るものとする。
- 災害後の復旧・再建等も世界内の資源・人員・技術・経済・政治等と接続できる方向とする。
- 標準では比較的深く扱うが、地球科学・気象学の全現象を最高詳細度で常時計算することは要求しない。
- より詳細・専門的な地球科学、気象、災害モデル等は将来アドオンで拡張できる余地を持たせる。
- 災害・自然変動に確率的要素を含める場合も、MachiVerse の決定論・完全再現性の原則に従う。

## 3. 自然状態からの発生

災害は、可能な限り世界生成・自然環境シミュレーションで保持する状態から導出します。

たとえば地震・噴火は地殻・プレート等、洪水は降水・地形・水系等、干ばつは気候・降水等、山火事は気象・植生等と接続できる方向とします。ただし、これらは設計方向の例であり、具体的な発生アルゴリズムや必要状態は今後定義します。

## 4. 社会への波及

災害の影響を被害件数だけの集約値で完結させることを標準とはせず、建物、道路・インフラ、住人、食料、産業、物流等へ影響を伝播できるものとします。

その結果として、人口移動、価格変化、事業停止、行政対応、政治的変化等が起こり得る方向とします。具体的な因果モデルは今後定義します。

## 5. 標準モデルとアドオン

標準では、自然状態と社会状態を因果的につなぐために必要な災害・自然変動を比較的深く扱います。一方で、高精度な連続体解析や専門シミュレーター相当の全現象再現は標準要件としません。

より高度・専門的な災害、地球科学、気象モデル等は将来アドオンで拡張できる余地を持たせます。具体的なアドオンAPI等は現時点では確定しません。

## 6. 今後決定が必要な事項

- 標準で扱う災害・自然変動の具体的な種類
- 各災害の発生条件と自然状態との接続
- 規模・継続時間・空間範囲の表現
- 建物・インフラ・住人への具体的な被害モデル
- 食料・物流・産業・経済・政治等への波及モデル
- 避難・救援・復旧・再建の標準粒度
- 外部簡易シミュレーション領域からの自然影響との接続
- 事前歴史シミュレーションでの簡略化範囲
- 詳細シミュレーション領域外での簡略化範囲
- 標準モデルと将来アドオン拡張の具体的な境界

# 公共施設の供給圏・利用可能性設計

## 確定方針

標準では学校、病院、消防署その他の公共・社会施設が存在するだけで地域全体へ一様な効果を与えるとはしない。

- 施設の利用可能性は実際の位置、交通時間、経路、定員、人員、設備、営業時間、費用、資格等によって変化し得る。この列挙は網羅ではない。
- 施設が存在しても、遠すぎる、経路が途絶している、満員、人員不足、設備故障、閉鎖時間等によって利用できない場合がある。
- 住人は自身が知る施設・経路・利用条件に基づいて利用先を選択し得る。
- 医療、教育、救急、行政、サービス待ち行列、交通、経路知識、営業時間等と接続する。
- 供給圏は固定半径だけでなく、実際の到達可能性・容量によって変化し得る。
- 標準では詳細な施設配置最適化や行政サービス圏計画をC相当まで必須としない。

## 今後決定が必要な事項

- 施設到達可能性の標準評価方法
- 定員・待ち時間との統合
- 複数施設からの選択方法
- 詳細領域外での供給圏簡略化

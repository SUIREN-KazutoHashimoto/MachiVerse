# 作業品質・失敗シミュレーション設計

## 1. 確定方針

標準では必要条件を満たした作業が必ず同品質・同速度で成功するとは仮定しない。

- 技能、知識、道具・設備、材料品質、疲労、健康、環境等によって作業速度・品質・失敗可能性が変化し得る。この列挙は確定済みの全要因ではない。
- 失敗は単純な成功/失敗だけでなく、低品質、やり直し、損傷、資材浪費、事故等の結果を持ち得る方向とする。
- 製造、建設、修理、医療、運転・操縦、保守等の各活動と接続する。
- 同じ住人・同じ作業でも、状態や環境が違えば結果が変わり得る。
- 標準では工程ごとの詳細なヒューマンエラー、操作ミス、認知エラー等を最高詳細度まで固定的に扱うことは要求しない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 作業品質・成功度の標準表現
- 速度・品質・失敗への影響要因
- 失敗結果の分類
- やり直し・修理・事故との接続
- 作業種別ごとの共通モデルと固有モデルの境界
- 詳細領域外での簡略化

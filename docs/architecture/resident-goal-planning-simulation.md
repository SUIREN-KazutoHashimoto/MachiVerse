# 住人の目標・計画シミュレーション設計

## 1. 確定方針

標準では住人がその瞬間の欲求だけから次の単発行動を選ぶのではなく、中長期的な目標を持ち、複数日にまたがる行動を継続・修正できるものとする。

- 仕事を探す、住居を得る、移住する、パートナー形成を望む、事業を始める等の中長期目標を持ち得る。この列挙は確定済みの全目標ではない。
- 目標は住人の欲求、価値観、感情、記憶、関係、経済状態、健康、社会環境等から形成・変更・放棄され得る。
- 目標達成のため複数の行動を時間をまたいで実行し、状況変化や失敗に応じて計画を修正できる方向とする。
- 複数目標が競合し、優先順位が変化し得る。
- 職業、住宅、移住、家族、企業、教育、消費等の各システムと接続する。
- 標準では詳細な階層型計画、全代替案探索、高精度な将来予測等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、より詳細な計画・代替案・将来予測等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 計画選択に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 目標の標準表現と粒度
- 目標生成・優先順位変更・放棄のモデル
- 計画と実際の日常行動との接続
- 失敗・中断・再計画の扱い
- 長期目標を評価する頻度
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

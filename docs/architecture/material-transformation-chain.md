# 原料から製品までの物質連鎖シミュレーション設計

## 1. 確定方針

標準では原料を消費すると完成製品へ直接変換される単純化を避け、必要な中間材・加工工程を世界内の因果として扱う。

- 鉱石→精錬→素材→部品→製品のように、対象技術・製品に応じた中間材と工程を経由する。この例は固定された普遍工程ではない。
- 技術の発展によって利用可能な工程、必要設備、歩留まり、必要材料等が変化し得る。
- 製造工程、材料、設備、労働者、知識・技能、エネルギー、物流、品質等と接続する。
- 中間材は必要に応じて在庫・輸送・取引の対象になり得る。
- 標準ではほぼ全製品について極端に細かなBOM、化学反応、副生成物を完全再現することは要求しない。
- 将来アドオンによって、詳細BOM・化学反応・工程等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 製造・変換結果は決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 中間材・部品の標準粒度
- 技術と製造経路の関係
- 工程選択・代替材料の扱い
- 在庫・物流・市場との接続
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

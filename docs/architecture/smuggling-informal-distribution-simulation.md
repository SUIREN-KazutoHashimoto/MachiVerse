# 密輸・非公式流通シミュレーション設計

## 確定方針

標準では法的に禁止・規制された物品や取引が、規則を設定しただけで世界から物理的に消滅するとはしない。

- 法的禁止・規制と、物理的・社会的な流通可能性を分離する。
- 監視・取締を回避できる場合、密輸、闇市場、非公式流通等が成立し得る。
- 非公式流通には実際の物品、輸送、保管、売買、情報、関係者等が関与し得る。
- 国境・検問、犯罪・非公式組織、市場、物流、情報、賄賂等を含み得る社会関係、司法・治安等と接続する。この列挙は網羅ではない。
- 違法性は社会・時代・地域の制度に依存し、Coreが普遍的な違法カテゴリを固定しない。
- 標準では詳細な隠匿手法、検査回避、地下流通網等をC相当まで必須としない。
- 将来アドオンでC相当の詳細な密輸・地下流通へ拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なわない。

## 今後決定が必要な事項

- 非公式流通の標準状態
- 取締・発見との接続
- 正規市場との価格・供給関係
- C相当の将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

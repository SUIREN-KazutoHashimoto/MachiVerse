# 物質保存シミュレーション設計

## 1. 確定方針

標準では世界因果上重要な資源・材料がシミュレーション都合だけで無根拠に生成・消滅することを避ける。

- 重要な資源・材料について、原則として「どこから来て、どこへ行ったか」を追跡可能な因果関係を維持する。
- 採掘、生産、輸送、在庫、消費、建設、解体、廃棄、再利用等を通じた物質収支が大きく破綻しないようにする。
- 集約表現を利用する場合も、詳細領域との間で資源・材料量が不自然に増減しないよう整合を維持する。
- 標準では微小物質や全成分を対象とする厳密な質量保存を必須とはしない。
- 食品、燃料、水、建材、金属等、どのカテゴリを標準保存対象とするかは今後定義する。
- 数値誤差や丸めが世界状態へ影響する場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準で保存対象とする資源・材料カテゴリ
- 集約・詳細間の量整合方式
- 消費・摩耗・燃焼・汚染等による状態変化の扱い
- 微量損失・丸め・閾値の扱い
- 性能上の集約方式
- 標準と将来アドオンの境界

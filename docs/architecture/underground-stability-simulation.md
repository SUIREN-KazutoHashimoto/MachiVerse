# 地下空間安全性シミュレーション設計

## 1. 確定方針

標準では地下空間を掘削すれば常に永久に安定するとは仮定しない。

- 地質、掘削形状、補強、地下水等によって地下空間の安定性・危険性が変化し得る。この列挙は確定済みの全要因ではない。
- 崩落・浸水等を地下空間に生じ得る事象として扱う。
- 地下空間の事故は住人、交通、採掘、生産、設備、建物・構造物等へ物理的・社会的影響を与え得る。
- 補強・保守等によって危険性を低減できる方向とし、既存の保守・劣化モデルと接続する。
- 詳細な応力解析、支持力計算、岩盤力学等を標準で最高詳細度まで扱うことは要求せず、必要なら将来アドオンで拡張できる余地を持たせる。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 地下安定性の標準状態表現
- 地質・形状・補強等から危険性への影響モデル
- 崩落の空間的結果
- 浸水と地下水・水シミュレーションの接続
- 補強・点検・保守の標準粒度
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

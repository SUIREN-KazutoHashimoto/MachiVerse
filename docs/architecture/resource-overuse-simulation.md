# 資源の過剰利用シミュレーション設計

## 確定方針

標準では各利用主体の採取・利用を独立に処理するだけでなく、複数主体による累積的な利用が共有資源・自然環境へ与える影響を扱う。

- 各主体にとって合理的な利用であっても、集合的には乱獲、過放牧、森林減少、水不足等を引き起こし得る。この列挙は網羅ではない。
- 過剰利用は資源量、生態系、産業、生活、価格、移住等へ波及し得る。
- 共同管理、慣習、規制、利用抑制、技術変化等によって持続利用・回復につながる場合もある。
- 資源枯渇・再生、生態系劣化・回復、共有資源、漁業・狩猟、農業、行政・政治等と接続する。
- 標準では特定の共有資源ゲーム理論や詳細な管理制度評価モデルをC相当まで必須としない。
- 利用・回復に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 累積利用圧の標準表現
- 利用圧から資源状態への接続
- 管理制度・利用権との関係
- 詳細領域外での簡略化

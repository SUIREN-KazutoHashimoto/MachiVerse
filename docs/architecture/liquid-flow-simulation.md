# 液体3D挙動シミュレーション設計

## 1. 確定方針

標準では洪水・浸水・漏水等を固定された水域表示だけとして扱わず、地形・構造物に沿った液体の移動を表現する。

- 洪水、浸水、漏水等について、地形、建物、地下空間等に沿った流入・排出・水位変化を扱えるものとする。
- 水の存在によって通行可能性、建物・設備、住人、地下空間、衛生等へ影響が生じ得る。
- 河川・水域、上下水道、地下水、天候、災害、地下空間等と接続する。
- 標準では世界中の液体を流速・方向・圧力等まで常に詳細な3D流体として解くC相当を必須としない。
- 将来アドオンによって、流速・方向・圧力等を含む比較的詳細な3D流体モデルへC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 液体移動・水位変化等も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準の液体空間表現
- 流入・排出・水位変化の計算方式
- 地表・建物・地下空間間の水移動
- 河川・海・地下水・配管との境界
- 水による物理的被害・移動制約
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

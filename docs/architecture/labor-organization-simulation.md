# 労働組合・ギルド・職能団体シミュレーション設計

## 確定方針

標準では社会・時代に応じて労働組合、ギルド、職能団体等が実際の組織として歴史的に形成・変化し得る。

- 団体は既存の組織シミュレーション上の主体として扱い、成立・成長・縮小・分裂・統合・消滅し得る。
- 賃金、労働条件、資格、職業への参入、ストライキ、交渉等へ影響し得る。この列挙は網羅ではない。
- 住人の職業、技能、雇用関係、企業、政治・法、資格・免許、評判・信頼等と接続する。
- 現代的な労働組合制度を全社会・全時代へ普遍的に適用しない。
- 標準では詳細な団体交渉制度、労使関係法制、組合内政治等をC相当まで必須としない。
- 組織形成・意思決定等に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 今後決定が必要な事項

- 労働系団体と一般組織モデルの追加状態
- 団体交渉・ストライキの標準粒度
- 職業参入・資格制度との接続

# 物品所在シミュレーション設計

## 1. 確定方針

標準では必要な物品について、単なる在庫コンテナ所属だけでなく、世界内の所在を表現し、実際にアクセスできる位置関係を持たせる。

- 必要な物品について、部屋、棚、設備、車両、住人の携行品等の所在を表現できるものとする。この列挙は確定済みの全所在種別ではない。
- 物品を利用するには、原則としてその所在へ物理的・制度的にアクセスできる必要がある。
- 所在状態は物品運搬、在庫、建物内部、アクセス制御、作業、所有・権利等と接続する。
- 同種品を必ず一個ずつ独立Entity化することは要求せず、既存の物品実体性方針に従う。
- 標準では一般物品すべてをセンチメートル級の3D座標・姿勢で常時管理するC相当を必須としない。
- 必要な粒度で位置・保管先・携行先等を表現し、物理的因果を維持する。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 所在表現の標準粒度
- コンテナ・棚・設備・携行品等の階層表現
- 同種品集約時の所在管理
- 物品へのアクセス判定
- 所在変更と運搬・荷役との接続
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

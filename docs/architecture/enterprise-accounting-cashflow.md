# 企業会計・資金繰りシミュレーション設計

## 1. 確定方針

標準では企業を単一の所持金・利益だけで評価せず、事業継続に必要な資産・負債・資金繰りをある程度区別する。

- 現金・利用可能な支払資産、債権、債務、在庫、固定資産、収入、支出等を必要な粒度で区別できる。この列挙は確定済みの全会計要素ではない。
- 利益が発生していても、必要な時点で支払いに利用できる資金が不足すれば事業活動が制約・停止し得る。
- 売掛・買掛等に相当する将来受取・支払関係を契約・信用・債務モデルと接続できる方向とする。
- 在庫・設備・不動産等の実世界資産と企業側の経済状態を接続する。
- 企業活動、製造、雇用、契約、金融・信用、税・公共財政、破産等と接続する。
- 標準では複式簿記、詳細な会計基準、減価償却制度、財務諸表等をC相当の最高詳細度まで必須としない。
- 将来アドオンによって、複式簿記・詳細な会計制度・財務諸表等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 経済状態の更新も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準の企業資産・負債状態
- 収益認識と現金・支払可能資産の区別
- 債権・債務の満期・回収・支払
- 固定資産・在庫の評価をどこまで扱うか
- 資金不足時の企業意思決定
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

# 鍵・アクセス権シミュレーション設計

## 1. 確定方針

標準では住人へ単一の「入室可能」フラグを付与するだけにせず、物理的な施錠と制度的な許可・権限を分離して扱う。

- 鍵、資格、許可、組織上の権限等によって、扉・設備・区域等へのアクセス可否が決まり得る。
- 物理的に鍵が掛かっていることと、制度上その場所・設備を利用してよいことは別概念とする。
- アクセス制御は所有・権利、組織、職業、犯罪・司法、防犯、建物内部等と接続する。
- 権限を持たなくても物理的に侵入・破壊等が可能な場合を排除しないが、具体的な侵入モデルは別途定義する。
- 標準では鍵の複製、錠前内部構造、電子認証方式等をC相当の最高詳細度まで常時計算することは要求しない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 物理鍵・資格・許可・組織権限の標準表現
- アクセス対象の識別方法
- 権限付与・失効・移譲のモデル
- 不正利用・盗難・侵入との接続
- 一時的アクセス・共有アクセスの扱い
- 詳細領域外での簡略化
- 標準と将来アドオンの境界

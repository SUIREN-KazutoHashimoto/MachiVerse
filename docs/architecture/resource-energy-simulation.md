# 資源・エネルギーシミュレーション設計

## 1. 確定方針

標準では、資源・エネルギーを地域単位の供給量だけに抽象化せず、世界内の生産・流通・消費過程と接続する。

- 地下資源その他の自然資源は、既存の自然環境・世界生成と接続する。
- 採掘・採取、加工、保管、輸送、消費を因果的につなげられるものとする。
- 発電・燃料等のエネルギー供給も設備、資源、技術、労働、物流、需要等と接続する。
- 資源・エネルギーの不足や供給障害が、産業、交通、都市、生活、軍事、経済等へ波及し得るものとする。
- 発電網・送配電・燃料品質・設備特性等を工学的に最高詳細度で常時シミュレーションすることは標準要件としない。
- より詳細なエネルギー工学・資源工学等は将来アドオンで拡張できる余地を持たせる。
- ランダム性を伴う場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 標準資源・エネルギー種別
- 埋蔵量・品質等の粒度
- 採掘・採取・加工工程の粒度
- エネルギー変換・発電設備の表現
- 電力網等を標準でどこまで扱うか
- 保管・輸送損失・供給制約の粒度
- 技術発展との接続
- 事前歴史・詳細領域外での簡略化
- 標準と将来アドオンの境界

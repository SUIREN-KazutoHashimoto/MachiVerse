# 製造工程・生産設備シミュレーション設計

## 1. 確定方針

標準では製造を原料と労働力から製品を直接生成する抽象変換だけにせず、比較的詳細な工程・設備モデルを持つ。

- 原料、中間財、設備、工具、労働、技術、時間等を利用する複数の製造・加工工程を表現できるものとする。
- 機械・設備ごとの役割や加工工程、工程順序を生産へ反映できる方向とする。
- 設備能力、設備状態・故障、必要な工具、物流・在庫等によって生産可能性・生産量が変化し得る。
- 品質管理や歩留まりを標準シミュレーション対象に含め、投入量と良品生産量が常に完全一致するとは仮定しない。
- 作業者の知識・技能・職業、製品品質、企業活動、物流、資源・エネルギー、保守等と相互作用する。
- C相当の比較的深い製造工程を標準範囲とするが、全製品について現実の製造工学を無制限に再現することまでは要求しない。
- 製造工程に確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 工程・レシピ・中間財の標準表現
- 機械・工具・設備能力の粒度
- 工程順序・並列工程の表現
- 品質管理・不良・歩留まりの具体モデル
- 作業者技能と工程結果の関係
- 設備故障・保守との具体的接続
- 生産ライン・工場内部をどこまで3D空間と接続するか
- 事前歴史・詳細領域外での簡略化

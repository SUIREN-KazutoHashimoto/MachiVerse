# 食料・農業・生態系シミュレーション設計

## 1. 目的

本書は、MachiVerse における食料生産・保存・輸送・流通・消費、農業・畜産・漁業・採集、生態系と自然環境の関係に関する要件を整理します。

## 2. 確定事項

- 食料を単一の抽象的な「食料値」だけで扱うことを標準とはしない。
- 農業、畜産、漁業、採集等の食料獲得・生産活動を自然環境、技術、労働、土地利用、経済、交通等と接続できるものとする。
- 生産された食料は、保存、輸送、販売・交換、消費等の過程を持てる設計とする。
- 不作や生産低下、物流断絶等が価格、健康、人口、移住、政治、社会その他へ波及し得るものとする。
- 生態系も標準で一定程度扱い、植生、動物資源その他の自然状態が人間活動から影響を受け、人間活動へ影響を返せる設計を目指す。
- 世界全域の全生物個体を常時個体単位でシミュレーションすることは標準要件としない。
- より高度・詳細な農業、生態学、個体群、生物種等のシミュレーションは将来アドオンで拡張できる余地を持たせる。
- 食料生産、生態系変化等に確率的要素を含める場合も、MachiVerse の決定論・完全再現性の原則に従う。

## 3. 食料の因果連鎖

食料について、生産量だけを直接増減させるモデルではなく、自然条件、資源、土地、技術、労働、設備等から生産され、保存・物流・市場等を通じて住人へ到達し、消費される因果連鎖を持たせる方向とします。

食料不足は健康・出生・死亡・移住・経済・政治等へ影響し得ますが、具体的な影響項目・数式・閾値等は今後定義します。

## 4. 生態系

植生や動物資源等は自然環境の固定背景ではなく、気候・地形・水・人間活動その他の条件により変化し得るものとします。

ただし、標準でどの生物群・生態関係を個別状態として保持するか、個体群として集約するか等は今後定義します。

## 5. 標準モデルとアドオン

標準では、食料が自然・経済・住人の健康・社会変化と因果的につながる程度まで比較的深く扱います。一方、詳細な作物生理、全生物個体、複雑な食物網等を世界全域で最高詳細度に扱うことは要求しません。

より詳細な農業、畜産、漁業、生態系、生物種等は将来アドオンで拡張できる余地を持たせます。具体的なアドオンAPI等は現時点では確定しません。

## 6. 今後決定が必要な事項

- 標準で扱う食料カテゴリと生産方式
- 農業・畜産・漁業・採集の具体モデル
- 作付け、収穫、繁殖、漁獲等の時間粒度
- 保存・腐敗・加工等の標準粒度
- 食料物流・市場との具体的な接続
- 栄養と健康モデルの接続
- 生態系を構成する標準状態・生物群
- 人間活動による生態系への影響
- 生態系から資源・農業等への影響
- 不作・飢饉等の発生・波及モデル
- 事前歴史シミュレーションでの簡略化範囲
- 詳細シミュレーション領域外での簡略化範囲
- 標準モデルと将来アドオン拡張の具体的な境界

# 室内空気環境シミュレーション設計

## 1. 確定方針

標準では建物全体を単一の空気環境として固定せず、少なくとも部屋等の空間単位で環境差を表現する。

- 部屋等の空間ごとに温度、換気、煙等の状態が異なり得る。
- 扉、窓、開口部、換気設備等の状態によって室内環境が変化し得る。
- 屋外の煙・ガス・気象、地下空間、火災、暖冷房、電力等と接続する。
- 室内空気環境は住人の健康、知覚、避難、睡眠、作業等へ影響し得る。
- 標準では部屋内部のあらゆる位置について詳細な空気流・煙・ガス濃度を常時計算するC相当を必須としない。
- 将来アドオンによって、部屋内部の空気流・煙・ガス濃度分布等をC相当まで拡張できる余地を持たせる。
- アドオン対応を理由として標準実装の性能・決定論・現在の要件を損なう設計にはしない。
- 確率的要素を含む場合も決定論・完全再現性の原則に従う。

## 2. 今後決定が必要な事項

- 室内環境の標準空間単位
- 温度・換気・煙・ガス等の標準状態
- 扉・窓・換気設備による交換モデル
- 屋外・地下との境界交換
- 暖冷房・電力・故障との接続
- 詳細領域外での簡略化
- C相当を可能にする将来アドオンとの境界。ただし具体的API・機構は現時点では定義しない

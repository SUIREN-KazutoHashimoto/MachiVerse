# 要件定義 Q100〜Q199

この文書は、対話ベースの要件定義で確定した質問と回答結果を要件番号順に保持します。質問文は要件として意味が変わらない範囲で要旨化し、回答結果は確定時の選択とカスタム指定を保持します。

| Q | 質問 | 回答結果 |
|---:|---|---|
| 100 | 労働を抽象フラグだけで処理するか | B相当。住人が実際に勤務場所へ移動し、必要な工具・設備・材料等を使用して仕事を行う。物理的に到達不能なら原則として仕事を実行できない。 |
| 101 | 商品の物理輸送をどこまで扱うか | 標準B、詳細はC相当アドオン。実際に持つ・積む・運ぶことを3D空間上で扱う。詳細な積載位置・重心等は将来拡張。 |
| 102 | 扉・窓・門の状態をどう扱うか | B相当。開閉・施錠状態が通行、視界、空気・煙、利用に影響する。 |
| 103 | 物理鍵と制度上のアクセス権をどう扱うか | B相当。鍵、認証情報、権限、組織上の権威等を扱い、物理的施錠と制度的許可を分離する。 |
| 104 | 物品の所在をどこまで持つか | B相当。必要な物品は部屋、棚、設備、車両、携行中等の位置を持ち、アクセス可能であることを要求する。全物品のセンチメートル姿勢は必須でない。 |
| 105 | 建設を瞬時に完成させるか | B相当。複数工程、労働、材料、工具・機械、設備、配送、技術、時間を必要とし、天候・不足・故障等で変化する。 |
| 106 | 建設途中状態を世界に存在させるか | B相当。基礎、骨組み、壁、未完成道路、設備等を実状態として持ち、3D世界へ影響させる。放棄時も残存し得る。 |
| 107 | 建設計画・設計をどう扱うか | B相当。場所、規模、資源等を持つ計画情報を実施工と分離し、変更・中止・延期を許容する。 |
| 108 | 公共事業をどう扱うか | B相当。道路、橋、鉄道、水道等を組織が計画・資金調達・権利調整・契約・調達・建設し、遅延・変更・中止し得る。 |
| 109 | 解体・撤去をどう扱うか | B相当。瞬時削除ではなく、労働、工具、時間を要する途中状態を持ち、廃棄物・再利用材・スクラップを発生させる。 |
| 110 | 野生動物をどう扱うか | 標準B、詳細はC相当アドオン。種ごとの個体群、 habitat、食物、繁殖、死亡、移動、捕食を扱い、必要な個体は実体化する。全個体常時詳細は必須でない。 |
| 111 | 家畜・ペットをどう扱うか | 標準B、詳細はC相当アドオン。実生物として所有、飼育、給餌、繁殖、疾病、死亡、移動を扱う。詳細性格・訓練・血統は拡張。 |
| 112 | 植物・森林をどう扱うか | 標準B、詳細はC相当アドオン。群落の成長、死亡、繁殖、遷移と自然・人間活動の影響を扱い、重要な植物は必要に応じ個体化。全樹木個体化は拡張。 |
| 113 | 動物行動をどう扱うか | 標準B、詳細はC相当アドオン。内部状態と知覚に基づく行動を持たせるが、人間心理モデルをそのまま適用しない。フル3D移動と接続。 |
| 114 | 食物網をどう扱うか | B相当。植物・動物種間の食物関係、捕食・採食、人間活動との因果を扱う。最大詳細の種・栄養フローは要求しない。 |
| 115 | 素材・材料の粒度をどうするか | B相当。鉄、銅、石灰岩、粘土、木材種等、用途・加工・入手・性質の差を表せる比較的細かな材料種を標準で持つ。最高詳細材料科学は要求しない。 |
| 116 | 原料から製品までの変換鎖をどう扱うか | 標準B、詳細はC相当アドオン。中間材と工程を実在させ、技術で工程が変化し、中間材も在庫・輸送・交易対象とする。詳細BOM・化学は拡張。 |
| 117 | 再利用・リサイクルをどう扱うか | B相当。廃棄物、スクラップ、中古品を回収、再利用、修理、再加工、再資源化し、資源・設備・労働を要し、無損失循環にはしない。 |
| 118 | 物質・資源保存をどこまで要求するか | B相当。重要な資源・材料フローでは因果的な収支整合性を保ち、集約・展開で不自然な生成・消滅を起こさない。微視的な厳密質量保存までは要求しない。 |
| 119 | 副産物・産業廃棄物をどう扱うか | 標準B、詳細はC相当アドオン。製造、採掘、精錬等で副産物を発生させ、処理、保存、輸送、販売、再利用、廃棄を扱う。 |
| 120 | 通貨・貨幣制度をどう扱うか | B相当。複数通貨・交換手段、受容・価値差、制度の成立・変化・衰退を扱い、普遍的な現代中央銀行を前提にしない。当時は通貨供給・金融政策を未確定としたが、Q279で標準範囲を確定。 |
| 121 | 支払・決済方法をどう扱うか | 標準B、詳細はC相当アドオン。物理貨幣、預金・口座的資産、信用による支払を区別し、時代・制度に応じた方法を扱う。銀行間清算等は拡張。 |
| 122 | 家計をどう扱うか | B相当。共同住宅、食料、生活費、育児等の共有資源・支出を扱いつつ、個人所有、所得、債務を分離する。核家族を普遍化しない。 |

| 125 | マスメディアをどう扱うか | 標準B、詳細はC相当アドオン。実組織・主体が情報収集、編集、発信し、到達範囲・速度が技術・インフラに依存する。詳細コンテンツ・視聴率等は拡張。 |
| 126 | 報道内容とCore真実をどう扱うか | 標準B、詳細はC相当アドオン。Core真実とメディア・住人・組織知識を分離し、不完全、誤り、偏り、編集を許容する。受信と信念も分離。 |
| 127 | 通信ネットワークをどう扱うか | 標準B、詳細はC相当アドオン。郵便、電信、電話、無線、デジタル等を時代に応じて扱い、遅延、範囲、容量、故障を持つ。詳細パケット・ルーティングは拡張。 |
| 128 | 秘密・機密情報をどう扱うか | 標準B、詳細はC相当アドオン。誰が知っているかを追跡し、共有、漏洩、窃取、諜報等を扱う。アクセス権と実際に知っていることを分離。 |

| 130 | 感情をどう扱うか | 標準B、詳細はC相当アドオン。複数感情を持ち、出来事、記憶、関係、身体、環境から変化し、意思決定へ影響する。詳細心理は拡張。 |

# 要件定義 Q001〜Q099

この文書は、対話ベースの要件定義で確定した質問と回答結果を要件番号順に保持します。質問文は要件として意味が変わらない範囲で要旨化し、回答結果は確定時の選択とカスタム指定を保持します。

| Q | 質問 | 回答結果 |
|---:|---|---|
| 001 | ワールド開始方式をどうするか | 外部Configで選択可能。デフォルトは現実世界に似た初期条件から開始する方式。現実世界そのものの複製ではなく、同一Seed・同一Configで決定論的に同一初期状態を得る。 |
| 002 | 現実世界らしさと固有名詞をどう扱うか | 国家・都市・人口・産業・交通等は現実世界に類似した構造を持たせるがコピーしない。実在固有名詞を標準使用せず、事前に非常に大規模な固有名詞リストを用意し決定論的に利用する。 |
| 003 | 初期地形をどう生成するか | Earth-likeな法則・統計を参考にSeedから独自世界を生成する。詳細生成前に世界全体の簡易マップを生成し、自然条件から社会形成へ因果をつなぐ。 |
| 004 | 簡易世界マップに何を持たせるか | 陸海、標高、山脈、河川・湖、気候帯、降水、気温、植生、土壌、資源、海流、プレート、大域風系を扱う。海陸比はデフォルトで地球と概ね同程度。 |
| 005 | 開始時点の文明・社会を直接配置するか | 可能な限り事前歴史シミュレーションの結果として形成する。初期生成は現実的な範囲ならある程度時間がかかってよく、速度より因果性・品質を優先する。 |
| 006 | 事前歴史シミュレーションの開始段階をどうするか | Configで選択可能。デフォルトは人類が世界各地にある程度分布しているが初期文明は未成立の段階。文化・言語・宗教・民族は歴史の中で形成・分岐・融合・変化する。民族は生物学的人種モデルとしない。 |
| 007 | 技術体系をどう表現するか | 技術カテゴリ・基礎原理と成立条件を事前定義し、発見時期・順序・伝播はシミュレーション結果とする。技術単位は比較的細かくし、伝播と喪失を扱う。 |
| 008 | 知識をどの粒度で持つか | 住人単位で知識を持つ。技術・知識の存在、知っている、理解している、利用できるを分離し、職業・伝承・喪失と接続する。 |
| 009 | 職業を固定属性にするか | 動的に形成・変更される状態とする。知識・技能だけで職業を決めず、実際の仕事、組織、収入、需要、個人・地域・社会条件等を含める。 |
| 010 | 住人の心理をどこまで標準化するか | 欲求、価値観、性格、対人関係等を標準で必要十分な深さまで扱う。より深い心理モデルは将来アドオンで拡張可能とする。 |
| 011 | 人間関係をどう保持するか | 全住人全組合せを持たず、実際に成立した関係をペア状態として保持し動的に変化させる。 |
| 012 | 組織をどう扱うか | 組織は歴史的に形成・成長・縮小・分裂・統合・消滅する実体とする。複数所属、役割、権限、利害を扱う。 |
| 013 | 経済をどこまで標準で扱うか | B相当。生産、消費、交換、価格、賃金、雇用、家計、企業、在庫、物流、基本金融をある程度深く扱う。 |
| 014 | 政治・統治をどこまで標準で扱うか | B相当。法、税、行政、治安、外交、軍事、権力移行等を扱い、制度は歴史的に成立する。 |
| 015 | 軍事をどこまで扱うか | 比較的深く扱う。兵士は実住人で、部隊、装備、補給、地形、輸送、指揮、士気等を扱う。フル3D世界と接続するが投射物物理等を最高詳細度まで要求しない。 |
| 016 | 集落・都市をどう成立させるか | 実際の建物、道路、インフラ等の建造環境から因果的に成立させる。成長・縮小・放棄・遺構を扱う。 |
| 017 | 所有権をどう扱うか | 所有・占有・利用と制度上の所有権・利用権を分離した世界状態として扱い、社会制度により形態が異なる。 |
| 018 | 犯罪・司法・治安をどう扱うか | 比較的深く扱う。捜査、逮捕、裁判、処罰を実際の過程として扱い、普遍的な現代法制度を前提にしない。 |
| 019 | 情報をどう扱うか | Coreの世界事実と住人の認識を分離する。受信と信念を分け、情報の伝播時間・経路・範囲・歪みを扱う。 |
| 020 | ライフサイクル・健康をどう扱うか | 出生、成長、老化、負傷、疾病、回復、障害、死亡を扱う。 |
| 021 | 家族・世代・遺伝をどう扱うか | 実際の親子関係と世代を持つ。外見・身体傾向に必要十分な遺伝要素を扱うが、人種メカニクスにはしない。 |
| 022 | 食料・農業・生態系をどう扱うか | 農業、畜産、漁業、採集を自然環境と接続し、保存、輸送、販売、消費を扱う。生態系もある程度扱う。 |
| 023 | 自然災害をどう発生させるか | 可能な限り地形、プレート、気候、水、植生等から因果的に発生させる。 |
| 024 | 歴史記録をどう残すか | 意味のある出来事を保持し、Coreの真の歴史と住人側の記録を分ける。全30Hz状態を歴史イベントとして保存する必要はなく、リプレイがあるため優先度は相対的に低い。 |
| 025 | 言語・文化・宗教をどう扱うか | B相当。住人レベルの関係を持ち、変化・混合・伝播し、必ずしも排他的でない。 |
| 026 | 教育・学習をどう扱うか | B相当。家族、徒弟、学校、組織、自学等の複数経路を持ち、資源・時間・費用を要し、制度は歴史的に成立する。 |
| 027 | 交通・物流をどこまで扱うか | C相当。交通手段・車両等を実体として移動させ、積載、積替、運行、混雑、事故等を扱う。 |
| 028 | 資源・エネルギーをどう扱うか | B相当。採掘、加工、保存、輸送、消費、発電・燃料、供給不足を扱う。 |
| 029 | 天気・気候をどこまで扱うか | B相当。日々の空間的・時間的天気変化を因果的に扱うが、完全な数値予報モデルは要求しない。 |
| 030 | 企業活動をどう扱うか | B相当。施設、在庫、資金、従業員を持つ実組織として、調達、生産、販売、投資、採用、解雇、価格設定等を扱う。 |
| 031 | 市場・価格をどう形成するか | B相当。実取引から価格が形成される。詳細な注文板を標準必須とはしない。 |
| 032 | 住人の日常行動をどこまで扱うか | C相当。実移動、食事、商品選択、余暇、家事等を比較的詳細に扱うが、身体の微細動作までは要求しない。 |
| 033 | 商品・物品の粒度をどうするか | B相当。種類＋数量を基本とし、必要に応じ在庫・輸送単位を持つ。同種商品すべてを必ず個別Entityにはしない。 |
| 034 | 建物内部をどこまで扱うか | C相当。部屋、扉、家具、設備等を実3D空間として扱い、住人が内部を移動・利用する。詳細度制御を許容する。 |
| 035 | 医療をどう扱うか | B相当。医療従事者、薬、施設、設備、診察、治療、入院、アクセス性を扱う。 |
| 036 | 感染症をどう扱うか | B相当。住人の接触、移動、密度、衛生、免疫等と疾病特性から流行を扱う。 |
| 037 | 外交をどう扱うか | B相当。条約、交渉、同盟、貿易、領土問題、使節等を扱い、国家・組織間関係は歴史を持つ。 |
| 038 | 汚染・廃棄物をどう扱うか | B相当。生産、輸送、廃棄、エネルギー利用等から大気・水・土壌汚染を発生させ、廃棄物処理系と接続する。 |
| 039 | 火災をどう扱うか | C相当。内部空間、可燃性、構造、天候、延焼、煙、避難、消防を実世界Entityと接続する。 |
| 040 | 水道・衛生インフラをどう扱うか | 標準B、詳細水理はC相当アドオン。自然水、取水、供給、利用、排水、処理を扱い、管路を世界インフラとする。 |
| 041 | 電力・通信インフラをどう扱うか | 標準B、詳細電力潮流・詳細ルーティングはC相当アドオン。発電所、送配電、通信設備、停電・障害を扱う。 |
| 042 | 土地利用・都市計画をどう扱うか | B相当。所有、権利、価値、交通、地形、需要、社会に存在する場合の計画規則から形成し、普遍的なゾーニングを前提にしない。 |
| 043 | 物理移動・衝突をどう扱うか | B相当。フル3Dで壁、内部、地形、障害物、通行可否、基本衝突・占有を扱う。高度物理はアドオン候補。 |
| 044 | 住人の知覚をどう扱うか | 標準B、詳細はC相当アドオン。視覚は遮蔽・距離・光、聴覚は距離・到達等をある程度扱い、知覚イベントを情報系へ接続する。 |
| 045 | 移住・人口移動をどう扱うか | 標準B、詳細はC相当アドオン。住人自身が意思決定し、実際に物理移動する。難民・国境詳細等は拡張可能。 |
| 046 | 社会階層・格差をどう扱うか | B相当。所得、資産、職業、教育、人間関係、権力等から創発し、固定普遍階級を前提にしない。 |
| 047 | 世論・集団行動をどう扱うか | B相当。個人意見が集約・相互作用し、抗議、デモ、ボイコット等を実際の行動として扱う。 |
| 048 | 政治制度の変化をどう扱うか | B相当。政治制度は歴史的に変化し、普遍的な発展段階を固定しない。 |
| 049 | 発明・イノベーションをどう扱うか | B相当。実住人・組織が知識、必要性、研究、資源等を背景に発見・発明し、所有・伝播を扱う。 |
| 050 | 信用・債務・金融をどう扱うか | B相当。貸借、利息、返済、信用、債務不履行、担保をある程度扱う。高度な銀行・市場はアドオン候補。 |
| 051 | 税・公共財政をどう扱うか | B相当。歳入、歳出、配分、徴税能力、財政効果を扱い、普遍的な現代税制を前提にしない。 |
| 052 | 資源枯渇・再生をどう扱うか | B相当。非再生資源の枯渇、再生資源の再生と過剰利用、その下流影響を扱う。 |
| 053 | 生態系劣化・回復をどう扱うか | B相当。土壌劣化、森林減少、砂漠化、汚染蓄積、回復を扱う。 |
| 054 | 建物・機械・インフラの保守劣化をどう扱うか | B相当。経年劣化し、保守に資源・人員を必要とし、故障・性能低下の結果を持つ。 |
| 055 | 恋愛・パートナー関係をどう扱うか | B相当。出会い、相性、価値観、生活、文化等から交際、同居、婚姻、別離等を扱い、普遍的な家族形態を固定しない。 |

| 061 | 消費者の商品選択をどう扱うか | C相当。価格、所得、必要性、品質、評判、嗜好、距離、在庫、ブランド・提供者、広告・情報、限定合理性・衝動等を扱う。 |

## 後続要件による補足

Q083の「標準では全世界を常時全個体詳細シミュレーションしない」という判断は、Q190〜Q193およびQ265〜Q266で整理されました。標準デフォルトでは可能な限り世界規模で個体の存在・永続ID・重要状態を保持しながら、更新頻度・計算詳細度を下げることを許容します。したがって「個体として存在すること」と「常時30Hzで詳細計算すること」は同義ではありません。
